# 개인 최종 산출물 검증 기록

## 최종 로컬 검사

2026-10-13, 실제 v1.0.1 data/가 설치된 작업 복사본에서 `python -m unittest discover -s tests -v`:

```text
Ran 110 tests in 62.422s
OK (skipped=7)
```

**103개 통과 / 7개 UI skip / 실패 0개.** 본문 최종 보고서에 적힌 99개 통과·6개 skip은 추가 검사를 보강하기 전의 중간 결과다. 대시보드 검사 22개 중 15개 집계 검사는 로컬 통과했고, Streamlit이 없는 로컬의 7개 UI 검사는 건너뛰었다. 원격 UI/합성 CI는 새 커밋의 실제 Actions 결과로 판정한다. 로컬 테스트를 원격 성공으로 간주하지 않는다.

주요 실행 코드·테스트·집계·선택/최종 JSON 등 26개 파일은 업로드된 Git 객체 해시와 로컬 바이트를 대조해 일치했다. 동결된 모델 코드 6개와 선택 Manifest SHA도 평가 후 바뀌지 않았다.

단일 최종 모델을 한 번 평가했으며, 저장된 예측의 산술 재검증과 저장 모델 128건 재로딩 일치 검사는 새 후보 테스트가 아니다. 예측 CLI는 별도 개발 입력 2건을 사용해 동작, 덮어쓰기 거부, 모델 SHA 불일치 거부를 확인했다.

원본/개별 예측/모델 바이너리는 공개 Git에 포함하지 않는다. 실제 브라우저 픽셀·모바일 레이아웃 검수와 외부 서비스 배포는 미실행이다. AppTest는 기능 검사이며 시각 검수를 대체하지 않는다.
