## 결과

전체 개발 데이터의 geo2 Group OOF로 **LGBM-O는 b=0.5, LGBM_TE_G는 b=0.3**을 고정했다. 규칙은 `argmax(p · (1,1,exp(b)))`다. 새 모델 학습은 0회이며 기존 검증된 확률 OOF를 재사용했다. 두 값 모두 그리드 상한 2.0에 닿지 않았다.

| 모델 | 고정 b | 3등급 확률 배수 exp(b) | 선택용 점수 b=0 | 선택용 점수 고정 b |
|---|---:|---:|---:|---:|
| LGBM-O | 0.5 | 1.648721 | 0.583186 | 0.597006 |
| LGBM_TE_G | 0.3 | 1.349859 | 0.592675 | 0.598055 |

표의 점수는 **b 선택에 사용한 동일 개발 OOF의 통계**다. 성능 개선의 독립 확인, 모델 간 우열, 최종 후보 선정으로 해석하지 않는다. T15의 효과 검증을 독립적으로 반복한 결과도 아니다.

이번 완료는 두 모델 설정 각각에 대한 b 고정이다. **규칙 채택·최종 모델 선정·전체 개발 최종 모델 학습·홀드아웃 평가는 수행하지 않았다.** LR-C 기준선을 유지한다. class_weight는 별도 학습 요인이며 이번에 변경하지 않았다.

## 방법과 재사용 검증

개발 데이터 208,480행을 `(geo_level_1_id, geo_level_2_id)` 그룹으로 나눈 seed 42/101/202/303의 5-Fold OOF를 사용했다. 각 seed에서 전체 개발 행은 정확히 한 번 검증 예측된다. seed42는 T8의 LGBM-O와 T11의 LGBM_TE_G, 나머지 seed는 T13의 두 팔이다. T15의 조정된 예측이 아닌 원래 확률을 재사용했다.

모델별로 b=0.0~2.0(0.1 간격)의 21개 값에서 각 seed의 풀링 Macro F1(labels=[1,2,3])을 구한 뒤 네 seed 점수의 산술평균을 최대화했다. 정확 동률이면 작은 b를 고른다. Fold 점수 평균이나 반복 행 전체를 합친 단일 Macro F1을 목적함수로 쓰지 않았다.

봉인 전에 데이터 계약과 환경, 4개 manifest와 8개 OOF의 SHA, ID 커버리지·중복·라벨·Fold·확률 행합·저장 예측과 argmax 일치를 확인했다. 각 그룹은 한 Fold에만 속하며 학습/검증 그룹·ID 교집합은 0이다. 클래스 지지 게이트도 통과했다. 새 RF/LGBM 학습과 최종 fit은 없다.

선택 곡선 8개와 모델별 고정값 2개를 집계 체크포인트로 저장하고, 재로딩·SHA·백업 검증 뒤 원장에 완료했다. 집계 JSON에는 seed·Fold별 보정 전/고정 b의 클래스별 P/R/F1, 혼동행렬, 3→1·3→2 오류와 전체 선택 곡선을 남겼다. 행별 자료·모델·manifest는 공개하지 않는다.

## 해석의 한계

- 같은 라벨로 b를 선택하고 표의 점수를 계산했으므로 선택 낙관성이 있다. 독립 평가값이 아니다.
- 팔과 분할은 T15 결과를 보고 선택했고 OOF도 이전 연구에서 사용했다. 이번 사전등록은 b 고정 절차를 묶는 것이며, 연구 전체를 새 비적응적 검증으로 바꾸지 않는다.
- 네 seed는 같은 건물을 반복 예측한 자료다. 독립 표본 네 개가 아니며 유의성·인과 주장을 하지 않는다.
- b는 기존 고정 파라미터의 두 모델과 미관측 geo2 상황에 대응한다. 별도 튜닝 모델이나 다른 배포 분포에 자동 이전할 근거가 없다. 전체 개발 fit과 OOF 모델의 학습 크기 차이도 남는다.
- 과거 학습 과정의 적합성은 기존 T8·T11·T13·T15 감사와 출처에 의존한다. 이번 단계에서는 기존 파일의 무결성과 선택 계산을 검증했다.
