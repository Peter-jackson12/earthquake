## 피처와 비교 범위

- `GEO1_CONTEXT`: outer-train의 `geo_level_1_id`별로 `count_floors_pre_eq`, `height_percentage`, `area_percentage` 순서의 중앙값 3열을 계산하고, 각 건물의 원값−사용한 중앙값 차이 3열을 뒤에 붙였다. 학습 행 자신의 값도 학습 지역 통계에 포함하며 정답과 검증 행은 통계 계산에 사용하지 않았다. 짝수 개 관측의 중앙값은 가운데 두 값의 산술평균이다.
- 학습 때 없던 geo1은 **같은 outer-train 전체의 수치 3열 중앙값**을 사용한다. 검증 자료에서 지역 통계를 다시 계산하지 않는다. 이 대체 규칙은 미관측 geo1 발생 행에 적용하는 fallback이며 y를 사용하지 않는다.
- 추가 6열은 float64로 중앙값·차이를 계산한 뒤 **스케일링·클리핑 없이 float32 CSR**로 변환했다. 차이는 음수일 수 있다. 지역 코드와 입력 수치는 유한한 비음수 정수라는 계약을 적용했고 전체 희소행렬을 밀집화하지 않았다. 높이·면적은 정규화된 값이므로 미터·제곱미터로 해석하지 않는다.

기존 38개 입력과 C 전처리의 age995 대치·표시·수치 스케일링·원핫은 그대로 유지했다. 300 rounds, 31 leaves, 학습률0.05와 내부2스레드를 고정했다. 가중치·ROS·early stopping·튜닝·사후 결정 규칙은 없으며 argmax 동률은 낮은 등급이다. 기준선은 T8/T13의 감사된 OOF를 재사용했고 신규 기준선 학습은0회다. 다른 피처, T17/T18/T20/T21/T22/T23 또는 순서형 학습을 결합하지 않았다.

## 해석의 한계와 유지할 결정

단일 후속 가설을 탐색했고 이전 연구에서 같은 개발 자료와 분할을 반복 사용했다. 다중 탐색과 누적 선택 편향이 남으므로 평균·Fold·seed의 조건 충족을 새로운 독립 외부 성능이나 통계적 유의성으로 해석하지 않는다. 20개 Fold 결과와833,920개 신규 예측도 독립 관측 수가 아니다. 다른 지역·미래 지진의 성능, 인과 효과, 안전성을 확정하지 않는다.

이번 결과는 geo1 중앙값과 상대 차이6열 묶음 전체의 비교이며 각 구성요소의 효과를 분리하지 않는다. 정답을 쓰는 지역 Target Encoding과 다르며 지역 특성의 인과 효과를 확정하지 않는다. geo2 Group 평가를 **미관측 geo1 일반화의 검증으로 확대하지 않는다**. 관측된 미관측geo1 건수와 fallback 정의 검증은 새로운 geo1 집단에서의 독립 성능 평가를 대신하지 않는다. 다른 연구의 개선량과 합산하거나 피처 중요도만으로 개선 원인을 확정하지 않는다.

LR-C 연구 기준과 기존 개인 최종 모델을 유지한다. 홀드아웃 접근, 전체 개발 최종 fit, 최종 모델 변경은 수행하지 않았다.
