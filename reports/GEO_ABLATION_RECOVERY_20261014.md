기존 `EXECUTION_DEVIATION.md`에는 43시도/42완료/1중단/2미시도가 기록돼 있다. `RESUME_UNATTEMPTED.md`와 보완 실행기는 미시도 Fold3·4만 보완해 조건부로 45시도/44완료가 되는 계획이다. 이 문서와 코드의 존재만으로 보완 완료를 확정하지 않는다. 원래 Fold2 재시도 금지와 완료 Fold 재학습 금지는 유지한다.

현재 런타임은 이전 작업 디렉터리가 없는 새 환경이었다. Library 검색과 ZIP 목록에서 T1~T5 패키지는 회수했지만 T6 결과 패키지는 찾지 못했다. 이는 외부의 모든 보관 위치에 파일이 없다는 증명은 아니다. **확인된 결과의 중복 학습으로 누락 증거를 대체하지 않았다.**

## 5. 검증 범위와 테스트

개발 건물 208,480개에서 세 검증 방식의 OOF 625,440행, 15개 Fold 지표를 검증했다. ID·정답·Fold·확률·argmax·혼동행렬·평균·SD·하위 집단 지표를 독립 산술로 확인했다. 두 Group CV는 원래 SHA와 전체 ID→Fold 배정이 일치하고, 동일 그룹의 학습/검증 중복은 0이다.

기존 C Group-CV 저장 모델 10개를 SHA 확인 후 로드하여 전체 검증행 416,960건의 예측·확률을 대조했다. 각 학습 Fold의 연령 중앙값·스케일러 통계·범주와 미관측 범주 처리를 검증했다. Stratified C의 과거 5개 모델 파일은 회수 패키지에 없어서 그 부분의 저장 모델 재예측은 불가하다. 해당 C OOF·설정·소스·지표는 검증했으며 대체 학습하지 않았다.

새 테스트 **32개 통과, 실패0, 건너뜀0**. 합성 데이터의 전처리-only fit4회, 분류기 fit0회다. 지역 제외 열의 C 투영과의 일치, 제외 지역값 변경 불변, 원본38 스키마, ID/정답/Fold 유입 차단, 연령 통계, OOF 변조 거부, 기존 파일 덮어쓰기 거부, 증거 부재를 미시도로 간주하지 않는 규칙을 검사했다. 실제 T6 모델을 감사한 것으로 계산하지 않는다.

기존 T6 전체 감사는 원래 출력 부재로 실행하지 않았다. 전체 저장소 테스트를 로컬 비공개 데이터 환경에서 무리하게 실행하지 않았고, 원격 데이터 없는 CI의 실행 결과는 전달 영수증에 구분한다.

## 7. 정확한 차단 원인과 재개 조건

아래 원래 디렉터리의 비공개 증거가 필요하다. 개발 CSV와 T5 C 기준선은 이번에 복구했으므로 이 두 항목은 현재 차단 원인이 아니다.

```text
outputs/geo_ablation_v1/
  design.json / design_seal.json
  execution_interruption.json (기존 기록의 실제 위치 보존)
  stratified|geo2|geo1 / R12|R1|R0 / metadata.json, folds.json, OOF, fold_*.joblib

  supplement_design.json / supplement_seal.json / progress.json
  fold_3.joblib / fold_4.joblib / partial_oof.csv.gz / audit.json
```

보완 디렉터리가 없으면 보완이 실제로 미시도였는지 원래 실행 로그/시도 원장으로 확인해야 한다. 단순 파일 부재를 이유로 다시 fit하지 않는다. 원래42개와 보완2개의 감사 범위를 각각 확인한 뒤만 합산한다. Fold2가 중단 상태라면 Stratified/R12의 전체5Fold 평균·SD·pooled는 여전히 미완료다.

복구 재검증 명령은 `experiments/geo_ablation/README.md`에 있다. 출력은 새 경로에만 작성한다. 모든 원래 파일을 보존하고 새 결과를 과거 결과처럼 소급 봉인하지 않는다.

## 8. 이번 연구로 내릴 수 있는 결론의 범위

기존 C의 미관측 상위 지역에서 3등급 식별이 매우 약하다는 T5 결과는 재확인했다. **지역 변수를 제거하면 좋아지는지, geo3만 제거할 때와 전부 제거할 때의 차이, 랜덤 CV 성능 손실, 실제3등급의 오류 수정·신규 발생은 아직 이 복구 세션에서 판단할 수 없다.** R0 추천이나 C보다 우월하다는 주장을 하지 않는다. C는 비교용 기준선으로 유지하며 기존 최종/배포 모델을 바꾸지 않는다.

지역 누수·과적합의 인과적 증명, 외부 지진 일반화, 새 홀드아웃 평가, 비용 가중치 최적화, T4 모델 계열과의 통합은 수행하지 않았다. 다음 단계는 새 연구 방향을 고르기 전에 **T6 기존 증거를 회수하여 독립 감사를 재개하는 것**이다.

## 9. 공개/비공개 전달

공개 코드 패키지: 새 소스·테스트·문서·집계 JSON·테스트 로그. 비공개 C 복구 패키지: 개발 전용 CSV, 고정 분할, C OOF/10개 모델 및 설정. **T6 비공개 결과 패키지가 아니다.** 원시 CSV/행별 OOF/manifest/joblib은 공개 Git에 넣지 않는다.

기존 전처리 ZIP은 보관 파일로 회수했지만 허용한 개발 CSV·manifest·schema·checksum 멤버만 추출했다. 홀드아웃 feature/label 멤버 내용은 열기·추출·평가하지 않았으며 원본 전체 CSV도 읽지 않았다.
