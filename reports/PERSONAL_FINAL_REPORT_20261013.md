# Earthquake 개인 분석 최종 보고서 — 2026-10-13

## 결론

개인 `peter` 범위에서 전처리 대안 검토·비교, 최종 후보 동결, 1회 홀드아웃 평가와 집계 대시보드를 마무리했다. 최종 모델은 **기존 v1.0.1 전처리 + 무가중치 Logistic Regression C=1**이다. 새 전처리/합성 방식을 구현했다고 무조건 최종 모델에 채택하지 않았다.

- 개발 CV Macro F1: **0.683677** (Fold 표준편차 0.001071).
- 최종 홀드아웃 Macro F1: **0.686771**, Accuracy: **74.24%**.
- 개발 208,480건 / 홀드아웃 52,121건 / 입력 38개 / seed 42 / 고정 5-Fold.
- 고유 설정 19개(Dummy 포함), 고유 비교의 Fold 기록 95개. 기준선 근거 복구 재실행 5회까지 실제 CV fit은 100회이며 이번 단계는 신규 10회 + 재현 5회다. 별도로 최종 전체 개발 fit 1회가 있다. 합성 단위 테스트의 소규모 fit은 세지 않는다.
- 팀 최종 선정, main 병합, 팀원 수행 기록, LMS 제출, 외부 서비스 배포는 이 개인 완료와 별개다.

## 1. 선택 전 고정한 처리 정책

정책 커밋 `53966920c250178eb738df3856a9fd058033bac1`을 먼저 기록했다. 일반 SMOTENC의 파일럿에서 나온 범주 조합/특수 연령 문제를 무시하지 않고 다음 대안을 사용했다.

동일 등급 안에서 **지역 3개 + 문자 범주 8개 + 이진 플래그 22개 + 층수 + 가구수 + 연령 상태(0/995/나머지)**가 전부 같은 행끼리만 최대 5개 이웃을 구성한다. 일반 연령·면적 비율·높이 비율만 선형 보간하고, 이웃이 없으면 원본 부모를 복제한다. 0과 995의 실제 의미를 임의 확정하지 않으며 두 값 사이를 보간하지 않는다. 범주 이름을 건축 재료명으로 임의 복원하지 않는다.

스키마/인코더/스케일러는 원래 학습 Fold에서만 fit한다. 동일 범주의 원핫 값과 이진값은 보간 차이가 0인지 검사한다. 분수 값은 합성 학습 벡터의 수치 3개에만 허용하며 원본 CSV의 정수 계약은 유지한다. 원본 행 삭제·반올림·대치는 없다. 검증/홀드아웃에는 샘플러를 적용하지 않는다.

이 방식은 **자체 제약형 SMOTE + RandomOverSampler fallback**이며 stock SMOTENC 실행이라고 부르지 않는다. 일반 SMOTENC 파일럿은 불채택 기록으로 보존했다. 범주 조합과 수치 경계를 지켰다고 실재 건물의 공학적 타당성이 입증되는 것은 아니다. 정확히 같은 문맥을 고정하는 제약은 보간 다양성을 제한하는 대가가 있다.

## 2. 신규 비교 결과

| label                  |   cv_mean |   cv_std |   error_3_to_1 |   error_3_to_2 |   grade3_recall |
|:-----------------------|----------:|---------:|---------------:|---------------:|----------------:|
| LR 제약형 SMOTE + 복제 |  0.663206 | 0.001461 |           2491 |          15554 |        0.741379 |
| LR C=1 재현 점검       |  0.683677 | 0.001071 |            467 |          24761 |        0.638433 |
| LR RandomOverSampler   |  0.663369 | 0.001730 |           2493 |          15538 |        0.741580 |

3→1/3→2와 3등급 Recall의 분모는 개발 실제 3등급 69,774건이다. 두 증강 방식은 같은 RandomOverSampler의 부모 선택과 같은 총 학습 건수를 사용하므로 보간 적용 여부를 대조했다. 클래스별 최종 수는 각 Fold 최대 클래스 수(94,885 또는 94,886)에 맞췄다.

단순 복제와 제약형 보간 모두 기존 무가중치 LR보다 CV Macro F1이 낮았다. 둘 사이의 작은 차이를 유의한 우열로 주장하지 않는다. 증강은 3등급 Recall을 높였지만 심한 피해를 1등급으로 예측하는 오류도 늘렸다. 따라서 사전 선택 규칙에 따라 최종 모델에 채택하지 않았다.

기준선 LR의 새 5-Fold 재현에서는 기존 Fold 점수와 전역 혼동행렬이 일치했다. 이 재현의 OOF를 새로 보존했으며, 과거 원래 OOF 파일을 복구한 것으로 보지 않는다.

## 5. 검증과 근거 수준

신규 3개 실행의 OOF 625,440행과 이전 9개 실행을 포함한 **12개 실행·2,501,760개 행별 예측**을 ID/Fold/정답/확률/혼동행렬/지표에 대조했다. 저장된 최종 예측의 지표도 별도 산식으로 재계산했다. 이 산술 재확인은 두 번째 모델 선정이나 두 번째 홀드아웃 모델 평가가 아니다. 모델 저장 후 128건에서 로딩 전후 확률 일치도 확인했다.

실제 데이터 설치 환경에서 이 보고서 작성 직전 전체 테스트는 **105개 중 99개 통과, 로컬 Streamlit 부재로 UI 6개 skip**이었다. 추가 UI·공개 패키지 검증의 최종 상태는 전달 기록/해당 커밋의 Actions 결과로 구분한다. 성공하지 않은 검사는 성공으로 기재하지 않는다.

전처리 v1.0.1, baseline.py, 데이터 계약, 개발 CSV, Manifest, 과거 주요 집계는 보존했다. 이전 8개 원래 OOF 파일은 여전히 없으며 LR C=1의 새로운 재현과 구분한다. 일반 SMOTENC의 원래 전체 CV는 미실행이고, 이번 전체 비교는 별도 제약형 SMOTE 방식이다. 과제에서 특정 구현이 요구될 경우 이 차이를 설명해야 한다.

## 6. 실행과 산출물

`README_PERSONAL.md`가 개인 프로젝트의 실행 진입점이다. Streamlit은 공개 집계·선택 기록·최종 지표만 읽으며 원본, OOF, 모델 바이너리, 홀드아웃 정답을 읽지 않는다. 개인 최종 평가 화면과 기존 EDA/실험/오류/진행 상태를 구분한다.

```bash
python -m pip install -r requirements-dashboard.txt
python -m streamlit run app.py
```

예측은 비공개 모델을 설치한 뒤 별도 CLI로 수행한다. 신뢰할 수 없는 joblib 파일은 로딩하지 않는다. 모델 SHA를 최종 평가 기록과 대조한다. `freeze/evaluate`는 최초 실행을 위한 보존된 절차이며 이미 완료된 홀드아웃 점수를 다시 고르는 용도로 사용하지 않는다.

## 7. 개인 완료와 팀 경계

**개인 최종 평가 후 같은 공통 홀드아웃은 이미 노출된 자료다.** 이 결과를 보며 팀 후보를 다시 선택하고 같은 점수를 새로운 독립 테스트처럼 제시해서는 안 된다. 개인 모델을 그대로 채택하면 개인 최종 평가 결과의 재사용임을 명시하고, 팀이 다른 선택을 하려면 별도 평가 설계를 검토해야 한다.

main 변경/병합, 팀 Notion/LMS 제출, 다른 팀원 수행 대체, 외부 앱 배포는 하지 않았다. 데이터는 한 번의 지진 관측자료이고 무작위 분할 결과이므로 새로운 지역이나 미래 지진에 대한 일반화가 확인된 것은 아니다.

방법 참고: imbalanced-learn SMOTE / RandomOverSampler 공식 문서, scikit-learn Pipeline 공식 문서. 구체적인 제약과 채택 여부는 본 프로젝트의 사전 정책과 실제 CV 결과에 따른 개인 설계다.
