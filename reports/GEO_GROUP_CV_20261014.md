## 1. 완료 판정과 핵심 결론

**실행·감사 완료. 지역 단위 일반화 성능 유지는 확인되지 않았다.** 기존 C와 G2를 그대로 사용해 신규 20회 학습을 수행했다. 기존 랜덤 CV 모델은 재학습하지 않았고, 저장 OOF만 재검증했다. 모든 신규 모델이 수렴했으며 실제 개발 208,480행의 새 OOF 833,920건과 기존 OOF 416,960건을 구분해서 검증했다. 고유 건물은 208,480개다.

G2는 **2차 지역 Group CV에서 평균 F1 +0.003739**, 3→1 −4건·3→2 −187건으로 C보다 소폭 개선됐지만 5개 Fold 중 3개에서만 개선됐고, 원본995 집단은 악화됐다. **1차 지역 Group CV에서는 평균 F1 −0.004111, 3→1 +36건**으로 C보다 나빴다. 기존 점수 개선을 미관측 상위 지역에 일반화할 근거는 없다.

가장 중요한 실패는 1차 지역 CV의 **실제3등급 Recall C 0.631%, G2 0.608%**다. 실제3등급 69,774개 중 각각 440개·424개만 맞혔다. 정확도 약57.7%나 줄어든 3→1만 보고 피해 판별이 안전해졌다고 해석해서는 안 된다.

이는 검증 대상/훈련 구성과 미관측 범주 처리 조건이 바뀐 결과다. **기존 데이터 누수나 지역 코드 암기의 인과적 증거는 아니며**, 기존 최종 모델 교체·배포·새 홀드아웃 평가도 수행하지 않았다.

## 8. 재현·증거 위치와 인계

실행 코드와 설정은 학습 전 고정된 원격 바이트와 일치한다. 로컬은 전체 Git clone이 아니라 기존 패키지에서 필요한 원격 blob을 대조해 조립한 소스 스냅샷이다. 전체 저장소 테스트는 원격 체크아웃에서 실행됐다.

```bash
# GitHub T5 브랜치 체크아웃 후, 비공개 개발 data/와 기존 C/G2 evidence를 준비

python -m experiments.geo_group_cv.run prepare --data data --output outputs/geo_group_cv_repro
for scheme in geo2 geo1; do
  for variant in C G2; do
    python -m experiments.geo_group_cv.run fit --data data \
      --output outputs/geo_group_cv_repro --scheme "$scheme" --variant "$variant" \
      --code-commit 3ebe0f39f26d6151216ebd03d0d3f024a7bc29e5

# 제공된 비공개 실행 산출물을 재학습 없이 감사
python -m experiments.geo_group_cv.audit --data data \
  --output outputs/geo_group_cv_v1 --baseline /path/to/baseline_private \

```

### 결론의 확인 범위

이번 분할에서는 **지역을 이미 관찰한 상황의 랜덤 CV 점수가 새로운 지역에 그대로 유지되지 않는다**는 사실을 확인했다. 특히 미관측 상위 지역에서는 두 고정 LR 파이프라인 모두3등급 판별에 심각한 한계가 있다. 검증 목표가 새 지역 예측이라면 기존 랜덤 CV만으로 모델을 선택하는 것은 충분하지 않다.

그러나 동일2015년 지진 자료의 개발 데이터에 대한 탐색적 검증이다. 전체 지역의 새로운 무작위 표본이나 다른 지진, 공간 거리 버퍼, 시간적 변화, 인과적 지역 변수 효과를 검증하지 않았다. 지역 코드 제거/인코딩 대안과 다른 모델의 Group CV는 별도 사전 계획으로 다룰 후속 연구이며 이번에는 실행하지 않았다. 1차 지역 CV에서 모든 지역 원핫이0이 되는 표현상의 조건도 결과 해석에 포함해야 한다.
