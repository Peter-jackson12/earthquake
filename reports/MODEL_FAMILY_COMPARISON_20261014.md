# Earthquake — 모델 계열 A/C 비교 v1 완료 보고

2026-10-14 KST · 전용 브랜치 `peter-exp/model-family-comparison-v1`

## 1. 결론과 완료 범위

**XGBoost·LightGBM의 A/C 4설정×고정5Fold=20회 실학습 및 독립 검증을 완료했다. 이번 공통 원핫·고정 300 rounds 조건에서는 새 모델 모두 기존 LR보다 낮았다.** LR A/C는 기존 원시 OOF를 검증해 재사용했으며 재학습하지 않았다.

수치상 새 모델 최고는 LGBM-C **0.669847**, 전체 비교 최고는 기존 LR-C **0.688687**이다. 기존 LR C 연구 기준·최종 모델·앱을 교체하지 않는다. 새 모델에서 3→1이 감소했지만 3→2가 늘고 실제3등급 Recall은 낮아졌으므로 안전성 개선으로 해석하지 않는다.

이것은 해당 구현·입력 표현·고정 예산의 개발 CV 결과이며 XGBoost/LightGBM 계열의 한계나 다른 지진으로의 일반화 성능이 아니다. G1~G5와 결합하거나 비교 후보에 넣지 않았다.

## 4. A와 C의 효과는 모델마다 다르다

XGB의 C−A CV 평균 차이는 **+0.000611851**로5/5Fold 양수지만, 원본995 집단 F1은 **0.581824→0.567689**로 하락했다. 전체3→1은238→239이며, 원본995의 3→2는150→152다. 따라서 전체 점수가 소폭 올랐다는 이유로 C를 모든 집단에 유리한 정책으로 채택하지 않는다.

LGBM의 C−A CV 평균 차이는 **+0.000016951**에 불과하고 C가 높은 Fold는3/5다. 995 집단 F1은0.598201→0.613063으로 올랐지만 Recall3은58.99%→57.73%, 3→2는129→133으로 악화했다. 관측 점수가 매우 가깝다는 사실은 통계적 동등성을 입증하지 않는다.

## 6. 심각한 과소예측의 교체와 지역별 악화

## 7. 실행 비용·경고와 해석의 한계

| 모델 | 학습 Fold F1 평균 | 검증 F1 평균 | 5회 fit 초 | Python 경고 |
|---|---|---|---|---|
| XGB_A_v1 | 0.649907 | 0.637946 | 102.1 | 0 |
| XGB_C_v1 | 0.649816 | 0.638558 | 106.5 | 0 |
| LGBM_A_v1 | 0.681691 | 0.669830 | 95.1 | 10 |
| LGBM_C_v1 | 0.681544 | 0.669847 | 97.7 | 10 |

메모리는 실행 프로세스 누적 peak RSS 최대 **562.0 MiB**다. 실행시간은 관측치이며 통제된 하드웨어 벤치마크가 아니다. 인코딩·학습/검증 재예측·파일 저장·동시 테스트의 시간을 fit 초와 혼동하지 않는다.

신규 LGBM10fit에서 `X does not have valid feature names...` UserWarning이 각2개, 총20개 기록됐다. 생성된 이름과 희소행렬의 이름 부재에 대한 경고이며, 동일 행렬 SHA와 전체 native booster 재추론으로 예측 일치를 확인했다. 실제CV에 다른 Python 경고는 없었고 모든모델300rounds를 완료했다. 합성 테스트의 `No further splits` 출력과 실데이터 학습 경고를 구분한다.

두 모델의 학습 F1도 높지 않다는 관측은 현재 표현·용량·학습 예산 제약을 후속 가설로 검토할 이유다. 이를 원인으로 확정한 실험은 아니다. XGBoost는 CSR 미저장 원소를 missing으로, 이번 LightGBM은 `zero_as_missing=false`에 따라0으로 처리한다. 같은 CSR을 전달해도 이 의미 차이가 있어 결과를 순수한 트리 성장 방식만의 인과 효과로 부르지 않는다.

공식 기술 근거: [XGBoost3.1.3 FAQ](https://xgboost.readthedocs.io/en/release_3.1.0/faq.html), [LightGBM4.6 Advanced Topics](https://lightgbm.readthedocs.io/en/v4.6.0/Advanced-Topics.html), [LightGBM4.6 Parameters](https://lightgbm.readthedocs.io/en/v4.6.0/Parameters.html).

## 8. 독립 검증 및 보존

학습기는 sklearn 지표를, 감사기는 crosstab·직접 산식을 사용했다. 모든 모델의 ID/정답/Fold/확률/argmax/해시와 분모, 평균/표준편차/등급별 지표를 재계산했다. **6설정 OOF1,250,880행**, 새20모델 **833,920개 검증 예측** 재추론 일치. 최대 확률 차이는 **1.11e-16**였다. 학습용 범주 사전·중앙값·스케일러 평균·행렬 SHA도 재확인했다.

추가 `verify_aggregates.py`는 sklearn 지표와 별도3차원 전이표로 **모델6행·Fold30행·그룹/프로필282행·혼동행렬282개·전이27행**을 재대조해 PASS했다. 실제 집계값4종을 변조하고 체크섬까지 다시 만든 경우도 모두 거부했다. 이는 독립 계산·저장모델 재추론이며, 다른 환경에서 모델20개를 새로 학습한 재현 검증은 아니다.

관련 계약·회귀 테스트 **73개 통과**, 기본 위치의 비공개 데이터가 없는 기존통합테스트19개는 명시적건너뜀. 신규 v1 단위41개는73개에 포함되며 중복 합산하지 않는다. 추가 실제산출물 변조거부4개가 통과해 고유 완료pass는77개다. 변조검사 묶음은3개 완료후 명령실행시간 제한으로 중단되어 남은1개를 별도로 통과시켰다. 학습을 재실행한 것은 아니다. 컨테이너가 저장소 전체 clone이 아니므로 이 로컬묶음을 저장소 전체CI라고 부르지 않는다.

학습 전후 보호파일13개, 감사 전후 비공개증거54개 및 기존소스SHA가 보존됐다. 기존 A~F/G1~G5, 원본, LR C 연구후보, app.py, main/peter/상위age995브랜치에 변경하지 않는다. 원시CSV·행별OOF·모델은 공개Git에 포함하지 않는다.

## 9. 산출물과 다음 단계

공개Git에는 코드·설정·핵심집계·그룹별CM·compact 오류프로필·검증요약·이보고서만 남긴다. 전체 비반올림 감사CSV/모든 프로필CM/모델재추론20개 기록/로그는 전달용 코드·증거ZIP의 `full_audit/` 및 `evidence/`에 있다. compact프로필은 읽기용6자리반올림이며 실험선택·검증은 원값으로 수행했다. 원시OOF·모델·전처리기는 별도비공개ZIP이다. 전체감사파일 SHA는 [verification](model_families_v1/verification.json)에 있다.

다음에는 **native categorical로 범주형 표현만 분리해 바꾸는 고정 설정 v2 비교**를 우선 검토한다. 지역 코드를 연속 수치로 넣거나 현재 v1을 덮어쓰지 않는다. 더 큰 학습 예산과 native categorical을 동시에 바꾸면 원인을 분리할 수 없으므로 별도요인으로 둔다. 대량Optuna, E2, G1~G5 결합은 미실행이다. 성능향상은 보장되지 않는다.

**현재 결정: 기존 LR-C 연구 기준 유지. 이번 트리 v1은 검증된 비교 결과로 보존하며 최종 모델·팀 제출물·앱을 자동 교체하지 않는다.**
