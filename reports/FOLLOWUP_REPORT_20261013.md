# 후속 구현·불균형 비교 결과 — 2026-10-13

개인 `peter` 작업. 기반 HEAD `fa34c11a22d3a3a65f013a1a360dddb7f4f6754f`; `main`의 `41f287f184a4ed22c88c506ebdd8aa0c66e681d5`는 변경하지 않았다.
원본 재첨부와 이전 독립 감사 결과를 바탕으로 재현 코드·테스트를 보완하고 **신규 4개 설정 × 고정 5-Fold = 20회 학습**을 완료했다.
기존 8개 설정·40회 결과는 재학습하거나 숫자를 덮어쓰지 않았다. 보고상 전체는 12개 설정·60 Fold이며, 이 세션에서 학습한 것은 신규 20회다.

## 문제 정의와의 연결

2026-10-13 배경·목적 문구 논의에서 동의한 범위는 2015년 피해 등급 분류·평가, 관련 건물 특성의 분석, 클래스 불균형과 심한 피해 과소예측의 검토다. 아래 결과는 Macro F1과 3→1·3→2의 손익을 함께 보여주는 개인 분석 근거로 재사용한다. 단일 지진의 관측 연관성과 개발 OOF 성능이며 인과효과나 미래 지진·다른 지역의 검증 성능을 뜻하지 않는다. 향후 점검·내진 보강 우선순위에 적용하려면 지진 강도·지반 조건 등을 고려한 추가 검증이 필요하다.

배경·목적의 동의와 공통 분할·오류 비용 및 허용 기준·최종 모델·팀 역할의 결정은 구분한다. 이 보고서의 실험 결과나 완료 상태를 새로 변경하지 않으며, 후속 진행 범위는 [다음 단계 작업 범위](../docs/NEXT_STAGE_SCOPE_20261013.md)를 확인한다.

## 1. 보존 범위와 입력 확인

첨부 CSV SHA는 `87abd2bc2b05d3e687bd176959967fd38334fff607e6afeb2d20d0d899c13e97`로 기존 원본과 동일하다.
컬럼정의서의 40개 컬럼명·순서가 CSV와 같고 입력은 38개다. CSV의 UTF-8 BOM은 읽을 때만 처리했으며 원본 바이트는 변경하지 않았다.
전처리 v1.0.1, 개발 CSV SHA, Manifest SHA, seed 42, 기존 Fold, 원본 특수값을 보존했다.
개발 데이터 **208,480건**, Fold별 학습 166,784 / 검증 41,696건이다. 홀드아웃을 EDA·학습·선택·평가에 사용하지 않았다.
기존 체크섬 테스트가 홀드아웃 파일 바이트를 읽는 것은 포함되며, 정답을 모델과 결합해 평가한 것은 아니다.
80/20와 고정 5-Fold는 여전히 팀 최종 합의 전 잠정 기준이다.

## 2. 실제 추가 실험

| 설정                                  |   기존 CV Macro F1 |   신규 CV Macro F1 |      차이 |   신규 표준편차(ddof=1) |
|:--------------------------------------|-------------------:|-------------------:|----------:|------------------------:|
| DT balanced                           |           0.594238 |           0.59807  |  0.003832 |                0.00885  |
| RF balanced (max_features=0.1)        |           0.628992 |           0.647867 |  0.018876 |                0.000646 |

| LR RUS                                |           0.683677 |           0.646302 | -0.037375 |                0.000997 |

DT는 기존 DT, RF/GBC는 각각 후보 변수 수를 완화한 기존 설정, RUS는 무가중치 LR과 비교했다.
DT/RF는 class_weight 하나만, GBC는 학습 Fold의 sample_weight 전달만, LR은 학습 표본 선택만 바꿨다.
CV 평균과 pooled OOF F1을 구분하며, 기존 기준점은 이전 저장 집계의 독립 산술 검증 수준이다. 과거 OOF 부재라는 한계는 남아 있다.

## 3. RUS 적용 위치와 표본 손실
