## 입력과 모델의 비교 범위

원본38입력을 보존했다. 기존 C와 동일한 비995 연령 중앙값 대치(0 포함)·age995 표시·수치 스케일링·이진 처리를 각 outer-train에서만 학습했다. 수치5열·이진22열·연령 표시1열의 float32 값과 순서28열을 기존 C와 정확히 대조했다. 원핫 전체 행렬을 밀집화하지 않고 이28열만 직접 만들었다.

지역3열·문자범주8열, 총 범주11열의 정규화한 원래 문자열을 붙인 총39열 DataFrame이며 cat_features 위치28~38을 명시했다. 범주값의 수치 크기나 순서로 해석하지 않았다. 학습 때 없는 문자열도 그대로 전달한다. 검증 자료로 어휘·빈도·정답 통계를 학습하지 않았다.

T25와 같은 CatBoost1.2.10 CPU의 고정 생성 파라미터를 유지했다: iterations300, learning_rate0.05, depth6, l2_leaf_reg3, random_strength1, Bayesian bootstrap, bagging_temperature1, Plain boosting, SymmetricTree, MultiClass, classes_count3, random_seed42, thread_count2, task_typeCPU, allow_writing_files=False, verbose=False. 차이는 범주 입력과 cat_features 지정이며 활성화된 내부 범주 관련 기본값은 실제 get_all_params()와 버전에 결속했다.

내부 범주 통계·조합 처리는 outer-train과 해당 정답에서만 학습된다. 일부 통계의 순열 처리는 CatBoost 내부 알고리즘이며 검증 정답을 입력하는 절차가 아니다. outer-valid는 학습 뒤 예측에만 사용하고 fit/Pool/전처리에 검증 정답을 넘기지 않았다. 외부 가중치·재표집·SMOTENC·튜닝·eval_set·early stopping·사후 결정 규칙은 없다. 내부012→실제123 확률과 낮은 등급 argmax 동률 규칙을 확인했다.
