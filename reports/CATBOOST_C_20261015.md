## 입력·분류기·전용 실행 환경

원본 38개 입력과 기존 C 전처리를 그대로 유지했다. 각 outer-train에서 비995 연령의 중앙값(0 포함)으로 age995를 대치하고 표시 열을 추가하며, 수치 스케일링과 학습 어휘 기반 원핫을 적용한 float32 CSR을 사용했다. 추가 피처는0개이고 전체 희소행렬을 밀집화하지 않았다. 검증 정답과 검증 통계를 전처리 학습에 사용하지 않았다. CatBoost에 원시 범주형을 따로 지정하지 않았으므로 native categorical 처리의 비교가 아니다.

CatBoost1.2.10 CPU의 MultiClass, iterations300, learning_rate0.05, depth6, l2_leaf_reg3, random_strength1, Bayesian bootstrap, bagging_temperature1, Plain boosting, SymmetricTree, classes_count3, random_seed42, thread_count2를 고정했다. allow_writing_files=False, verbose=False이며 나머지 기본값도 버전과 실제 get_all_params()에 결속했다. Bayesian bootstrap은 모델 내부 학습 알고리즘이며 외부 증식·재표집을 의미하지 않는다. 외부 sample/class weight, ROS, eval_set, early stopping, 튜닝과 사후 결정 규칙은 없다. 내부 클래스012를 실제 등급123에 대응시켰고 argmax 동률은 낮은 등급이다.

기존 동결 Python3.13.5 환경을 변경하지 않고 T25 전용 vendor를 추가했다. 독립 감사는 환경 명세 SHA, vendor3,014파일·12개 추가 배포와 기존 배포 RECORD의 실제5,210파일, 실제 import 출처·버전을 검증하고 봉인된 runtime과 연결했다. 이 보고 생성기는 환경을 활성화하거나 패키지·모델을 로딩하지 않고 완료된 감사의 환경 검증 영수증과 명세 SHA를 대조한다. 명세 전체와 private 경로는 공개하지 않는다.

기준선은 T8/T13의 감사된 OOF를 재사용했고 신규 기준선 학습은0회다. 이전 연구의 피처·가중치·순서형 학습을 결합하지 않았다.

## 실행과 독립 감사

신규 학습은 단일 팔20개를 각1회 시도로 완료했다. 기준선 재학습·자동 및 수동 실패 재시도·별도 smoke fit은 없다. 학습시간 합계는 928.6초이며 전처리·저장·백업·감사·대기를 포함한 전체 경과시간과 다르다.

코드 커밋 `44cc9744d2d8418c9df9d2f20c321d8bc3029b08`, 설계 SHA `3d6b3fe1b1f751029bb27196a5121bcac27d7093e098a86eae00c33cdf9e8e96`, 원 집계 SHA `133060bb0d820cb4f37a6e60e11a78110c54e9ed79365e55ee9ebc80275b96cc`에 결속했다. 독립 감사 `PASS_T25`은 실행기 import·joblib 역직렬화·분류기 재학습 없이 동일 C 전처리를 별도로 재구성해 전체 CSR과 상태를 대조했다. native 모델20개 재추론의 최대 확률 절대차는 0로 등록 허용오차 1e-12 이내였다. 입력·분할·기준선·원본/백업 SHA와 모든 집계·판정을 확인했다. 과거 fit 호출의 실행 사실은 봉인된 소스와 원장에도 의존한다.

감사 영수증 SHA `13cfd79d308a3085c062ba0f375117dfb3d75ab62c09055e2c735f2e7a2bb2ee`. 비공개 영수증 파일명은 `t25_audit_result_v1.json`이며 감사 스크립트·T25 독립 코어·독립 runtime 검증기·재사용 T21 C/지표 helper·이전 private helper의 SHA는 동반 JSON에 기록했다. `fits`의20회 완료·시도1회와 `finalizations.analysis`의 단일 완료·집계 SHA·학습 종료 후 집계 시각을 확인했다. 준비 영수증 SHA 42752238d95c3fb4ac4fa50fa1624891c255ab0f5d0fa062ff8cdc09e3921e5d와 소스7개·감사9개·재사용 helper4개 및 작성자 합성 진단 메타데이터2개의 SHA도 대조했다. 준비 상태 READY_NOT_EXECUTED, 준비 합성 검사20개와 환경만 검증한 ENVIRONMENT_ONLY_PASS는 실제 PASS_T25와 구분한다. 작성자의 별도 합성4fit 진단 이력은 이번 실자료20fit에 포함하지 않는다.

native 상태에 포함된 **float 표현만** 절대차≤1e-7이면서 float32 변환값이 정확히 같을 때 허용했다. 키·자료형·문자열·정수·구조는 엄격히 대조했다. 이는 고정 파라미터와 상태의 직렬화 표현 기준이며 **예측 재로딩 절대차≤1e-12를 완화하지 않았다**. 초기 합성 상태 비교 실패와 수정 후 성공 증거는 별도로 보존했다.

환경 명세 SHA c67feaf2addb617dea50e2cf26a3757d0f1cab037add37611851893a5fbde6ef도 설계·준비·실제 감사·명세 파일 바이트에 결속했다. 모델·원시자료·OOF·전체 환경 manifest·private 경로·인코딩 열 이름·전처리 상태·CSR 배열은 공개 집계에 포함하지 않는다. 공개 보고서 검토·공통 문서·Git 및 원격 CI는 컨트롤 타워가 별도로 확인한다.

## 해석의 한계와 유지할 결정

단일 후속 가설을 탐색했고 이전 연구에서 같은 개발 자료와 분할을 반복 사용했다. 다중 탐색과 누적 선택 편향이 남으므로 평균·Fold·seed의 조건 충족을 새로운 독립 외부 성능이나 통계적 유의성으로 해석하지 않는다. 20개 Fold 결과와833,920개 신규 예측도 독립 관측 수가 아니다. 다른 지역·미래 지진의 성능, 인과 효과, 안전성을 확정하지 않는다.

이번 결과는 동일 C 입력에서의 모델 family 탐색 비교다. 깊이6 대칭 트리와 기준선의31 leaves 등 구조·용량·규제·내부 학습이 다르므로 차이를 알고리즘 이름 하나의 효과로 분리하지 않는다. 외부 원핫을 고정한 결과를 CatBoost의 원시 범주형 처리 결과나 모든 설정의 우월성으로 확대하지 않는다. 팀원 notebook은 분할·전처리가 달라 점수를 직접 비교하지 않는다. 다른 연구의 개선량과 합산하거나 중요도로 원인을 확정하지 않는다.

LR-C 연구 기준과 기존 개인 최종 모델을 유지한다. 홀드아웃 접근, 전체 개발 최종 fit, 최종 모델 변경은 수행하지 않았다.
