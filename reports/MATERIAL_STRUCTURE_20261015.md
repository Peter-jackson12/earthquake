## 피처와 비교 범위

- `MATERIAL_PAIRS`: 재료 표시값 11개의 모든 서로 다른 쌍(i<j)을 사전 고정 순서로 곱한 **55열**을 추가했다. 각 열은 원래 0/1 값의 동시출현이다. `has_superstructure_` 아래 재료 순서는 `adobe_mud`, `mud_mortar_stone`, `stone_flag`, `cement_mortar_stone`, `mud_mortar_brick`, `cement_mortar_brick`, `timber`, `bamboo`, `rc_non_engineered`, `rc_engineered`, `other`다. 정답·빈도로 쌍을 선택하거나 상수 열을 제거하지 않았다. 강도 순서나 검증된 취약도 의미를 부여하지 않는다.
- `STRUCTURE_FLOORS`: `foundation_type` 및 `other_floor_type` **각각의 원핫 × 원래 층수 `count_floors_pre_eq`**를 추가했다. 두 범주를 서로 교차한 복합범주가 아니며 열 수는 두 학습 어휘 크기의 합이다. 어휘는 outer-train에서만 학습하고 미관측 범주는 해당 블록 전체 0이다. 층수 0에서는 곱이 모두 0이다(합성 경계값으로 검증한 정의이며 실제 0층 관측을 주장하지 않는다). 문자 코드에 공학적 강도 순서를 부여하지 않는다.

두 추가 블록은 **스케일링하지 않고 float32 CSR**로 기존 C 뒤에 붙였다. 재료는 유한한 정확한 0/1, 층수는 유한한 비음수 정수, 범주는 결측 없는 문자열이라는 계약을 적용했다. 피처 계산은 y를 사용하지 않았다. 기존 C 블록의 연령 995 대치·표시·수치 스케일링·범주 인코딩은 그대로 유지했다.

두 팔은 각각 기존 38개 입력과 C 전처리를 유지하고 새 블록만 추가한다. 300 rounds, 31 leaves, 학습률 0.05와 내부 2스레드를 고정했다. 가중치·ROS·early stopping·튜닝·사후 결정 규칙은 없으며 argmax 동률은 낮은 등급이다. 기준선은 T8/T13의 감사된 OOF를 재사용했고 신규 기준선 학습은 0회다. T17/T18/T20/T21 또는 A+B를 결합하지 않았다.

## 해석의 한계와 유지할 결정

두 후보를 비교했고 이전 연구에서 같은 개발 자료와 분할을 반복 사용했다. 다중 탐색과 누적 선택 편향이 남으므로 평균·Fold·seed의 조건 충족을 새로운 독립 외부 성능이나 통계적 유의성으로 해석하지 않는다. 40개 Fold 결과와 1,667,840개 신규 예측도 독립 관측 수가 아니다. 다른 지역·미래 지진의 성능, 인과 효과, 안전성을 확정하지 않는다.

재료 팔은 55쌍 전체 묶음의 효과이며 개별 재료쌍의 기여를 분리하지 않는다. 구조 팔도 기초구조별 층수와 다른 층 바닥구조별 층수를 함께 추가한 묶음의 비교다. 재료쌍을 공학적 강도나 인과 효과로 해석하지 않고 피처 중요도만으로 개선 원인을 확정하지 않는다. 두 팔 중 좋은 결과만 고르거나 다른 연구의 특정 묶음 결과를 모든 피처엔지니어링의 우열로 일반화하지 않는다. 이 연구의 개선량을 T17/T18/T20/T21과 합산하지 않으며 A+B를 선택하지 않는다.

LR-C 연구 기준과 기존 개인 최종 모델을 유지한다. 홀드아웃 접근, 전체 개발 최종 fit, 최종 모델 변경은 수행하지 않았다.
