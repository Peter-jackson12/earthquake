# age995 후속 실험 D/E/F 완료 보고서

2026-10-13 · 개인 브랜치 `peter-exp/age995-outlier-treatment`

## 1. 결론과 완료 범위

**신규 D/E1/E2/E3/F1/F2의 6개 설정 × 고정 5-Fold = 30회 실제 학습과 독립 OOF 감사를 완료했다. A/B/C는 이전 출력 재사용이며 이번에 재학습하지 않았다.**

전체 CV 평균의 수치상 1위는 기존 **C(중앙값+표시, 0.688687)**이고 **E2(상한+표시, 0.688664)**는 사실상 근접한 대안이다. 차이는 **0.000023867**뿐이며 E2는 C보다 2/5 Fold에서 높았다. 이 차이로 우열·동등성·통계적 유의성을 확정하지 않는다. 기존 C를 개발 비교 기준으로 유지하고 E2를 대안으로 보존한다. 배포 모델이나 기존 최종 모델을 교체한 것이 아니다.

반면 D/F1/F2는 검증의 age995 **1,125건 전부를 3등급으로 예측**했다. 3등급 Recall 100%와 3→1 오류 0건은 1/2등급을 전혀 구분하지 못한 결과이므로 안전성 개선으로 해석하지 않는다. 더 넓게 삭제할수록 좋아진다는 근거도 얻지 못했다.

## 2. 데이터·검증 계약과 보존

LR은 C=1, lbfgs, max_iter=1500, tol=1e-4, random_state=42, 클래스 가중치·샘플링 없음으로 고정했다. 실제 실험 환경은 이전 A/B/C와 같은 Python 3.13.5 / numpy 2.3.5 / pandas 2.2.3 / scipy 1.17.0 / sklearn 1.8.0이고 1 thread를 사용했다.

원본 CSV는 바이트 해시만 확인했으며 전체 원본이나 홀드아웃으로 EDA·학습·선택을 하지 않았다. **홀드아웃 feature/label 파일은 압축 해제·읽기·평가하지 않았다.** split manifest의 홀드아웃 ID/-1 표시는 원래 분할 확인에 포함된다. 이전 결과·원본 코드·데이터 27개 보호 파일의 전후 SHA 일치를 확인했다.

E3는 995 1,125행 외에 비995 고령 건물 **1,998행**도 검증 표현을 바꿨다. 검증 행을 삭제했다는 뜻은 아니다. D/F의 검증 변환 0은 원값 그대로 예측했다는 뜻이다.

개발 데이터의 고유 제거 대상은 D=1,125, F1=12,953, F2=18,201행이다. 각 행이 학습에 4번 들어가므로 5개 학습 Fold의 제거 건수를 그대로 더해 고유 건물 수로 보고하지 않는다. F1 고유 제거 등급 분포는 315/7,815/4,823, F2는 1,952/10,515/5,734다.

FAITH 네 조건별 고유 대상은 age>55: 12,953, floors>5: 205, area>20: 3,641, height>10: 2,682다. 조건이 겹치므로 합계 19,481이 OR 합집합 18,201과 다르다. Fold별 개별 조건·등급·중복 수는 실행 기록과 독립 감사의 `criteria.csv`에 있다.

F2의 전체 학습 제거율은 8.68~8.81%인데 지역 코드 `geo_level_1_id=3`에서는 27.39~28.14%다. 모든 1차 지역은 남았으나 작은 지역 범주의 손실은 있다. D/F1/F2의 Fold별 소실 3차 지역 범주는 각각 16~22 / 98~110 / 114~128개이고, F2 중 학습 빈도<=5인 희귀 범주는 104~121개다. F2는 2차 지역도 Fold별 1~4개 소실했다. 검증에서 학습 때 보지 못한 3차 지역을 가진 행은 D +11~30, F1 +58~83, F2 +65~89행/Fold 증가했다. 지역 코드 자체를 실제 행정구역 이름으로 해석하지 않는다.

## 7. 독립 감사·테스트·실행 비용

학습기의 sklearn 평가 함수와 별도로 pandas crosstab 및 직접 산술로 혼동행렬·P/R/F1·CV 평균·표준편차를 재계산했다. 삭제 규칙과 선형 분위수도 별도 코드로 다시 계산했다. **9개 설정, 45개 Fold, 1,876,320개 행별 OOF 예측, 162개 그룹 혼동행렬**을 검증했다. 신규 예측은 1,250,880개, 과거 재사용 예측은 625,440개다. 이것은 고유 건물이 187만 개라는 뜻이 아니다.

OOF 해시·ID 유일성·정답·원래Fold·확률 범위/합/argmax, 원래 검증 분모, 학습 선택 ID hash와 등급 구성, 학습 통계·범주 수, 조건·지역 집계, 실효 모델 파라미터와 소스 SHA를 대조했다. 원시 OOF를 다시 생성하는 독립 모델 재학습이나 계수 분석은 하지 않았다. 훈련 예측을 별도 저장하지 않아 train F1은 독립 재계산 범위가 아니다.

신규 합성 안전성·손상 거부 테스트 **48개**, A/B/C·Fold·모델 회귀를 포함한 로컬 대상 테스트 **80개 모두 통과**, 실패/건너뜀 0이다. 실행·감사 코드 커밋 `206b66a`의 GitHub 전체 `unittest discover`는 **175개 중 146 통과, 29 건너뜀**, 실패 0이다. 29개는 비공개 전처리 19개·개발 통합 3개·UI 7개다. UI는 별도 Dashboard workflow에서 성공했다. CI는 실데이터 30회 학습을 대신하지 않으며, 기존 Dashboard 시험은 이전 공개 집계에 관한 것이지 신규 대시보드 기능을 추가한 것이 아니다.

실제 신규 30개 Fold에서 수렴 경고는 없었고 반복 수는 517~629였다. fit 시간 합계는 **508.29초**이며 변환·예측·감사·문서화 시간은 제외한다. 과거 A/B/C의 시간과 현재 D/E/F 시간을 엄밀한 성능 벤치마크로 비교하지 않는다.
