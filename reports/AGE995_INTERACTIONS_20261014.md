# 지역·기초구조·연령 조합 후속 실험 결과

2026-10-14 | `Peter-jackson12/earthquake` | `peter-exp/age995-outlier-treatment`

## 1. 완료 범위와 판단

**G1~G5의 5개 설정 × 고정 5-Fold = 25회 실제 Logistic Regression 학습과 독립 감사를 완료했다.** C는 이전 OOF를 재사용했으며, C 분류기를 다시 학습하지 않았다. 홀드아웃의 feature/label을 추출·읽기·평가하지 않았다.

**CV 평균 최고는 G2(0.690993), 기존 연구 기준은 C를 유지한다.** G2는 C보다 평균 F1이 0.002306 높고 5개 Fold 모두 개선됐지만, 실제 심각 피해를 경미로 예측하는 **3→1 오류가 452→478건**으로 증가했다. 995 집단 F1도 0.669477→0.658986으로 낮아졌다.

모든 신규 설정의 평균 F1은 C보다 높았으나, 모든 설정에서 전체 3→1 오류도 증가했다. 학습 전 계획에 정한 ‘평균 F1 개선 + 전체 3→1 증가 없음 + 995 집단 3→1 증가 없음’을 동시에 만족하는 후보는 없었다. 결과를 본 뒤 기준을 바꾸지 않았다. 이 보수적 연구 검토 규칙이 실제 피해 비용이나 운영 안전성을 대변하는 것은 아니다.

G2는 **성능 향상 후보**로 보존한다. 기존 `RESEARCH_CANDIDATE.json`, 최종 모델, 앱, main/peter에는 변경을 적용하지 않는다. ‘어떤 변수 조합이 전체 점수에 도움이 되는가’에는 근거가 생겼지만, ‘심각한 과소예측을 줄였는가’라는 이번 개선 목표는 달성하지 못했다.

## 2. 한 요소씩 비교한 설계

| 설정 | C에 추가한 입력 | 주 비교 |
|---|---|---|
| G1 | 원본 연령 구간 | C: 연령 범주 표현 추가 |
| G2 | G1 + 1차 지역×기초구조 | G1: 지역·구조 조합 |
| G3 | G1 + 1차 지역×연령 구간 | G1: 지역·연령 조합 |
| G4 | G1 + 기초구조×연령 구간 | G1: 구조·연령 조합 |
| G5 | G1 + 위 세 가지 2변수 조합 | G1 및 개별 조합: 결합 효과 |

지역은 `geo_level_1_id`, 구조는 `foundation_type`이다. 예를 들어 지역 코드와 기초구조 코드를 하나의 범주로 표현하지만, 이를 특정 피해 등급으로 강제 대응시키지는 않는다. 익명 코드의 실제 지명·공법도 추정하지 않았다.

연령 구간은 이전 진단에서 사용한 **0 / 1–10 / 11–20 / 21–30 / 31–50 / 51–100 / 101–994 / 995**로 고정했다. 추가 구간은 대체 전 원값에서 만들므로 995 건물이 15년 구간으로 들어가지 않는다. C의 수치형 연령은 계속 각 학습 Fold의 비995 중앙값(0 포함)으로 대체하며, 실제 중앙값은 모두15.0이었다. G1의995 범주와 기존 표시 변수의 정보 중복·규제 효과도 G1의 표현 변경에 포함된다.

모든 기존38개 입력과995 표시의 전처리 블록을 유지하고, 추가 희소 원핫 블록만 붙였다. 범주 사전은 학습 Fold에서만 배웠다. 처음 보는 조합은 추가 블록에서0으로 처리하지만 기존 C의 주효과 정보는 남는다. 특정 지역 예측 덮어쓰기, 행 삭제, 정답 인코딩, 클래스 가중치, 샘플링, 임계값 튜닝은 하지 않았다.

개발208,480행, Fold별 학습166,784행/검증41,696행, 기존 Stratified 5-Fold와 seed42를 유지했다. LR은 C=1, lbfgs, max_iter=1500, tol=1e-4, random_state=42로 고정했다. 원본 정수 입력 검증도 완화하지 않았다.

다음은 각 지역의3→1 **건수**다. 지역 내 비율은 해당 지역의 실제3등급 수로 나눈다.

G2에서 지역13은52→42건으로 줄었지만, 지역26은160→163건, 지역20은80→84건으로 늘었다. 세 지역 합계는292→289건으로3건 감소했으나, 나머지 지역 합계는160→189건으로29건 증가했다. 일부 진단 지역의 개선을 전체 개선으로 오해하면 안 된다.

모든31개1차 지역, 기초구조, 연령 구간의 결과를 전체 `profiles.csv`에 남겼다. 실제3등급 지원수가30미만인 집단은 작은 표본으로 표시했다. 지역·구조·연령은 서로 겹치는 절단면이므로 오류 수를 원인 기여도처럼 합산하지 않는다. 이 세 지역은 이전 개발 OOF에서 발견한 사후 진단 대상이지, 새로운 독립 검증 지역이 아니다.

| 설정   | 추가 원핫 열   |   최대 반복수 |   미관측 추가조합 노출 합계 |

‘미관측 추가조합 노출 합계’는 Fold·추가 블록별 검증 행 수의 합이다. 한 건물이 여러 추가 블록에서 처음 보는 조합에 해당할 수 있으므로 **고유 건물 수가 아니다**. 기존 C 블록의 열 수는 Fold별12,594/12,609/12,571/12,624/12,582개였으며, 추가 열만 붙였다. 모든 출력은CSR float32이고 전체 희소 행렬을dense로 바꾸지 않았다.

신규25개 Fold 모두 수렴했고 수렴 경고가 없었다. fit 시간 합계는 **510.75초**다. 전처리 일치 검사, 예측, 감사, 테스트, 문서화 시간은 제외한다. 테스트와의 동시 부하도 있어 이전 실험과 엄밀한 속도 벤치마크로 비교하지 않는다.

별도 감사기에서 직접 혼동행렬·P/R/F1 산술과 독립적으로 작성한 연령·조합 규칙을 사용했다. **C+G1~G5의1,250,880개 OOF,30개 Fold,108개 혼동행렬**이 검증을 통과했다. 고유 건물은208,480개이며, 신규 예측은1,042,400개다.

데이터·소스·OOF·모델 SHA, ID·정답·Fold·확률, 검증 분모, 학습 중앙값·스케일러·추가 사전·미관측 수·열 수를 확인했다. 감사기에서25개 저장 모델을 다시 로드해 전체 검증 Fold의 예측과 확률도 OOF에 대조했다. **독립 구현으로 모델을 다시 학습한 검증은 아니다.** train F1은 기록했으나 원시 훈련 예측을 저장하지 않아 독립 재계산 범위에서 제외했다.

신규 계약·손상 거부 테스트35개를 포함해, 기존age995 회귀125개와 추가Fold/모델15개, 총 **서로 다른 로컬 대상140개가 통과**했다. 실패·건너뜀은0이다. 실제G1 기록 복사본에 가한7개 전처리 손상도 모두 거부했다.

코드 커밋`86a854de`의 원격 전체 unittest는 **235개 중206개 통과,29개 건너뜀,실패0**이다. 건너뜀은 비공개 전처리19개·개발 통합3개·UI7개이며, UI는 별도 Dashboard 작업에서 성공했다. CI의 합성 검증과 실제 데이터25회 학습은 별개다. 최종 문서 커밋의CI는 전달 기록에서 구분한다.

## 7. 재현·보존과 한계

학습 실행기/설정은`109abd61e3ebf732e6f3be12b2544f7008f57c6c`, 감사/테스트는`86a854de22c8522b47987831a60b6500f6457e58`에 고정했다. 원격Git blob과 실제 실행 파일이 일치했다. 직접git clone은DNS 실패였으므로, 보관된 소스 스냅샷을 사용했으며 clone 성공으로 보고하지 않는다.

원본CSV·개발CSV·manifest의 SHA는 기존 계약과 일치했다. 원본CSV는 바이트 해시만 확인했으며 전체 원본을 EDA·학습에 넣지 않았다. 이전 소스·집계·개발 데이터 등83개 보호 파일이 전후 동일했다. 원본/이전 OOF/모델을 공개Git에 올리지 않고, 신규 원시OOF·모델도 사용자 보관용 비공개 패키지로 분리한다.

실제 환경은 Python3.13.5/numpy2.3.5/pandas2.2.3/scipy1.17.0/sklearn1.8.0으로 C와 같다. 학습은단일 스레드다. 재학습 없이 검토하려면 [README](../experiments/age995/interactions/README.md)의 감사 명령을 사용한다. 전체 Fold·집단·지역·구조·연령·커버리지·전이 집계와 실행 로그는 증거 패키지에 있다.

이번 조합은 이미 관찰한 개발 오류에 기반한 **탐색적 후속 연구**다. 동일 개발CV를 반복 사용한 선택 편향의 한계가 남으며, 통계적 유의성·새 독립 최종성능·다른 지진으로의 일반화·운영 안전성을 주장하지 않는다.995의 공식 의미도 이번 실험으로 확정되지 않는다.

**결론: C를 연구 기준으로 유지하고, G2를 전체 성능 향상 후보로 보존한다. 지역·구조 조합의 점수 개선 근거는 얻었지만, 심각한 과소예측까지 줄이는 개선안으로 채택하지 않는다.**
