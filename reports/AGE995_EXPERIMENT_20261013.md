# age=995 전처리 A/B/C 1차 비교 — 2026-10-13

개인 후속 개발 CV 연구. 브랜치 `peter-exp/age995-outlier-treatment`, 시작 커밋 `03111b802a9ceebe93a52083f2c9413ce0dc322a`. 실행 전 범위는 `5272c4d978c2c9525670bbfb72e83e400fee91fc`에서 고정했다.
요청한 `peter/exp/...`는 기존 `peter` ref와 충돌하여 거절됐다. 기존 main/peter를 변경하거나 삭제하지 않고 별도 이름으로 생성했다.

## 1. 범위와 직접 참고

저장된 [995 참고자료 4건](../docs/AGE_995_REFERENCE_NOTES_KO.md)의 A/B/C 제안을 실행했다. 4건은 학술 논문만이 아니라 공개 프로젝트·작성자 글도 포함한다.
직접 채택한 처리 아이디어는 [Sahil Ali app.py](https://github.com/sahilali09/earthquake-damage-prediction/blob/main/app.py)의 표시 변수 생성 → 995를 NaN으로 치환 → 대체 방식이다. 확인한 app.py blob은 `81ed226d001bcfba10de6392671fd407ec9471b4`다. 앱의 15.0 하드코딩을 복사하지 않고 각 학습 Fold에서 비995 중앙값을 계산했다. 이번에 notebook 본문은 재조회되지 않아 notebook의 내부 실행 순서는 재검증한 것으로 주장하지 않는다.

| 조건 | 연령 처리 | 원본 입력/파생 입력 |
|---|---|---|
| A | v1.0.1 원값 그대로 | 38 / 38 |
| B | 원값 그대로 + age_is_995 | 38 / 39 |
| C | 995만 학습 Fold 중앙값으로 대체 + age_is_995 | 38 / 39 |

행 삭제 0건. age=0, 비995 연령, 층수·높이·면적·지역 등 나머지 원본 정보는 유지했다. `995`가 공식 결측 코드나 실제 995년이라는 판단은 하지 않는다. 가중치·ROS/RUS·SMOTE·Isolation Forest는 이번 실험에 사용하지 않았다. FAITH의 넓은 범위 삭제도 미실행이다.

## 2. 고정 조건과 누수 방지

개발 208,480건, 기존 5-Fold/seed=42. 매 Fold 학습 166,784건, 검증 41,696건. 무가중치 LR C=1, lbfgs, max_iter=1500, tol=1e-4를 고정했다. 데이터/Manifest의 계약 SHA는 작업 전후 일치했다.

원본 v1.0.1 스키마 검증 → 별도 age 변환 → 기존 수치 스케일링·원핫 인코딩 → LR 순서다. 중앙값·스케일러·인코더는 학습 Fold에서만 fit한다. C의 중앙값 계산에는 age=995만 제외하고 age=0은 포함한다. 실제 5개 Fold 중앙값은 모두 **15.0**이었다. 원본 파일의 995를 덮어쓴 것이 아니라 모델에 들어갈 복사본만 변환한다.

모든 전처리 출력은 float32 CSR이다. B/C의 열 수는 Fold별 12,594 / 12,609 / 12,571 / 12,624 / 12,582로 기준선보다 표시 1열만 추가됐다. 검증 transform 전후 학습된 평균·범주가 불변인지 검사했다. 일반적인 분할에서 중앙값이 비정수가 되는 경우도 실험 내부에서 지원하며 원본 정수 계약을 완화하지 않는다.

A는 기존 `lr_c1_confirmation`의 재현 OOF를 재사용했다. 원래 과거 OOF를 새로 복구했다고 주장하지 않는다. 데이터 계약·코드 SHA·실효 파라미터·실행 Manifest·ID·Fold·정답·확률·OOF checksum 및 기존 지표를 다시 대조했다. 이번 신규 실데이터 학습은 B/C의 **2개 설정 × 5-Fold = 10회**다.

## 3. 전체 성능

| 조건 | CV Macro F1 평균 | 표준편차(ddof=1) | pooled OOF F1 | A 대비 | 3→1 | 3→2 |
|---|---:|---:|---:|---:|---:|---:|
| A 원값 유지 | 0.683677 | 0.001071 | 0.683680 | 기준 | 467 | 24,761 |
| B 표시만 추가 | 0.687129 | 0.001455 | 0.687140 | +0.003452 | 438 | 24,693 |
| C 중앙값+표시 | **0.688687** | 0.001508 | 0.688695 | **+0.005010** | 452 | 24,681 |

B와 C는 각각 A보다 **5/5 Fold 모두 높았고**, C도 B보다 **5/5 Fold 모두 높았다**. C-B 평균 차이는 +0.001559다. Fold 표준편차와 상승 횟수는 통계적 유의성이나 독립 최종 평가를 뜻하지 않는다.
전역 3→1/3→2 비율의 분모는 실제 3등급 69,774건이다. C는 A보다 두 오류가 모두 줄었지만 B보다는 3→1이 14건 많다. 전체 점수 한 개만으로 모든 오류가 개선됐다고 해석하지 않는다.

## 4. age995 집단의 손익

개발 데이터 age995는 **1,125건**(1/2/3등급 147/661/317), 비995는 207,355건이다. 집단은 대체 후 값이 아니라 **원본 age**로 나눴다.

| 원본 age995 집단 | A | B | C |
|---|---:|---:|---:|
| pooled Macro F1 | 0.628555 | 0.650227 | **0.669477** |
| 1등급 Recall | 25.17% | 34.01% | **40.82%** |
| 3등급 Recall | **68.45%** | 63.09% | 62.78% |
| 3→1 건수 / 실제 3등급 317건 | **1** | 3 | 5 |
| 3→2 건수 / 실제 3등급 317건 | **99** | 114 | 113 |

C는 이 집단의 Macro F1과 1등급 Recall을 높였지만 3등급 Recall은 낮아졌다. 3→1은 0.32% → 1.58%로 늘었다. 표본이 작은 집단의 개별 오류 변화는 제한적으로 해석한다. 비995 집단의 pooled Macro F1도 A 0.683995 → B 0.687377 → C 0.688833으로 증가했다.

## 5. 검증과 재현

- 신규 테스트 17개 + 기존 Fold 검사 7개 + 기존 모델링 검사 8개 = **선택한 32개 테스트 통과, skip 0**. 전체 저장소의 모든 테스트를 로컬에서 실행했다는 뜻은 아니다.
- 신규 실제 학습 10개 모두 수렴 경고 0개. B 반복 수 538/590/558/524/528, C 578/563/520/598/578. 모두 기존 최대 1,500회 미만이다.
- B fit 합계 129.01초, C 112.89초. 테스트와 작업 부하가 일부 겹쳐 엄밀한 속도 벤치마크는 아니다.
- 3개 설정 **625,440개 OOF 기록**, 15개 Fold 혼동행렬, 9개 집단 집계를 검증했다. 별도 audit.py의 pandas crosstab과 직접 지표 공식으로 재계산해 저장된 sklearn 지표와 일치했다.
- Git clone은 이 환경의 DNS 실패로 되지 않았다. 실행에 사용한 공통 소스는 기존 전달물에서 가져온 뒤 현재 parent의 Git blob과 일치함을 확인했다. 원격 checkout에서 직접 실행했다고 주장하지 않는다.
- 코드·학습 입력 및 기존 성능 집계는 수정하지 않았다. 새로운 실험과 집계만 별도 추가한다. 공개 Git에는 행별 예측·라벨·모델을 넣지 않는다.

## 6. 판단과 미실행 범위

이번 동일 조건에서는 **C를 후속 개발 비교의 우선 후보**로 유지한다. 이것은 995의 의미가 밝혀졌거나 이전 최종 모델이 교체됐다는 뜻이 아니다. 표시와 연령 스케일 표현이 달라져 정규화된 LR에 미치는 영향도 함께 바뀐 실험이다.

훈련행 삭제, 상한절단, 구간화, Isolation Forest, 논문 전체 전처리 재현은 아직 하지 않았다. 먼저 연령 표현만 바꾼 이 기준을 남긴다. 이전 홀드아웃 결과는 이미 노출됐으며 이번 선택·비교에 다시 사용하지 않았다. 학습 코드에서 홀드아웃 feature/label을 읽거나 평가하지 않았다. 새 독립 테스트 성능이나 실무 안전 판정을 주장하지 않는다.

main/peter의 기존 결과·최종 후보·대시보드는 이번 실험으로 교체하지 않는다. 이 브랜치의 app.py는 이전 개인 결과 화면이며 age995 결과 화면을 새로 통합한 것이 아니다.
