# 저장된 OOF 기반 오류 분석 — 2026-10-13

**새 학습 없음.** `peter`의 기존 `outputs/baseline_full_v1/`, `outputs/feature_budget_v1/`, `outputs/lr_balanced_v1/`의 **개발 데이터 208,480건 OOF 예측**을 읽어 집계했다. 최종 홀드아웃 52,121건은 사용하지 않았다.

- `y_true`와 개발 CSV의 `damage_grade`를 `building_id`로 1:1 대조
- 혼동행렬 행 = 실제 피해 등급, 열 = 예측 피해 등급, 순서 = 1·2·3
- 3→1/3→2의 비율 **분모는 실제 3등급 69,774건**
- `CV Macro F1`은 5개 Fold 점수의 평균; 등급별 F1·오류 건수는 전체 OOF를 모아 계산. 두 집계를 혼동하지 않는다.

## 1. 초기 네 모델 비교

| 모델 / 설정 | CV Macro F1 | 3→1 건수 | 3→2 건수 | 3등급 Recall |
|---|---:|---:|---:|---:|
| LR 기본 | 0.683677 | 467 | 24,761 | 63.84% |
| DT 초기 | 0.594238 | 165 | 33,626 | 51.57% |
| RF 초기 (`max_features=sqrt`) | 0.357704 | 2 | 61,238 | 12.23% |
| GBC 초기 (`max_features=sqrt`) | 0.469489 | 47 | 52,017 | 25.38% |
| RF 후보 변수 수 완화 (`0.1`) | 0.628992 | 187 | 35,420 | 48.97% |
| GBC 후보 변수 수 완화 (`None`) | 0.612109 | 220 | 33,579 | 51.56% |

초기 RF·GBC가 3→1을 거의 하지 않은 것은 피해를 잘 알아본다는 증거가 아니다. 대부분의 3등급을 **2등급으로 예측**한 결과이고, 3등급 Recall이 각각 12.23%/25.38%에 불과하다. `max_features` 하나를 완화하면 RF 0.3577→0.6290, GBC 0.4695→0.6121로 개선됐다. 이는 **초기 계산량 제한 설정의 효과**이며 해당 모델 계열의 최종 우열을 뜻하지 않는다.

## 2. LR 가중치 적용 전후: 득실

| 지표 | LR 기본 | LR `class_weight=balanced` | 해석 |
|---|---:|---:|---|
| CV Macro F1 | **0.683677** | 0.665166 | -0.018511 |
| 1등급 Recall | 50.54% | **83.73%** | 소수 등급을 더 자주 발견 |
| 1등급 Precision | **66.09%** | 43.95% | 잘못된 1등급 예측 증가 |
| 1등급 F1 (OOF) | 0.572822 | 0.576390 | 거의 비슷 |
| 2등급 F1 (OOF) | **0.788279** | 0.710546 | 상당한 손실 |
| 3등급 F1 (OOF) | 0.689940 | **0.708563** | 개선 |
| 3등급 Recall | 63.84% | **74.20%** | 개선 |
| 3→1 오류 | **467건 (0.67%)** | 2,445건 (3.50%) | **1,978건 증가** |

**해석:** 가중치로 1·3등급 Recall이 높아졌지만, 2등급 성능이 악화되고 심한 피해를 경미한 피해로 낮춰 예측하는 **3→1 위험**이 상승했다. 이번 `balanced` 설정은 Macro F1 기준 개선안으로 채택하지 않는다. 이는 가중치 전체나 다른 모델의 모든 불균형 처리 방식을 부정하는 결론은 아니다.

## 3. 지역별 오류 집중: 코드 26

개발 데이터에서 지역 코드 **26의 실제 3등급 건물은 1,532건**이다.

| 해당 지역의 실제 3등급에서 | LR 기본 | LR balanced |
|---|---:|---:|
| 3→1 | 177건 (11.55%) | **632건 (41.25%)** |
| 3→2 | 1,222건 (79.77%) | 691건 (45.10%) |
| 3→3 정답 | 133건 (8.68%) | 209건 (13.64%) |

지역 26은 전체적으로 3등급이 8.49%(n=18,038)인 지역이다. 높은 3→1 비율은 지역별 피해 분포와 모델 예측의 연관성을 시사하지만, **그 원인이 지역 코드 그 자체라고 단정할 수 없다.** 구조·연령·하위 지역 등 다른 변수의 구성도 다를 수 있다.

반면 지역 17은 실제 3등급 14,013건 중 LR 기본의 3→2가 447건(3.19%), 3→1이 10건(0.07%)으로 매우 다른 오류 양상을 보인다. 이 차이는 추후 **미관측 지역 검증** 필요성을 뒷받침하지만, 랜덤 5-Fold 성능을 지역 외삽 성능으로 바꿔 해석할 수는 없다.
