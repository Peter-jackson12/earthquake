# age995 D/E/F 후속 실험 — 실데이터 학습 전 동결

2026-10-13. 대상은 `peter-exp/age995-outlier-treatment`만이다. 시작 HEAD는 `6deae3ee71982c84b2f1de7bb42b30718152042d`. A/B/C와 기존 v1.0.1 코드는 바꾸지 않는다.

## 고정 정책

- D: 학습 Fold의 age==995만 제거한다. 검증 행에는 적용하지 않는다. A와 비교한다.
- E1: 학습 Fold의 **비995 연령(0 포함)의 99백분위수, linear 보간**을 상한으로 계산해 995만 바꾼다. 표시 없이 A와 비교한다.
- E2: E1과 같은 상한에 원본 age==995 표시를 추가한다. B 대비 변환 효과를 비교한다.
- E3: E1과 같은 비995 분포·99백분위수 상한으로 모든 초과 연령을 절단한다. 표시 없이 E1 대비 정상 고령 연령까지 처리한 영향을 분리한다.
- F1: 학습 Fold의 age>55만 제거한다.
- F2: 학습 Fold에서 age>55, count_floors_pre_eq>5, area_percentage>20, height_percentage>10의 **합집합(OR)**을 제거한다. F1 대비 추가 조건의 결합 효과다.

D/E를 먼저 완료한다. F는 이후 독립 ID로 실행한다. 상한 분위수 후보 탐색이나 결과를 본 뒤 상한 변경은 하지 않는다. 모든 삭제 기준은 라벨을 사용하지 않으며 검증의 995·고령·높이 이상치 등은 전부 평가에 남긴다. 학습 행 삭제 후 인코더와 스케일러도 **남은 학습 행에서만** fit한다.

전처리 순서는 원본 정수 검증 → 별도 복사본 age 변환 → 기존 float32 수치 스케일링·희소 원핫 → 고정 LR이다. E2만 표시 1열을 추가한다. C의 중앙값 처리와 마찬가지로 비정수 분위수는 내부 복사본에서만 허용한다.

## 검증 계약

개발 CSV 208,480건·원본 입력 38개·기존 저장 Stratified 5-Fold·seed 42를 사용한다. LR은 C=1, lbfgs, max_iter=1500, tol=1e-4, random_state=42, 가중치·샘플링 없음이다. CV 평균과 표준편차(ddof=1), pooled OOF, 1/2/3등급 P/R/F1, 원시·행 정규화 혼동행렬, 3→1/3→2 오류를 전체/원본995/비995에 기록한다.

삭제·변환 수, 원래/잔존 등급 구성, 조건별 제거 대상과 중복, 지역 구성 변화, 희귀 범주(학습 빈도<=5) 소실, 검증 미관측 범주 증가도 집계한다. 학습 ID hash와 OOF checksum은 공개 가능하지만 원시 CSV·ID별 라벨/예측·모델은 공개 Git에 올리지 않는다.

기존 Library의 원본·개발·manifest SHA가 인계와 일치했고 A/B/C 625,440개 OOF를 별도 crosstab/직접 F1 계산으로 검증했다. 기존 수치는 재학습 결과가 아니라 재사용이다. 현재 Python/numpy/pandas/scipy/sklearn 환경도 기존과 일치한다. 후속 구현의 합성 안전성 테스트 27개가 통과했으며 합성 성능은 실제 비교표에 넣지 않는다.

각 설정은 followup_v1.json의 고유 ID와 별도 출력 폴더를 사용한다. 존재하는 설정 폴더는 덮어쓰지 않는다. 신규 원시 OOF는 학습 코드와 다른 직접 혼동행렬 산술로 다시 검증한다. 검증 코드에서 삭제 실험의 학습 건수와 **변하지 않은 검증 분모**를 구분한다.
