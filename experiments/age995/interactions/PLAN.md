## 목적과 사전 비교

995 대체값은 더 탐색하지 않는다. C의 모든 입력·전처리를 그대로 유지하면서 저차원 조합을 추가한다. 지역26/20/13의 오류를 본 뒤 만든 **탐색적 개발CV 연구**이며 새 독립 검증이라고 부르지 않는다. 특정 지역의 예측을 강제 변경하거나 오류 행을 삭제하지 않는다.

| 설정 | C에 추가하는 변수 | 주 비교 |
|---|---|---|
| G1 | 원본 연령 구간 | C: 연령 범주 표현의 추가 효과 |
| G2 | G1 + geo_level_1_id × foundation_type | G1: 지역·구조 상호작용 |
| G3 | G1 + geo_level_1_id × 원본 연령 구간 | G1: 지역·연령 상호작용 |
| G4 | G1 + foundation_type × 원본 연령 구간 | G1: 구조·연령 상호작용 |
| G5 | G1 + 위 세 가지 2변수 조합 모두 | G1 및 G2/G3/G4: 결합 효과 |

5설정×고정5Fold=25회 신규 학습이다. C를 다시 학습하지 않고 SHA·ID·정답·Fold·확률·파라미터·환경·지표 검증 후 재사용한다. 추가 분위수, 구조 변수 후보 탐색, 3중 교차, 클래스 가중치·오버샘플링·임계값 튜닝·새 모델 계열은 범위 밖이다.

연령 구간은 이전 진단의 0 / 1–10 / 11–20 / 21–30 / 31–50 / 51–100 / 101–994 / 995를 그대로 사전 고정한다. 연령 구간은 중앙값 대체 **이전 원값**에서 만든다. C의 수치형 연령은 계속 학습 Fold의 비995 중앙값으로 대체한다. G1에 들어간995 범주와 기존 표시 변수의 정보 중복 및 규제 효과도 G1 표현 변경에 포함되므로 순수한 비선형성 효과만 입증했다고 쓰지 않는다.

조합은 모든 지역·구조에 동일하게 적용하고 각 학습 Fold에서만 원핫 사전을 fit한다. 희귀 조합을 삭제하거나 정답으로 합치지 않는다. 미관측 조합은 해당 추가 블록에서 0으로 처리하며 기존 C의 주효과 정보는 남는다. 모든 기존38개 입력과995 표시의 인코딩 블록을 정확히 유지한 CSR float32 행렬에 새 블록을 붙인다.

## 평가·검증

개발208,480행·학습166,784행/검증41,696행·원래 Stratified 5Fold·seed42를 보존한다. LR C=1, lbfgs, max_iter=1500, tol=1e-4, random_state42 고정. 모델/스케일러/중앙값/원핫 사전은 학습 Fold에서만 fit한다. 각 Fold에서 기존 C 전처리 블록과의 일치, 사전·통계 불변, 행 보존, 미관측 조합 수, 수렴·반복수·비용, 저장 모델 전체 검증Fold 재추론 일치를 확인한다.

CV 평균·표준편차(ddof1), pooled OOF, 전체/원본995/비995 등급별P/R/F1·혼동행렬,3→1/3→2, 모든1차지역·기초구조·연령구간별 오류를 기록한다. 지역26/20/13은 진단용으로 따로 확인하되 지역별 실제3등급 분모와 작은 표본을 함께 표시한다. C 대비 기존3→1 수정/신규/잔존을 분리한다.

추천 검토 순서: 수렴·무결성 통과 → C보다 CV평균 개선 → 전체3→1과995집단3→1이 각각 C보다 늘지 않는 후보를 우선 → 그 안에서 CV평균이 높은 후보를 후속 실험 후보로 제시한다. 조건을 만족하는 후보가 없으면 C를 유지하며 성능/오류 tradeoff만 보고한다. 지역별 악화는 숨기지 않고 별도 검토한다. 이는 연구용 보수적 검토 규칙이지 사용자 합의된 실제 피해 비용 또는 운영 안전 인증이 아니다. 실험 실행 중 기준을 바꾸지 않는다. 기존 연구 기준 파일·최종 모델·앱은 자동 교체하지 않는다.

분석기는 학습 지표 함수를 재호출하지 않고 원시 OOF에서 혼동행렬과F1을 재계산한다. 원시 OOF·모델은 비공개 보관, 공개 Git에는 코드·검토된 집계·보고서만 넣는다. 홀드아웃 feature/label은 추출·읽기·재평가하지 않는다. 원본·기존 결과 바이트를 보존한다.
