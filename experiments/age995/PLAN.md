## 이번 범위

저장된 `docs/AGE_995_REFERENCE_NOTES_KO.md`의 A/B/C 제안을 먼저 실행한다.

| 조건 | 처리 | 목적 |
|---|---|---|
| A | v1.0.1 원값 유지 | 동일 조건 기준점 |
| B | age 원값 유지 + age_is_995 이진 표시 | 표시 변수의 효과 분리 |
| C | 학습 Fold의 비995 연령 중앙값으로 995만 대체 + 동일 표시 | 수치 표현 변경의 효과 확인 |

무가중치 LR, C=1, lbfgs, max_iter=1500, tol=1e-4, random_state=42를 고정한다. 개발 208,480건, 기존 저장 5-Fold, Macro F1을 사용한다. 샘플링·가중치·지역 인코딩·다른 이상치 처리는 추가하지 않는다.
원본 38개 입력은 보존하고 B/C에서만 파생 표시 1개를 추가한다. age=0도 보존한다. 행 삭제는 하지 않으며 995를 공식 결측 코드라고 단정하지 않는다.

## 구현 및 검증

원본 검증기는 변경하지 않는다. 원본 스키마 검증 다음에 별도 age 변환을 넣고 기존 인코더·스케일러를 학습 Fold에서 fit한다. 중앙값 계산에는 995만 제외하고 0을 포함한다. 실수 중앙값도 실험 내부에서만 허용하며 원본을 반올림하지 않는다. 검증 Fold에는 transform만 적용한다.
A는 기존 개인 완료 증거의 동일 LR 재현 OOF를 데이터·코드 해시, 모델 파라미터, ID/Fold/정답/확률 검증 후 재사용한다. 근거 검증이 실패하면 재사용하지 않는다. B/C는 10개 Fold 학습이며 신규 하이퍼파라미터 탐색은 없다.
CV 평균/표준편차(ddof=1), pooled OOF, 등급별 P/R/F1, 3→1/3→2, 995·비995 그룹, 수렴 경고, 시간, 중앙값과 원시 OOF 체크섬을 기록한다. 원시 예측은 공개 Git에 올리지 않는다.

## 참고와 미실행
