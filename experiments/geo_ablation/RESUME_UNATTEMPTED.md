# T6 미시도 Fold 보완 계획 — 추가 결과 확인 전 고정

원래 실행의 `audit_available`은 43시도/42완료/1중단/2미시도를 검증했다. 이 기록과 모든 파일을 그대로 보존한다. 아래 보완은 **아직 한 번도 시도하지 않은** Stratified/R12 Fold3/4만 대상으로 한다. 중단 Fold2와 완료된44개 이하의 어떤 Fold도 재학습하지 않는다.

- 기존 모델·전처리·입력·정답·분할·seed·단일 스레드·평가 공식 변경 없음.
- `complete_unattempted.py`는 원래 `run.verify()`/`make_pipeline('R12')`를 사용한다. 원래 결과 폴더는 쓰지 않고 별도 `outputs/geo_ablation_unattempted_v1`에만 저장한다.
- 보완 코드와 원래 코드 SHA, 원래 전체 증거 SHA 목록, 실행 환경과 목표 Fold[3,4]를 보완 학습 전에 다시 봉인한다.
- 정확히2번만 새로 fit한다. 기존43시도와 합쳐 **최대45시도**이다. 성공하면44완료/1중단/0미시도가 되며,45완료라고 보고하지 않는다. 재시도 없음.
- 저장된 두 모델 전체 검증행 재로딩, 원래 C 전처리 행렬의 지역 제외 열 투영과 전체 학습/검증행 일치, 제거 지역값 변경 불변, train-only 통계, ID/정답/Fold/확률과 독립 산술을 추가 감사한다. C 전처리-only fit2회는 C 분류기 학습이 아니다.
- 이미 검증된42개 모델과8개 완결 비교는 다시 fit하지 않는다. 기존 감사42 + 보완 감사2의 범위를 명시한다.
- Fold2가 없으므로 Stratified/R12의 전체5Fold 평균/SD/pooled 결과는 여전히 미완료다.4Fold를5Fold 결과로 바꾸어 표시하지 않는다.

원래 사전 계획45개 중 미시도2개를 완료하는 운영상 보완이며, 성능에 따른 모델/분할 변경이 아니다. 최종 상태는 원래 `EXECUTION_DEVIATION.md`와 보완의 실제 `audit.json`을 함께 읽는다. 기존 문서의42완료 수치는 보완 전 스냅샷이다.
