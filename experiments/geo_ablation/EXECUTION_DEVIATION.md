첫 `stratified/R12` 실행의 Fold0/1은 수렴·저장·전체 검증행 재로딩을 완료했다. Fold2 실행 중 컨테이너 호출이 약45초의 실행 제한으로 종료됐다(요청 timeout=200000ms에도 종료). 잔존 프로세스/중간 모델 체크포인트는 없었다. 원본 metadata는 attempted=3/completed=2/status=running인 마지막 기록을 그대로 보존했다. 이 상태는 실행 중임을 뜻하는 현재 상태가 아니라 **도구에 의해 중단된 당시의 기록**이다. 별도 `execution_interruption.json`이 현재 상태를 설명한다.

- 완료 Fold0/1: 보존, 재학습 없음.
- Fold2: 학습 시도 중단. 성능·수렴·완료를 주장하지 않음.
- Fold3/4: 해당 구성의 중단 뒤 미시도. 누락값을 보간·추정하지 않음.
- `stratified/R12`의 5-Fold 평균/SD/pooled OOF 성능은 **미완료**로 표시.
- 나머지8개 독립 구성은 동일한 동결 실행기를 호출하되 도구 호출 수명에 학습 프로세스가 잘리지 않도록 현재 세션에서 프로세스를 관리·확인한다. 모델/분할/피처/하이퍼파라미터/실행 순서·스레드 수는 변경하지 않는다. 재시도는 하지 않는다.
- 가능한 최종 범위는 신규43시도 중42완료/1중단, 원래45계획 중2미시도. 전부 성공한45회 연구라고 보고하지 않는다. 다른 실패가 생기면 이 범위도 완료라고 표시하지 않는다.

## 감사·보고의 분리

원래 `run.py`, `audit.py`, `config.json`, `design.json`/seal과 모든 기존 출력 바이트를 보존한다. 완결45회를 요구하는 원래 감사의 PASS 조건을 느슨하게 바꾸지 않는다.

새 `audit_available.py`는 오직 위의 정확한 중단 패턴을 허용하며, 나머지8개 구성 각각5Fold 완료와42개 저장 모델 전체 검증행/입력행렬 검사를 요구한다. 모델 재학습 없음. 기존과 독립된 혼동행렬 산술로 지표를 재계산한다. 부분2Fold는 따로 기록하며 전체 성능 표에 합치지 않는다. `PARTIAL_PASS_AVAILABLE_EVIDENCE`, `complete_study=false`를 결과에 명시한다. 이 감사 파일은 실행 도구 문제에 대한 사후 추가 파일이며 **학습 전 동결 코드인 것처럼 주장하지 않는다**. 감사 코드 SHA를 별도로 남긴다.

운영 방법의 변경은 모델 개선 실험이 아니다. 미완료 R12 랜덤 CV 때문에 geo3 제거의 전체 랜덤 성능 손실은 확정할 수 없다. R1/R0 및 두 Group CV에서 완결된 비교의 근거까지 폐기할 필요는 없으므로 검증 가능한 결과와 미완료 부분을 구분해 전달한다.
