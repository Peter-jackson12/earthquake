# 건물 특징을 활용한 지진 피해 등급 예측

건물의 위치·구조·재료 정보로 지진 피해 등급을 분류하고, 클래스 불균형 처리 전후의 성능과 오류 변화를 비교하는 팀 프로젝트입니다.

2015년 네팔 지진의 건물 피해 데이터를 바탕으로 세 등급의 예측 성능을 분석합니다. 현재 프로젝트 진행 중이며 최종 모델·성능·인사이트는 실제 실험과 검증 완료 후 기록합니다.

> 과제 요구사항과 중복 작업 방지 절차는 [별도 프로젝트 가이드](docs/PROJECT_GUIDE_KO.md)를 확인하세요. 기존 전처리 작업의 최신 인계본을 바탕으로 이어서 진행합니다.
>
> 이 README는 수업에서 제공한 양식의 1~11장 구조를 적용한 작성 중 문서입니다. `미확정`·`확인 후 기입`은 완료된 결과가 아닙니다. 대표 이미지는 실제 결과물 준비 후 추가합니다.

## 1. 프로젝트 개요

### 1.1 프로젝트 소개

**프로젝트 배경**

- 건물의 특성과 관측된 피해 등급의 관계를 분석하여 건물 취약성 이해와 점검 우선순위 검토를 위한 근거를 탐색합니다.
- 다수 클래스의 비중이 높으므로 Accuracy만으로 모델을 판단하지 않고 등급별 오류와 불균형 처리의 효과를 함께 살펴봅니다.
- 구체적인 활용 대상과 우선적으로 줄일 오류는 팀 문제 정의 합의 후 확정합니다.

**프로젝트 목표**

- `damage_grade` 1·2·3을 예측하는 다중 분류 모델을 비교합니다.
- 주지표는 **Macro F1**이며 Accuracy, 등급별 Precision·Recall·F1, 혼동행렬을 함께 확인합니다.
- 기본 전처리 Baseline과 불균형 처리·튜닝 결과를 같은 평가 조건에서 비교합니다.

### 1.2 프로젝트 정보

| 항목 | 내용 |
|---|---|
| 프로젝트 기간 | 2026.10.13 ~ 2026.10.19 |
| 프로젝트 유형 | 4인 팀 프로젝트 |
| 데이터 출처 | [Richter's Predictor: Modeling Earthquake Damage](https://www.drivendata.org/competitions/57/nepal-earthquake/page/136/) |
| 주요 기술 | Python·scikit-learn 기반 모델링 및 Streamlit 결과 대시보드 예정. 실제 버전·사용 내역은 인계·구현 후 확정 |

### 1.3 주요 성과

- **모델 성능:** 실제 데이터 실험 결과 확인 후 기입.
- **불균형 처리:** 처리 전후의 개선·악화 지표 확인 후 기입.
- **주요 인사이트:** EDA와 검증된 실험 결과를 바탕으로 기입.

## 5. 데이터셋

### 5.1 데이터 개요

**데이터 출처:** [DrivenData / Richter's Predictor](https://www.drivendata.org/competitions/57/nepal-earthquake/page/136/)

다음 규모·분포는 주제 가이드 기준입니다. 실제 사용하는 파일과 일치하는지는 데이터 인계 시 확인합니다.

| 항목 | 내용 |
|---|---|
| 데이터 수 | 260,601건 |
| Feature 수 | 입력 후보 38개. 별도로 `building_id`와 정답 포함 총 40열 |
| Target 변수 | `damage_grade` |
| 문제 유형 | 다중 분류, 1·2·3등급 |
| 클래스 분포 | 1등급 25,124건 / 2등급 148,259건 / 3등급 87,218건 |

### 5.2 데이터 특징

- 한 행은 건물 한 채이며 지역·구조·재료·연령 등의 특성이 있습니다.
- 1등급은 상대적으로 적지만, 3등급의 피해를 낮게 예측하는 오류도 중요하게 검토합니다.
- 건물 식별자는 입력에서 제외하고 지역 코드를 연속적인 크기·거리로 해석하지 않습니다.
- 면적·높이 비율을 실제 제곱미터·미터로 표현하지 않습니다.
- **Target 클래스 분포 시각화:** 실제 사용 데이터 확인 후 추가.

## 6. 데이터 분석 및 전처리

### 6.1 탐색적 데이터 분석 (EDA)

**주요 분석 내용**

데이터 구조·유형, 결측·중복, 변수 분포, 등급 분포 및 변수와 피해 등급의 관계를 확인합니다.

**주요 발견 사항 / 분석 결과 시각화**

실제 EDA와 근거 파일을 확인한 뒤 기입합니다. 현재 가이드에 제시된 수치를 팀의 독립 분석 성과로 기록하지 않습니다.

### 6.2 데이터 전처리

기존 전처리 작업이 있으며 **최신 코드·README·보고서의 버전과 실제 반영 상태를 확인하여 재사용**합니다. 구버전 첨부본을 임의로 다시 가져오거나 병렬로 같은 기능을 만들지 않습니다.

| 처리 항목 | 적용 방법 | 선택 이유 |
|---|---|---|
| 결측치 처리 | 최신 인계본 확인 후 기입 | 실제 품질 확인 결과에 따라 기록 |
| 이상치 처리 | 최신 인계본 확인 후 기입 | 특수값을 임의 삭제하지 않고 의미 확인 |
| 범주형 인코딩 | 최신 인계본 확인 후 기입 | 모델·변수 유형과 미관측 범주 처리 확인 |
| 스케일링 | 최신 인계본 확인 후 기입 | 모델별 필요성 및 학습 범위 확인 |
| Feature Engineering | 적용 여부 미확정 | 추가 실험인 경우 근거와 효과 기록 |

**전처리 과정에서 고려한 사항**

- 팀 공통 분할 비율·seed·CV 수는 합의 후 기록합니다.
- 데이터에서 학습하는 변환은 각 학습 fold에서만 fit하고 검증·Test에는 transform만 적용합니다.
- 합성 데이터 호환성 검증을 원본 데이터의 모델 성능 검증과 구분합니다.

## 7. 머신러닝 모델링

### 7.1 Baseline 모델

**사용 모델:** 아래 네 필수 모델의 Baseline 비교 예정. 실제 학습 결과 확인 후 선정 이유와 성능을 작성합니다.

### 7.2 모델 비교 및 성능 개선

**비교 대상**

- Logistic Regression
- Decision Tree
- Random Forest
- sklearn GradientBoostingClassifier

**주요 실험**

Baseline, 불균형 처리 전후, CV와 하이퍼파라미터 탐색을 동일한 평가 기준으로 비교합니다. 구현·실행 완료 여부와 결과는 근거 확인 후 기록합니다.

### 7.3 불균형 데이터 처리

**적용한 방법 / 선택 이유:** 실제 실험 완료 후 기입.

비교 대상은 클래스 가중치, Random Under Sampling, SMOTE 계열이며 데이터와 모델 특성에 맞춰 설계합니다.

- 학습 fold 내부에서만 처리하고 검증·Test 분포는 유지합니다.
- 처리 후 등급별 건수와 가중치를 기록합니다.
- 혼합형 변수에서는 SMOTENC 등 범주를 고려한 방식을 검토합니다.
- GradientBoostingClassifier 가중치 실험은 `class_weight` 대신 학습용 `sample_weight`를 사용합니다.

### 7.4 모델 성능 비교

실제 성능 수치는 아직 기입하지 않았습니다. PR-AUC 예시 대신 이번 다중 분류 과제의 Macro F1과 등급별 지표를 사용합니다.

| Random Forest Baseline | 미기입 | 미기입 | 미기입 | 실행 결과 확인 후 |
