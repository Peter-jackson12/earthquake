# 건물 특징을 활용한 지진 피해 등급 예측

건물의 위치·구조·재료 정보로 지진 피해 등급을 분류하고, 클래스 불균형 처리 전후의 성능과 오류 변화를 비교하는 팀 프로젝트입니다.

2015년 네팔 지진의 건물 피해 데이터를 바탕으로 세 등급의 예측 성능을 분석합니다. 현재 프로젝트 진행 중이며 최종 모델·성능·인사이트는 실제 실험과 검증 완료 후 기록합니다.

> 과제 요구사항은 [프로젝트 가이드](docs/PROJECT_GUIDE_KO.md), 팀 진행 순서는 [공통 계획](docs/PLAN.md), 데이터 준비·전처리 실행은 [공통 실행 안내](docs/RUNBOOK.md)를 확인하세요. `main`에는 팀 공동 기반을 두고, 개인 모델링·연구 결과는 개인 브랜치에서 관리합니다.
>
> 이 README는 수업에서 제공한 양식의 1~11장 구조를 적용한 작성 중 문서입니다. `미확정`·`확인 후 기입`은 완료된 결과가 아닙니다. 대표 이미지는 실제 결과물 준비 후 추가합니다.

## 1. 프로젝트 개요

### 1.1 프로젝트 소개

**프로젝트 배경**

- 건물의 특성과 관측된 피해 등급의 관계를 분석하여 건물 취약성 이해와 점검 우선순위 검토를 위한 근거를 탐색합니다.
- 다수 클래스의 비중이 높으므로 Accuracy만으로 모델을 판단하지 않고 등급별 오류와 불균형 처리의 효과를 함께 살펴봅니다.
- 구체적인 활용 대상과 우선적으로 줄일 오류는 팀 문제 정의 합의 후 확정합니다.

**프로젝트 목표**

- `damage_grade` 1·2·3을 예측하는 다중 분류 모델을 비교합니다.
- 주지표는 **Macro F1**이며 Accuracy, 등급별 Precision·Recall·F1, 혼동행렬을 함께 확인합니다.
- 기본 전처리 Baseline과 불균형 처리·튜닝 결과를 같은 평가 조건에서 비교합니다.

## 5. 데이터셋

다음 규모·분포는 주제 가이드 기준입니다. 실제 사용하는 파일과 일치하는지는 데이터 인계 시 확인합니다.

| 항목 | 내용 |

- **Target 클래스 분포 시각화:** 실제 사용 데이터 확인 후 추가.

## 6. 데이터 분석 및 전처리

### 6.1 탐색적 데이터 분석 (EDA)

**주요 분석 내용**

데이터 구조·유형, 결측·중복, 변수 분포, 등급 분포 및 변수와 피해 등급의 관계를 확인합니다.

**주요 발견 사항 / 분석 결과 시각화**

실제 EDA와 근거 파일을 확인한 뒤 기입합니다. 현재 가이드에 제시된 수치를 팀의 독립 분석 성과로 기록하지 않습니다.

### 6.2 데이터 전처리

`main`에는 검증된 **`preprocess.py` v1.0.1**을 공통 코드로 보존했습니다. 팀은 동일한 원본 파일과 분할을 확인해 재사용하며, 재분할 또는 전처리 변경은 비교 조건에 영향을 주므로 별도 버전으로 기록합니다. 개인 모델별 전처리 실험은 개인 브랜치에서 진행합니다.

| 처리 항목 | 적용 방법 | 선택 이유 |
|---|---|---|
| 결측치 처리 | 기존 v1.0.1 데이터 점검에서 일반 결측 0건; 입력값 검증 | 다른 버전의 입력에는 동일 검사를 다시 수행 |
| 이상치 처리 | `age=995` 등 특수값 유지 | 의미 불명 값을 임의 삭제·대치하지 않음 |
| 범주형 인코딩 | 지역 3개 + 문자 범주 8개를 희소 One-Hot으로 처리 가능 | 각 학습 Fold에서만 fit, 검증에서는 transform |
| 스케일링 | 수치 5개에 대한 선택 옵션 제공 | 필요한 모델에서만 학습 Fold에 fit |
| Feature Engineering | 적용 여부 미확정 | 추가 실험인 경우 근거와 효과 기록 |

**전처리 과정에서 고려한 사항**

- 기존 실험의 **80/20·seed 42·5-Fold는 현재 참고용 잠정안**입니다. 팀 공통 분할 합의 후 정식 계약을 기록합니다.
- 데이터에서 학습하는 변환은 각 학습 fold에서만 fit하고 검증·Test에는 transform만 적용합니다.
- 합성 데이터 호환성 검증을 원본 데이터의 모델 성능 검증과 구분합니다.

## 7. 머신러닝 모델링

### 7.1 Baseline 모델

**사용 모델:** 아래 네 필수 모델을 팀이 각각 학습·비교할 예정입니다. 개인 브랜치에 예비 실행 결과가 있더라도 팀의 공통 결과로 확정하기 전에는 `main`에 기입하지 않습니다.

### 7.2 모델 비교 및 성능 개선

**비교 대상**

- Logistic Regression
- Decision Tree
- Random Forest
- sklearn GradientBoostingClassifier

**주요 실험**

Baseline, 불균형 처리 전후, CV와 하이퍼파라미터 탐색을 동일한 평가 기준으로 비교합니다. 구현·실행 완료 여부와 결과는 근거 확인 후 기록합니다.

### 7.3 불균형 데이터 처리

**적용한 방법 / 선택 이유:** 실제 실험 완료 후 기입.

비교 대상은 클래스 가중치, Random Under Sampling, SMOTE 계열이며 데이터와 모델 특성에 맞춰 설계합니다.

- 학습 fold 내부에서만 처리하고 검증·Test 분포는 유지합니다.
- 처리 후 등급별 건수와 가중치를 기록합니다.
- 혼합형 변수에서는 SMOTENC 등 범주를 고려한 방식을 검토합니다.
- GradientBoostingClassifier 가중치 실험은 `class_weight` 대신 학습용 `sample_weight`를 사용합니다.

- 데이터 및 등급 분포 시각화.
- 모델별 성능과 불균형 처리 전후 비교.
- 최종 평가와 주요 오류 확인.

### 9.2 실행 화면

구현·실행 확인 후 실제 화면을 추가합니다. 현재는 대시보드 실행 완료 상태가 아닙니다.

### 10.3 프로젝트를 통해 배운 점

각자의 실제 작업·문제 해결 기록을 바탕으로 작성합니다.
