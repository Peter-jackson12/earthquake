## 합의된 목적과 적용 범위

2015년 네팔 지진 당시 수집된 건물 특성으로 피해 등급을 분류하고, 등급별 성능과 주요 특성의 연관성을 분석합니다. 클래스 불균형과 심한 피해를 낮은 등급으로 예측하는 오류를 함께 검토합니다. 향후 건물 점검·내진 보강 우선순위에 참고할 기초 근거를 마련하되, 인과관계나 미래 지진·다른 지역의 예측 성능을 검증한 것으로 표현하지 않습니다. 추가 적용에는 지진 강도·지반 조건 등을 고려한 검증이 필요합니다.

이번 동의는 배경·목적의 표현 범위이며, 아래 잠정 분할이나 오류 비용·허용 기준·최종 모델·팀 역할의 확정을 대신하지 않습니다.

## 실험 비교 계약

- 고정 분할(팀 승인 전엔 잠정), 같은 검증 ID, 주지표 **Macro F1 (라벨 1/2/3)**, 등급별 지표와 혼동행렬 유지
- 3→1·3→2 건수와 비율, 3등급 Recall을 함께 비교하고, 오류 비율의 분모는 해당 평가 집합의 실제 3등급 건수로 명시
- CV Fold 점수 평균과 전체 OOF 집계 지표를 구분하며, 어느 한 오류의 감소만으로 개선을 확정하지 않음
- 인코더·스케일러·샘플러는 각 학습 Fold 안에서만 fit하고 검증·홀드아웃에는 적용만 수행
- 변경 요인을 가능한 한 분리하고, 학습/검증 점수·OOF와 최종 홀드아웃을 혼동하지 않음
- GitHub 공개 저장소에는 원시 CSV·라벨 행·행별 예측·학습 모델·키를 넣지 않음
- 개인 실험을 팀 결과로 채택하려면 코드·데이터 버전·분할·재현·한계가 함께 검토되어야 함

개인 브랜치의 연구를 팀이 참고할 수는 있지만, 마감 전 과제 제출 대상은 **공개 `main`**의 검토·통합된 결과물입니다. 팀의 공통 완료 여부는 실제 작업/합의에 맞춰 계속 수정합니다.
