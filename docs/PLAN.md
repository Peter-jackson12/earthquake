## 우선순위

1. 팀원은 저장소를 받아 별도 data/를 설치하고 공통 실행 흐름을 직접 수행한다. 현재 결과를 팀원 모두의 수행 결과로 대신 기록하지 않는다.
2. 초기 계산량 제한 설정의 낮은 RF/GB 점수를 모델 자체의 한계로 해석하지 않는다. 개선 실험을 참고해 다음 탐색 예산을 정한다.
3. 다음은 불균형 실험을 확장한다. 같은 fold/검증 분포를 유지하고 가중치 또는 샘플링을 한 번에 하나만 바꾼다.
4. RUS는 학습 fold만 축소한다. SMOTE 계열은 수치/명목형 혼합과 거리 계산·이진 플래그·지역 계층의 타당성을 검토하고 train 안에서만 수행한다. GBC의 가중치는 sample_weight 경로로 별도 구현·검사한다.
5. 필수 모델·불균형·튜닝·대시보드를 먼저 완성한다. 지역 그룹 CV, SHAP, 추가 모델은 선택 심화다.

## 변경·공유 규칙

전처리·분할은 임의로 재생성하거나 변경하지 않는다. 새 실험 설정과 결과 디렉터리는 별도로 둔다.
main의 동시 변경을 확인하고 다른 사람의 README·가이드를 덮어쓰지 않는다. 큰 후속 변경은 작업 브랜치/PR로 검토한다.
원본 데이터·행별 예측·모델·비밀 값은 공개 Git에 올리지 않는다. 최종 평가 전 승인과 팀원 역할·공유 경계는 AGENTS.md를 따른다.
이 문서는 작업 상태 기록이며 예약·무인 지속 실행을 시작하지 않는다.
