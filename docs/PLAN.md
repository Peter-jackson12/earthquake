# 실행 계획

## 완료 조건

1. **공통 기반:** v1.0.1 보존, 원본/분할 해시 고정, 공개 데이터 제외, 합성+통합 테스트.
2. **기준선:** Dummy, LR, DT, RF, GradientBoostingClassifier를 같은 개발 208,480건·같은 5-Fold로 비교. 모든 건물 OOF 1건, 모델 저장/복원 검사, 수렴 경고 보존.
3. **오류 분석:** 등급별 Precision/Recall/F1, 3→1 과소평가, train/CV 차이, 개발 데이터 특성별 오류.
4. **한 요소 개선:** 클래스 가중치 → 지역 정보 포함/제외 → 제한된 깊이·후보 변수 수 → 특수 연령/구조 조합 변수. 한 번에 모두 바꾸지 않는다.
5. **추가 검증:** 개발 데이터 안에서 지역 그룹 CV. 일반 층화 CV와 결과를 섞지 않는다.
6. **최종 평가·발표:** 팀의 공식 분할 규정과 최종 후보를 확정한 뒤 홀드아웃 평가. 평가 후 같은 홀드아웃으로 재튜닝하지 않는다.

## 이번 실행 범위

공통 기반과 실제 전체 기준선을 우선한다. 실행한 결과만 reports/에 기록한다. 자동 튜닝을 무제한 실행하지 않는다.
후속 실험에서 표본을 썼다면 전체 개발 결과와 별도 표를 사용한다. 하이퍼파라미터는 configs/의 새 파일로 관리한다.

## 실험 로그 규칙

가설, 변경된 한 요소, 비교 기준, 데이터·분할·코드 해시, 실제 파라미터, fold별 Macro F1, 등급별 변화, 경고, 실행 범위, 채택/미채택 이유를 남긴다.
공식 과제 원문의 분할·추가 제한은 아직 확인되지 않았다. 현재 80/20·5-Fold를 유지하되 팀 합의 완료라고 기록하지 않는다.
