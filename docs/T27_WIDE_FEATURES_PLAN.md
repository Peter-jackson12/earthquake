# T27 — 넓은 파생변수 묶음 비교

2026-10-15 사용자 승인: 구현·독립 검토 후 자원 여유가 있으면 실행한다. 개인 `peter`에서만 작업하고 최종 코드·설정·이 계획을 실자료 실행 전에 커밋·봉인한다. 진행 상태는 [RESEARCH_STATUS](RESEARCH_STATUS.md)에 기록하며 봉인 후 이 문서를 바꾸지 않는다.

## 질문과 비교

기존 C 입력에 곱·비율·재료·범주·지역 문맥을 폭넓게 결합하면 고정 LGBM-O가 개선되는지 평가한다. 사용자가 알려 준 강사의 약144피처 사례는 정확한 목록·모델·평가가 미확인이다. 이 실험은 우리 조건에 맞춘 새 설계이며 강사 방법의 재현이라고 부르지 않는다.

기존 T12 요약/비율, T21 삼중곱/범주쌍, T22 재료55쌍/구조별 층수, T24 지역 문맥은 분리 평가됐다. T22 재료55쌍 단독의 평균Δ−0.000427은 결합 효과의 성공이나 실패를 예측하지 않는다. 전체 묶음의 효과만 평가하며 개별 피처의 기여를 분리하거나 과거 개선량을 더하지 않는다. T26 결과에 따라 모델·묶음을 바꾸거나 CatBoost와 결합하지 않는다.

신규 팔은 `WIDE_FEATURES` 하나, 주비교는 감사된 T8/T13 무가중치 `LGBM_O`다. 기준선 OOF를 그대로 재사용하며 기준선 재학습·다른 팔 선택·튜닝·가중치·재표집·사후 결정 규칙을 추가하지 않는다.

## 입력과 고정 후보

기존 원본38개와 C의 `age_is_995` 표시1개를 보존한다. C의 age995 대치·수치 스케일링·범주 인코딩 및 원래 열 순서는 바꾸지 않는다. 추가 블록은 정답 없이 계산한다.

수치 순서는 `age_clean`, `count_floors_pre_eq`, `height_percentage`, `area_percentage`, `count_families`다. `age_clean`은 각 outer-train의 비995 연령 중앙값(0 포함)으로 995만 대체한다. C가 학습한 중앙값과 같아야 하며 비995 연령이 없는 학습 자료는 거절한다. 995의 공식 의미를 결측이라고 확정하지 않고 원래 표시를 보존한다.

|---|---|---:|---|
| 1 | 수치 곱 | 10 | 위5변수의 서로 다른 쌍 i<j, 지정 순서 |
| 2 | 비율 | 6 | 높이/층수, 면적/층수, 가구/층수, 높이/면적, 가구/면적, 면적/가구 |

복합 범주 순서는 `(foundation_type,roof_type)`, `(ground_floor_type,other_floor_type)`, `(foundation_type,ground_floor_type)`, `(roof_type,other_floor_type)`, `(position,plan_configuration)`, `(foundation_type,land_surface_condition)`다. C와 같이 문자 앞뒤 공백을 제거한 뒤 충돌 없는 튜플과 정렬된 outer-train 어휘를 사용하며 검증 미관측 조합은 해당 블록 전체0이다. 허용 범주의 조합 상한은15+20+25+12+40+15=127이다. 범주 코드에 강도 순서를 부여하거나 geo ID를 크기·거리로 곱하지 않는다.

지역 문맥은 T24와 같은 정의다. 각 outer-train의 geo1별 중앙값을 학습하고 학습행 자신도 통계에 포함한다. 미관측 geo1에는 전체 outer-train 중앙값으로 대체한다. 검증 행을 지역 통계에 포함하지 않는다.

95개 수치/이진 후보와6종 복합 범주로 **추가 논리 후보101종**, 기존C 포함 **원핫 전 후보140종**이다. 과거 실험 항목도 포함하므로101종 모두 새로운 아이디어라는 뜻은 아니다. 인코딩 후 추가 후보 폭은95+6조합의 관측 학습 어휘 수이며 실제 모델 열수140이라고 보고하지 않는다. 원래 C의 지역 원핫 열 수도 Fold마다 다르다.

## 산술·품질 정리 경계

- 새 수치 산술은 float64로 계산한 뒤 유한한 float32로 변환한다. overflow·비유한 입력/출력은 실패 처리한다. 비율 분모0은 결과0과 위 표시로 정의하며 epsilon·clip을 넣지 않는다. 변환 뒤 값에 따라 정의를 바꾸지 않는다.
- 추가 전체 후보를 float32 CSR로 정리하고 중복 좌표 합산·명시적0 제거·인덱스 정렬 후 열을 비교한다. outer-train에서 모든 행의 값이 동일한 열은 상수로 제거한다(0 및 비0 모두). 나머지 중 앞서 보존한 열과 값이 정확히 같은 열은 중복으로 제거하며 생성 순서상 첫 열을 유지한다. 해시만 같다고 같다고 판단하지 않고 실제 sparse 좌표와 값을 확인한다.
- 비교·제거 대상은 추가 블록 안으로 한정한다. 기존 C와의 중복 비교/제거는 하지 않으며 C를 완전히 보존한다. 이는 실행 비용과 기준 입력 보존을 위한 고정 선택이다. 희귀빈도 임계값으로 제거하지 않고 지원수만 기록한다.
- 제거 목록과 보존 인덱스는 outer-train X로 한 번 결정한 후 고정한다. 검증 값을 보고 선택하지 않으며 y를 읽지 않는다. 모든 추가 열이 제거되면0열 블록을 허용한다. 빈 검증 입력은 같은 보존 폭의0행 행렬로 처리한다.
- 추가 블록을 C 뒤에 붙이고 C 부분의 float32 CSR 값·열 순서 일치를 확인한다. 전체 C/OHE 희소 행렬은 밀집화하지 않는다. 95개 수치 후보의 작은 별도 배열 계산은 허용한다.
- 높이·면적은 정규화된 입력이다. 비율을 실제 층고·제곱미터당 거주 밀도, 곱을 검증된 공학적 취약도로 해석하지 않는다.

## 사전 판정과 기록

전체 고정 묶음에 기존 다섯 조건을 적용한다: 20Fold 평균 Macro F1 차이≥+0.003, 양의 차이 Fold≥14/20(동률 제외), 양의 seed별 평균≥3/4, 반복 pooled Recall3 차이≥0, 반복 pooled3→1 오류율 차이≤0. 모두 충족해도 자동 채택이나 독립 최종 성능 인증은 아니다.

Fold 평균/SD(ddof=1), seed별 pooled, labels=[1,2,3]의 P/R/F1·혼동행렬, 오류 전환, age995/non995를 기록한다.3→1·3→2 분모는 실제3등급,2→3 분모는 실제2등급이다.208,480개 건물의4회 반복833,920예측은 독립 표본이 아니다. 같은 개발 자료의 반복 탐색 한계를 유지한다. importance·지원수·하위 집단 결과는 진단이며 같은 결과에서 피처를 다시 골라 개선 검증으로 보고하지 않는다.

비공개 Fold 기록에는 후보140/추가101 논리수, 수치95·범주6, 인코딩 후보 폭·보존 폭, 각 후보명·지원수·상수/중복 제거 이유·보존 인덱스, 학습 중앙값·지역 통계·범주 어휘, 미관측 범주6/geo1 발생률을 남긴다. 기존/추가/전체 train·valid 여섯 CSR SHA와 shape·dtype, nnz, 전처리·학습 시간 및 관측 가능한 프로세스 메모리를 기록한다. 전처리나 감사 시간은 fit_seconds와 구분한다. 원시값·어휘·상태·행별예측은 공개하지 않는다.

## 검토·실행·감사 순서

1. 병렬 구현은 파일 소유권을 나눈다. 합성 검사로 각 식·후보 수·순서·float32 후 상수/중복·train-only·y 미사용·특수값·범주 충돌·미관측/fallback·빈 입력·overflow·직렬화·C 일치를 확인한다. 실행기 예산·실패 전역 중단·체크포인트·집계도 검증한다.
2. 독립 정적/합성 검토와 전체 `unittest discover`를 통과한 뒤 부모가 최종 커밋과 소스 SHA를 확인한다. 기존 T21~T26 봉인 파일은 수정하지 않는다.
3. 실행 관리자가 T26의 원장·잠금·프로세스·자원을 확인한다. 현재 메모리와 디스크 여유를 확인해 기존 작업과 자원 경쟁을 피하며 중복 Fold를 실행하지 않는다. 가용RAM≥8GiB·디스크≥15GiB, 지속CPU≥90% 또는 디스크 포화가 없을 때 새 단위를 시작하고 부족하면 보류한다. 실행 중 T26을 중단하거나 재학습하지 않는다.
4. 최초 prepare 봉인 뒤 첫 공식 Fold를 실행한다. 시작 전 attempt1/running 기록, 모델·전처리·피처 상태·확률/예측·지표 저장, SHA·별도 백업·즉시 재로딩 확률차≤1e-12 확인 후 complete로 기록한다. 자원 재확인 후 나머지19개와 finalize를 이어간다. fits/finalizations 어디든 failed/running이면 다른 필터로 후속 실행하는 것도 차단한다. 기존 출력·실패 기록을 보존하고 재시도하지 않는다.
5. 독립 감사는 실행기 import·저장 joblib 역직렬화·신규 학습 없이 C/후보 생성/품질 정리/전체 CSR·상태를 별도로 재구축하고 native20모델을 재추론한다. 원장·분할·기준선·원본/백업 SHA·지표·판정을 대조한다. 실제 PASS 뒤 `reports/WIDE_FEATURES_20261015.md`와 `wide_features_20261015.json`에 집계만 작성·독립 검토한다.

모든 작업은 `worktrees/peter_rules`의 `peter`에서 한다. 새 브랜치/worktree, 홀드아웃 접근, 팀원 브랜치나 메인 checkout 변경, 기존 산출물 덮어쓰기, 원시자료·모델·OOF·manifest 공개 업로드는 금지한다. 공통 문서와 커밋은 부모가 조율하며 이번 승인으로 공개 push나 컴퓨터 종료를 하지 않는다.
