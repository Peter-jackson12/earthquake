- **지역 평균 키:** 각 수준(geo1/geo2/geo3)은 그 수준의 `geo_level_*_id` **단일 열 문자열**을 키로 하고 상위 수준과의 계층 경로를 합치지 않는다. 평균은 float64 groupby로 계산한다. 단일 열 키 기준이 팀원 파일의 정의와 같은지는 컨트롤 타워가 검증한 식을 따르며, `preflight`가 수준별 고유값 수와 키 형식을 기록한다.

## 3. 팔과 모델 설정

### 3.1 공통 고정

원본 38개 입력과 특수값(age 995·0)은 삭제하지 않는다. 연령 정책은 각 기준선 그대로(**둘 다 C**: 995 → 학습 Fold 비995 연령 중앙값으로 대체 + `age_is_995` 표시). 하이퍼파라미터·결정 규칙(확률 argmax)·가중치 없음·재표집 없음·early stopping 없음·튜닝 없음을 기준선과 동일하게 유지한다. 바꾸는 것은 **기준 입력 행렬 뒤에 파생 열을 붙이는 것 하나**이며 기존 열의 값·순서는 바뀌지 않는다. 팔별 붙이는 열: S0 10열(#1–#10), S1·S2 13열(#1–#13).

| 모델 | 기준 입력 | 파라미터 | 파생 블록 처리 |
|---|---|---|---|
| LGBM-N | T8 N 39열 dense float32(수치/이진 28열 + 범주 11열 순서 코드), `categorical_feature=[28..38]` | T8 설정 그대로: 300 rounds, lr 0.05, num_leaves 31, `deterministic=true`, `force_col_wise=true`, seed 42, `n_jobs=2` | 수치(S0 6열, S1·S2 9열)는 **표준화 없이** float32로 이어 붙이고(트리는 단조 변환에 불변이므로), 범주 4열은 학습 Fold 어휘 `OrdinalEncoder`(미관측→NaN) 코드로 이어 붙여 `categorical_feature`에 추가. S1·S2: 입력 52열, 지정 인덱스 `[28..38] + [48..51]`. S0: 입력 49열, 지정 인덱스 `[28..38] + [45..48]` |
| LR-C | T1 C 전처리 CSR float32(수치 5열 표준화 + 이진 + `age_is_995` + 지역·텍스트 원핫, 약 12.6천 열) | lbfgs, C=1, max_iter=1500, tol=1e-4, random_state=42, 단일 스레드(`threadpool_limits(1)`) | 수치(S0 6열, S1·S2 9열)는 학습 Fold로 fit한 `StandardScaler` 후 float32 CSR, 범주 4열은 `OneHotEncoder(handle_unknown='ignore', sparse_output=True, float32)`(학습 Fold 어휘, 최대 75열)로 **CSR hstack**. 전체 `.toarray()` 없음 |

### 3.2 지역 평균 연령 (#11–#13) — S1과 S2의 유일한 차이, S0에는 없음

공통: 학습 Fold의 **원본 `age`(C 정책의 대체 이전 값)** 로 지역별 평균 표를 만든다. 학습 행은 자기 행을 포함한 표를 조회하고(leave-one-out 아님), 검증 행은 **학습 Fold 표**를 조회한다. 검증 행·정답으로 표를 만들지 않는다. 지역 열은 geo1/geo2/geo3 각각 독립 표다.

| 항목 | S1 (원형) | S2 (보정판) |
|---|---|---|
| 평균에 쓰는 행 | 해당 지역의 학습 Fold 모든 행(`age` 995 포함) | 해당 지역의 학습 Fold 행 중 `age != 995` |
| 학습 Fold에 없는 지역(**검증 행에만 해당**, 학습 행에는 발생하지 않음) | 학습 Fold **전체 `age` 평균**(995 포함) | 학습 Fold 전체 **비995** `age` 평균 |
| 지역에 비995 행이 없음(S2에만 해당; 학습·검증 행 모두 같은 규칙) | 해당 없음 | 위 전체 비995 평균으로 대체하고 지역 수·행 수를 기록 |

- `age==0`은 실제 값으로 평균에 포함한다(995만 제외). 어느 쪽도 C 정책의 대체 연령(중앙값 15)을 평균에 섞지 않는다.
- S1은 컨트롤 타워가 관찰한 팀원 파일의 동작(지역 평균에 995가 섞임: geo2 평균 최대 707, geo3 최대 995)을 우리 Fold에서 그대로 재현한 것이다. S2는 그 문제를 고친 보정판이며, **결과를 보기 전에 고정한 사전 정의**다(팀원 파일의 관찰에서 나왔고 우리 결과에서 나오지 않았다).
- **알려진 성질(가설, 판정 규칙 아님):** (a) 학습 행의 평균에는 자기 `age`가 들어 있어, 특히 소규모 geo3에서 학습 행은 평균이 자기 연령과 거의 같고 검증 행은 그렇지 않은 **학습·검증 분포 차이**가 생긴다. 정답을 쓰지 않으므로 라벨 누수는 아니지만 트리가 이 관계를 학습 Fold에서만 쓸 수 있다. (b) geo3 평균 연령은 지역별로 거의 유일한 값이라 지역을 식별하는 **지문** 역할을 할 수 있다. 층화 CV에서는 같은 지역이 학습·검증에 모두 있어 지역 암기만으로도 점수가 오를 수 있고, 이는 "연령 문맥 정보"의 증거가 아니다(§12). (c) **S2에서는 `age==995`인 학습 행만 평균에서 자기가 제외되고 나머지 학습 행은 자기가 포함**되어, 한 팔 안에서 자기 포함 규칙이 행 집단에 따라 다르다. 이 성질들은 진단 지표로 측정만 하고(§9; 995 행과 비995 행의 "학습 평균–자기 연령" 관계를 분리해 보고) 정의를 바꾸지 않는다(leave-one-out 평균 등은 범위 밖).
- S1과 S2는 지역 평균 연령 3열의 값만 다르다. 나머지 열·모델 설정은 동일하다. S0는 그 3열이 없다. S0−B, S1−S0, S2−S0, S2−S1 비교의 의미는 §8.3이다.

### 3.3 LGBM-N에서 새 범주 4열을 native로 넣는 결정과 근거

**결정(제안): native categorical.** 근거:
1. **표현 일관성.** LGBM-N의 정의가 "범주 입력은 모두 native"다(T8). 새 4열만 원핫으로 넣으면 한 팔 안에 두 표현이 섞이고 T9(지역 원핫 + 텍스트 native는 0.669966, T8 N은 0.699342)가 보인 것처럼 범주 표현이 성적을 크게 바꾸는 모델에서 표현 선택이 새 교란 요인이 된다.
2. **행렬 형태 유지.** native는 입력이 dense 39 → 49/52열로 늘 뿐이다. 원핫은 최대 75개의 희소 열을 붙여야 해서 dense → CSR 혼합으로 컨테이너가 바뀐다(T31이 지적한 교란).
3. 조합 열의 어휘 크기(15·20·25·15)는 LightGBM 기본값(`max_cat_threshold=32`, `min_data_per_group=100`, `cat_smooth=10`, `max_cat_to_onehot=4`) 안에서 처리된다. Fold마다 모델 텍스트의 실효 범주 파라미터를 기록한다.
- **한계:** 원핫 대안은 실행하지 않는다. 학습 Fold 어휘의 희귀 조합이 native 분할에서 과적합될 가능성은 있으나 진단으로만 본다(§9). 이 선택은 승인 항목이다.
- 범주 조합은 LR에서는 원핫이다(§3.1). 두 모델의 범주 표현이 다른 것은 각 기준선의 표현을 유지하기 위함이며, 모델 간 순위 비교는 하지 않는다.

### 3.4 묶음 해석 제한과 "한 요소씩" 원칙

AGENTS는 개선을 기존 기준선과 한 요소씩 비교하도록 한다. 이 실험은 사용자가 요청한 **묶음 평가**이므로 그 원칙의 의도된 예외다: 묶음 전체 효과를 보되, 가장 위험한 부분(지역 평균 연령 3열: 지역 지문·자기 포함 분포 차이)만 S0로 분리해 **10열(수치 6 + 조합 4)과 지역 평균 연령 3열**의 두 덩어리로 나눈다. 변수별 기여, 과거 실험(T12·T21·T22·T24·T27) 효과의 합산, 10열 안의 하위 묶음 분해는 하지 않는다. 변수 중요도·분할 횟수는 진단용이며 같은 결과에서 변수를 골라 다시 검증하는 데 쓰지 않는다. `height_percentage`·`area_percentage`를 실제 미터·제곱미터로 해석하지 않고 비율을 취약도 지수로 해석하지 않는다.

위 세 SHA(LGBM-N, LR 로컬 재적합, LR 원 환경)는 작성·검토 중 파일 바이트에서 **직접 계산해 일치를 확인했다**(OOF 내용은 읽지 않았다). 로컬 재적합과 원 환경 OOF의 Fold F1 차이는 검토자 계산상 +3.64e-4, +9.3e-5, −1.4e-5, +3.21e-4, +9.7e-5(최대 3.6e-4, 평균 +1.7e-4)이며 OS·BLAS 차이로 의심되나 확정은 아니다.

**LR 기준선을 로컬 재적합으로 정한 이유(검토 M1):** 원 환경 OOF를 B로 쓰면 환경 차이(Fold F1 최대 3.6e-4)가 T12에서 계산된 짝지은 ΔF1의 SD(LR 약 2~4e-4)와 같은 규모라 처리 효과와 섞일 수 있다. 로컬 재적합은 처리 팔과 같은 기계·venv·스레드 설정이므로 더 공정하다.

확인 방법(구현 후, `design.json`에 결과를 봉인):
1. 파일 SHA-256이 위 값과 같다(다르면 즉시 중단).
2. `building_id` 정렬 후 건물 ID·Fold 배열·정답이 `load_development()`·`split_manifest.csv` 순서와 일치한다(T8 `reference()`와 같은 방식, 확률은 `float_precision='round_trip'`로 읽는다).
3. Fold 평균 Macro F1이 위 표 값과 1e-9 이내로 재현된다(`metrics.json`의 Fold 값과 대조).
4. 보고용 3→1·3→2·Recall3은 이 OOF에서 풀링으로 다시 계산한다(분모 69,774).

**대조 재학습(제안 기본값: 한다, 2 fit, `control_check/`):** 봉인 전에 새 실행기로 **파생 블록 없는 기준 행렬**의 Fold 0을 LGBM-N, LR-C 각각 1회 다시 학습해 위 B의 해당 Fold와 비교한다(T8 `control-check`와 같은 위치·성격. 연구 fit 수에는 넣지 않고 완료 fit 집계에는 포함).
- **LGBM-N:** 확률 최대 절대차 ≤ 1e-9, 예측 등급 동일(상위 두 확률 동률 행의 등급 차이는 기록). 불일치 시 설계를 봉인하지 않고 중단·보고한다.
- **LR-C(로컬 재적합 B 대비):** 같은 코드 경로·같은 venv·단일 스레드이므로 **LGBM과 같은 엄격 기준**을 쓴다: 확률 최대 절대차 ≤ 1e-9, 예측 등급 동일. 통과하면 B를 유지한다. 실패하면(`CONTROL_FAILED_LR`) **사전 규칙에 따라 `prepare`가 `LR_B_REFIT`(LR-C 기준 행렬 5 Fold 재학습, +5 fit)를 연구 팔로 추가**하고 LR 판정의 B는 그 재적합 OOF로 한다(로컬 재적합·원 환경 OOF는 인용). 이전 초안의 "Fold F1 5e-4 허용"은 **폐기**했다. 이 분기는 처리 팔 결과가 아니라 대조 결과만으로 정해지며 봉인 전에 확정된다.
- 두 대조 fit은 기준 행렬(파생 블록 없음)만 쓰고 판정에 쓰지 않는다. 대조 실패 시의 산출물은 폐기하지 않고 `control_check/`에 보존한다.

## 6. 실행 설계

### 6.1 단계 (순서 고정)

1. **구현·합성 테스트:** `experiments/derived_bundle/`, `tests/test_derived_bundle.py`(합성만). 기존 코드(T8 `experiments.lgbm_native_cat.run`, `experiments.age995.run.make_pipeline`, T12 `experiments.struct_features.run`의 행렬 이어 붙임·점검 패턴)는 **import만** 하고 수정하지 않는다. `preprocess.py` 불변. 정확한 재사용 함수는 구현 시 확인한다(설계자는 코드 구조를 읽었으나 구현 호환은 미검증). 합성 검사: 13개 식과 열 순서, S0/S1/S2 열 구성, 수기 계산, 0/1 경계, 단일 행 지역, 미관측 지역·미관측 조합, S1/S2 평균(995 있는/전부 995인 지역), 학습·검증 분리(검증 값을 바꿔도 학습 상태 불변), y 무사용, 기준 열 prefix 불변, 직렬화·재로딩, **홀드아웃·`x_train.csv` 접근 가드(§11)와 배타 잠금·시도 원장 동작**.
2. **전체 unittest:** `python -m unittest discover -s tests -v` 전체를 실행해 pass/skip을 구분해 기록한다.
3. **`peter` 커밋(전체 40자 SHA):** 코드·설정·이 계획을 커밋한다. 이후 단계의 control 결과와 봉인이 **같은 커밋 SHA**에 결속된다(커밋 뒤 코드 변경 금지).
4. **`preflight`(분류기 학습 0회):** 전 Fold의 파생 블록을 만들어 값 범위, `area_percentage==0` 여부, 지역별 고유값 수·키 형식, 지역 미관측 건수(Fold별, 검증 행 기준), 995가 섞인 지역 수·S1과 S2의 평균이 다른 행 비율(지역 수준별), 조합 어휘 수(≤75), 열 수·nnz·형식, B OOF SHA·정렬을 기록한다.
5. **`control-check`:** §5의 2 fit(같은 커밋 SHA). PASS 후에만 6으로. 결과 파일의 SHA와 코드 커밋 SHA를 `design.json`에 결속한다.
6. **`prepare`:** 설계·소스·환경·SHA·대조 결과를 봉인(`design.json`, `design_seal.json`). 봉인 후 설계·코드·설정은 실행 중 변경하지 않는다. 이 문서도 봉인 대상 소스다.
7. **`fit-all`:** 단일 실행권을 가진 한 주체만. 순서: (`LR_B_REFIT`이 있으면 가장 먼저) → LR S0 → LR S1 → LR S2 → LGBM-N S0 → LGBM-N S1 → LGBM-N S2(각각 Fold 0–4). 중간 결과로 설정·팔을 바꾸지 않는다.
8. **`finalize`:** 팔별 OOF 조립, 지표, 판정, 진단(`analysis.json`). 이 시점에 처음으로 판정을 계산한다.
9. 독립 감사 → 공개 집계 보고 → 메인이 커밋·푸시(§10).

### 6.2 fit 수·시도 상한·재시도

| 구분 | 내용 | 완료 fit |
|---|---|---:|
| 연구 팔 | LR-C × {S0,S1,S2} × 5 Fold = 15, LGBM-N × {S0,S1,S2} × 5 Fold = 15 | 30 |
| 대조 재학습 | LGBM-N·LR-C 각 Fold 0 기준 행렬(§5) | 2 |
| **기본 합계** | | **32** |
| 조건부(사전 규칙) | LR 대조 `CONTROL_FAILED_LR`이면 `LR_B_REFIT` 5 Fold | +5 → 37 |

- B 팔은 신규 fit 0. 홀드아웃·geo2/geo1 학습 0회. 단일 시드(seed 42).
- **시도 상한:** 기본 **36**(완료 32 + 인프라 재시도 4), 조건부 포함 **41**(완료 37 + 4). 대조 생략 시(승인 항목 8의 대안) 완료 30, 상한 34.
- 재시도는 인프라 중단(프로세스 강제 종료·디스크·전원)에만 `--retry-interrupted --retry-reason`으로 수동 허용하며 단위(팔×Fold, **대조 fit 포함**)당 최대 1회, 전체 최대 4회다. 대조 불일치·알고리즘·데이터 결함은 재시도가 아니라 **중단·보고**다(설계 개정은 새 ID로만). 성능을 본 뒤 설정을 바꾸는 재시도는 금지한다.
- **LR 비수렴(M6):** `max_iter`를 올리거나 재시도하지 않고, 중단하지도 않는다(수렴 경고·낮은 점수는 실패가 아니다). 대신 사전에 정한 처리: Fold별 `n_iter`와 `ConvergenceWarning`을 판정 표에 병기하고, 처리 팔 또는 B에 미수렴 Fold가 하나라도 있는 LR 비교에는 **`CONVERGENCE_CAVEAT`** 를 붙이며 그 비교의 `ALL_MET`은 후보 표시로도 쓰지 않는다(§8.2). B의 `n_iter`는 §5 표의 값을 같은 표에 인용한다(`LR_B_REFIT`이면 새 값). 기준선이 5 Fold 모두 수렴(`n_iter` 566–595 < 1500)한 것이 확인돼 있으나, 파생 열 추가(스케일이 다른 수치 9열, 이진 열의 합인 `material_count` 등으로 인한 공선성)가 수렴을 늦출 수 있다는 점은 미확인이다.

### 6.3 병렬도와 실행 조건

- 병렬도 1단계: Fold·팔은 완전 직렬이고, 학습 내부만 기준선과 같은 스레드를 쓴다(LGBM `n_jobs=2`·`threadpool_limits(2)`, LR 1 스레드). 해시·백업 복사도 순차다. 기준선과 같은 스레드를 쓰는 이유는 대조(§5)가 같은 조건에서 이뤄지게 하기 위함이다.
- 다른 학습(T30 등)이 같은 PC에서 돌 수 있다. **다른 학습과 동시에 `control-check`·`fit-all`을 실행하지 않는다**(같은 Fold 중복 학습 금지와 별개로 자원 경합). 구현·합성 테스트·`preflight`(분류기 학습 0)는 병행 가능하되 무거운 계산은 피한다. 새 단위 시작 전 가용 RAM ≥ 8 GiB, 디스크 ≥ 15 GiB, 지속 CPU 포화 없음을 확인하고 기록한다(T27과 같은 기준). 실행 순서·시작 시점은 컨트롤 타워가 정한다.
- 환경: 동결 venv(`local_reproduction/20261014_01/venv`, Python 3.13.5, numpy 2.3.5, pandas 2.2.3, scipy 1.17.0, scikit-learn 1.8.0, lightgbm 4.6.0, joblib 1.5.3, threadpoolctl 3.6.0). 설치·변경 없음. `prepare`가 버전을 기록하고 불일치하면 중단한다.

## 7. 체크포인트·원장·SHA·재개·운영 요건

AGENTS "머신러닝 연구 운영 순서"를 따른다.

- **배타 실행:** 실행기는 `RUNNING.lock`을 **배타적으로 생성**(이미 있으면 실패)하고, 실제 실행 주체가 없음을 컨트롤 타워가 확인한 뒤에만 제거한다.
- **시도 원장:** `attempts.jsonl`에 단위 시작 전 `running`(시도 번호·시각·코드 SHA)을 먼저 기록하고 종료 시 `complete`/`failed`로 닫는다. 실패 시도의 부분 파일은 삭제하지 않고 `.incomplete_attempt<N>`으로 보존한다. `failed`/`running` 단위가 있으면 다른 필터로 후속 학습을 우회할 수 없다.
- **Fold(fit) 단위 저장:** 각 fit 완료 직후 분류기 산출물(LGBM 모델 텍스트, LR 파이프라인 joblib), 전처리·파생 상태(지역 평균 표, 조합 어휘, 스케일러; 비공개), 검증 예측 확률(CSV gzip `%.17g`), 지표, Fold JSON, 로그를 저장하고 SHA-256을 `ledger.json`에 기록한다. 저장 직후 (a) 모델·전처리기 재로딩 확률 차이 ≤ 1e-12와 등급 동일, (b) CSV를 `float_precision='round_trip'`으로 읽어 정확 일치, (c) `backup/` 복사 후 SHA 일치를 확인한 뒤에만 `complete`로 기록한다. 저장 실패는 완료가 아니다.
- 완료 fit은 해시만 검증하고 재학습하지 않으며 중단 후 재개가 가능하다. 원본 결과는 덮어쓰지 않는다. 원시 데이터·모델·행별 OOF·manifest·지역 표·어휘는 공개하지 않는다.
- 각 Fold의 행렬 점검(실제 Fold에서 매번): (i) 기준 열 prefix가 같은 Fold의 기준 행렬과 완전히 같다(희소는 CSR 비교, LGBM-N dense는 앞 39열 비교, 전체 `.toarray()` 없음), (ii) 파생 블록이 독립 pandas 계산과 일치한다, (iii) S1과 S2는 지역 평균 연령 3열만 다르고 S0는 S1에서 그 3열을 뺀 것과 같다, (iv) 학습 통계가 학습 Fold 행만으로 만들어졌다.

## 8. 판정 (사전 고정 기술 판정, 임계는 제안값)

### 8.1 비교 단위

**판정군(한 군으로 보고):** 같은 모델, 같은 Fold 쌍에서 `(S0−B)`, `(S1−B)`, `(S2−B)`를 각 모델에 대해 계산한 **6개 비교** — (LR, S0), (LR, S1), (LR, S2), (LGBM-N, S0), (LGBM-N, S1), (LGBM-N, S2). `Δ` = 처리 − B. LR의 B는 대조 통과 시 로컬 재적합 OOF(§5), 실패 시 `LR_B_REFIT`이다.

**기술 비교(임계·태그 없음):** `S1−S0`, `S2−S0`(지역 평균 연령 3열 유무의 효과), `S2−S1`(995 보정의 차이) — 각 모델에 대해 6개. §8.3.

### 8.2 다섯 조건 (기존 반복 평가의 다섯 조건을 층화 5-Fold에 맞춤)

판정군 6개 각각에 적용한다. 모든 조건을 충족해야 `ALL_MET`이다. 하나라도 미충족이면 `NOT_ALL_MET`이며 미충족 조건을 모두 표시한다.

| # | 조건 | 기존(geo2 4 seed × 5 Fold) | 층화 5-Fold 조정과 근거 |
|---|---|---|---|
| 1 | Fold 평균 Macro F1 `Δ ≥ +0.003` | 같음 | 이 저장소의 사전 기준(T12·T21·T22·T24·T27·T31)을 그대로 쓴다 |
| 2 | 같은 Fold에서 처리 F1이 B보다 **엄격히 큰** Fold 수 `≥ 4/5` | ≥ 14/20 | 14/20 = 70%는 5 Fold에서 3.5이므로 정수 올림해 4/5(T8·T12·T31이 층화에서 쓴 값). 부호 검정으로 보면 귀무에서 4/5 이상이 나올 확률이 6/32 ≈ 0.19라 약한 기준이다. 유의성이 아니라 일관성 참고다 |
| 3 | 풀링 OOF 3등급 Recall `ΔR3 ≥ 0` | 같음 | 분모 실제 3등급 69,774 |
| 4 | 풀링 OOF 3→1 오류율 `Δ ≤ 0` (분모 69,774) | 같음 | 엄격 비교(건수 +1도 미충족, T27 관례) |
| 5 | 최악 Fold `Δ > −0.003` | (seed별 평균 양성 ≥ 3/4) | 시드가 하나뿐이라 seed 조건은 구조적으로 성립하지 않는다. 대신 한 Fold가 크게 악화된 평균을 걸러내는 조건으로 대체하는 제안이다(승인 항목 10) |

- **임계값의 근거(검토 M2 반영):** 판정은 같은 Fold 쌍의 차이를 쓰므로 소음 척도는 비짝지은 Fold F1 SD가 아니라 **짝지은 ΔF1의 SD**다. T12 층화 집계에서 검토자가 계산한 값은 LR 0.00024~0.00043, LGBM-O 0.00073~0.00112이다(새 측정 아님, LGBM-N·이 실험의 값은 미확인). 이에 비추어 +0.003은 LGBM에서 약 3 SD, LR에서 약 10 SD 수준이다. 따라서 **LR에서는 조건 2(4/5)가 조건 1과 사실상 중복되고 조건 5(−0.003)는 거의 구속력이 없다**(역할이 약함). 임계값 자체는 저장소 관례를 유지한다. 어느 판정도 유의성·인과·일반화 주장이 아니다.
- **고정 보고 항목:** 보고서에 Fold별 `Δ`와 `Δ`의 평균 ± SD(ddof=1)를 판정군·기술 비교 모두에 포함한다.
- **방향 설명 태그(조건과 별도):** `Δ ≥ +0.003`이면 `HIGHER`, `Δ ≤ −0.003`이고 승수 ≤ 1이면 `LOWER`, 그 밖은 `NEUTRAL`.
- **`CONVERGENCE_CAVEAT`(LR만):** 처리 팔 또는 B에 미수렴 Fold가 하나라도 있으면 붙이고, 그 비교의 `ALL_MET`은 후보로도 쓰지 않는다(§6.2).
- **안전 점검:** 3→1은 조건 4가 이미 판정에 들어 있다. 건수 차와 비율 차를 함께 적고, 풀링 3→1 건수는 LGBM-N 기준 530건 수준이라 수십 건 변동이 소음일 수 있음을 보고서에 적는다. 안전 점검 표에 T30·T31의 이중 플래그(처리 팔이 B보다 3→1이 상대 +10% 넘게 **그리고** 절대 +30건 이상 많음)를 병기한다(판정을 바꾸지 않음). 3→2·2→3·1→2 변화와 실제 3등급 Recall도 표로 병기해 악화된 등급을 숨기지 않는다.
- **다중 비교 규칙(검토 M3 반영):**
  1. 판정군 6개를 **한 군(family)** 으로 보고하며 다중성 보정은 하지 않는다. 참고로 조건 2 단독의 귀무 확률 0.19를 6개 비교(S0·S1·S2는 서로 상관이 있어 독립은 아님)에 적용하면 하나라도 충족할 확률은 독립 가정 시 약 71%(상한)이다. 다섯 조건 동시 충족은 이보다 훨씬 엄격하나 이 문서가 정량하지 않는다.
  2. **`ALL_MET`은 후보 표시일 뿐이다.** 같은 Fold 반복 평가이므로 별도 확인 평가(T29) 전에는 어떤 채택·승격·"개선 확인" 문구도 쓰지 않는다. 최종 모델 교체·홀드아웃 평가는 이 설계 범위가 아니다.
  3. 한 모델에서만 `ALL_MET`이면 "모델 의존"이라고 쓰고 일반화 문구를 금지한다.
  4. 같은 모델에서 S0·S1·S2 중 일부만 `ALL_MET`이면 충족한 팔만 부각하지 않고 세 팔 표를 나란히 둔다.
  5. 가장 좋은 팔만 골라 쓰지 않는다. 모든 결과를 판정과 무관하게 보고한다.

### 8.3 기술 비교 (임계도 태그도 없음)

같은 모델·같은 Fold 쌍에서 `S1−S0`, `S2−S0`, `S2−S1`의 `ΔF1`(Fold별, 평균 ± SD), 승수, `ΔR3`, 3→1·3→2 변화, 같은 행 전이(고쳐진/새 오류, `experiments/geo_ablation/audit.py` `turnover()` 정의)를 보고한다. 결론 문구("지역 평균 연령이 도움/해로움", "995 보정이 낫다/못하다")를 쓰지 않고 차이의 크기만 적는다. 해석 가이드(가설): `S0−B`는 지역 평균 연령을 뺀 10열 묶음의 효과, `S1−S0`·`S2−S0`는 지역 평균 연령 3열 추가의 효과(지역 지문·자기 포함 분포 차이가 섞임, §3.2), `S2−S1`은 그 3열에서 995 처리만 바꾼 차이다. 995 포함 지역에 속한 검증 행과 나머지의 하위집단 F1은 행 수 200 미만이면 F1 없이 건수만 보고한다.

## 9. 보고 지표

팔×Fold: Macro F1, Accuracy, 클래스별 Precision/Recall/F1·지지 수, 혼동행렬(풀링), 3등급 Recall, 3→1/3→2 건수·비율, 같은 행 전이(B 대비), 학습 Fold 지표(과적합 기술용), age 995 집단 프로필(원본 age==995 vs 나머지), geo1 26/20/13 프로필(T8과 같은 정의), LR `n_iter`·수렴 경고(B 포함), LGBM 트리 수·모델 텍스트의 범주 실효 파라미터·파생 열 gain 비중(진단, 선택 근거로 쓰지 않음).

진단(판정 불사용): 지역 수준별 미관측 검증 행 수, 995가 섞인 지역 수·S1/S2 평균 차이 분포, **학습 행 대 검증 행에서 지역 평균 연령과 자기 `age`의 관계**(상관, 평균절대차를 geo3 지역 크기 구간별로; 자기 포함 효과 측정. S2는 `age==995` 학습 행과 비995 학습 행을 분리), 조합 어휘 수와 검증의 미관측 조합 건수, geo2 인용(T27 등 기존 값은 출처와 함께 "새 측정 아님·판정 미사용"으로 표시).

## 10. 독립 감사와 공개 보고

- 독립 감사는 실행기를 import하지 않고 새로 구현한다. 항목: (1) 데이터·manifest·B OOF 2개(및 인용 OOF)의 SHA와 층화 Fold 배정; (2) 팔별 OOF가 모든 행에 정확히 한 번, ID·정답 정렬; (3) 지표를 OOF에서 재계산해 Fold JSON·집계와 일치; (4) 파생 열을 독립 코드(pandas 등)로 재생성해 일치(S0는 10열, S1·S2는 13열), S1/S2의 지역 평균 연령이 정의대로이며 학습 Fold 행만 사용(검증 행·정답 무사용), 기준 열 prefix 불변; (5) 저장 모델 재추론 일치(LGBM은 모델 텍스트, LR은 허용 범위를 감사 준비 영수증에서 확정); (6) 원장·`attempts.jsonl`·백업 SHA, 완료 fit 수, 시도 수 ≤ 상한; (7) 대조 결과, 코드 커밋 SHA와 control·봉인의 결속, `LR_B_REFIT` 분기의 정당성; (8) 판정 5조건·`CONVERGENCE_CAVEAT`·태그 재계산; (9) 홀드아웃·`x_train.csv`·`final_holdout` 접근 없음(코드 문자열 검사, 런타임 가드 로그, 실행 로그). 감사 PASS 전에는 보고서를 결과 확정으로 커밋하지 않는다.
- 공개 보고는 집계(지표, 혼동행렬, 판정, 진단 요약)만 `reports/`에 넣는다. 행별 예측·OOF·모델·manifest는 Git에 올리지 않는다. 커밋·푸시는 메인이 조율하고 `peter`에 non-force로 한다.
- 문서 갱신: 완료 시 `docs/RESEARCH_STATUS.md`·`docs/PLAN.md`에 상태를 기록한다. 수행하지 않은 실험은 완료로 표시하지 않는다.

## 11. 홀드아웃과 팀원 경계

`earthquake/data/final_holdout/`에 접근하지 않는다(경로 열거·SHA 포함). 모델 선택·튜닝·early stopping에 쓰지 않는다. 과거 개인 평가에 쓰인 홀드아웃을 재사용하거나 새 독립 성능으로 주장하지 않는다. 코드는 `load_development()`만 쓴다. 팀원 파일 `earthquake/data/x_train.csv`는 열지 않으며, 코드에 그 경로 문자열을 넣지 않는다. 팀원 브랜치(EY·jjjjin·sy)는 접근·수정하지 않는다. 팀원 성능과의 비교도 하지 않는다.

**런타임 가드(M5):** 실행기의 모든 파일 열기·경로 해석 지점에서 경로를 정규화해 `final_holdout`을 포함하거나 파일명이 `x_train.csv`인 경로면 즉시 예외로 실패시킨다(문자열 검사만으로 대체하지 않는다). `tests/test_derived_bundle.py`에 (a) 해당 경로를 읽으려 하면 가드가 실패시키는 합성 테스트, (b) 일반 개발 경로는 통과하는 테스트를 둔다. 감사는 가드 로그와 코드 검사를 함께 확인한다.

## 12. 한계

1. **팀원 파이프라인의 재현이 아니다.** 같은 이름·같은 식의 파생변수를 우리 Fold 안에서 만든 것이다. 팀원은 `x_train.csv`(전체의 70%) 안에서 지역 평균을 계산했고, 우리는 개발 자료 208,480행의 학습 Fold(80%)에서 계산한다. 모델·하이퍼파라미터도 기준선 그대로라 팀원 성능과 비교할 수 없다.
2. **seed 42 층화 Fold의 반복 노출.** 이 5개 Fold로 이미 수십 개 설정을 비교했다. 선택 통계이며 독립 성능이 아니다. 시드가 하나뿐이다(LGBM-N은 행·열 샘플링이 없어 시드 영향이 작을 것으로 보이나 미확인).
3. **묶음 효과.** 13개(또는 S0의 10개)를 함께 바꿨으므로 변수별 기여, 과거 변수 효과의 합산을 주장하지 않는다. S0로 지역 평균 연령 3열과 나머지 10열은 나뉘지만, 각 덩어리 안의 분해는 없다. S1·S2의 차이도 지역 평균 연령 3열 전체의 효과이며 995 보정 하나의 순수 효과라고 단정하지 않는다.
4. **지역 지문·암기 가능성.** 지역 평균 연령은 지역을 거의 식별한다. 층화 CV는 같은 지역이 학습·검증에 모두 나오므로 성적이 오르더라도 "연령 문맥"의 증거가 아니라 지역 암기일 수 있다. S0와의 비교가 이를 간접적으로 나누지만 지역 암기 자체를 분리하지는 못한다. 미관측 지역 일반화(geo2/geo1 Group)는 이 판정의 범위 밖이며 새로 측정하지 않는다(필요하면 별도 심화 설계).
5. **자기 포함 평균의 학습·검증 분포 차이**(§3.2). 정의를 바꾸지 않으므로 소규모 지역에서 학습 Fold 효과가 과대할 수 있다. S2는 995 행과 비995 행의 자기 포함 규칙이 다르다.
6. **LGBM-N의 새 범주 4열은 native만 시험했다**(원핫 미실행). 범주 조합 효과와 표현 효과가 섞여 있다.
7. **하이퍼파라미터 미조정.** 입력이 바뀌어도 기준선 값 그대로다. 각 팔의 최적 성능이 아니다.
8. **LR 기준선의 증거 수준.** B는 같은 venv의 로컬 재적합이지만 대조는 Fold 0 하나다. 원 환경 산출물(0.688687)과 다른 값(0.688860)이 B이므로 "이후 연구의 LR-C 기준선 0.688687"과의 숫자 연결은 인용 열로만 한다.
9. **모델 간 순위 비교 불가**(LGBM과 LR의 범주 표현·학습 방식이 다름). 모델 계열 간 우열을 말하지 않는다.
10. **다중 비교 6개**와 약한 조건 2(귀무 확률 0.19)로 위양성이 가능하다. `ALL_MET`은 후보 표시일 뿐이다.
11. **설계자가 확인하지 못한 것:** `area_percentage==0` 여부, 지역 수·소규모 지역 비율·995가 섞인 지역 비율, 파생 열 실제 값 범위, S1/S2 평균이 다른 행 비율, 층화 Fold별 지역 미관측 건수, LGBM 범주 4열의 모델 내부 분할 양상, 파생 열 추가 후 LR 실제 수렴 여부·반복 수, 모든 시간 추정, LGBM-N·이 실험에서의 짝지은 ΔF1 SD, T33 구현 코드와 이 설계 코드의 충돌 가능성, 컨트롤 타워가 검증한 `x_train.csv` 계산식(이 문서가 재검증하지 않음), 단일 열 키 기준이 팀원 파일 정의와 같은지(컨트롤 타워 검증식에 의존).

## 13. 승인 필요 항목

1. 범위: 모델 2개(LGBM-N, LR-C) × 팔 {**S0**, S1, S2} + 기준선 B(OOF 재사용). 다른 모델(RF·GBC·DT 등)은 범위 밖임을 확인. S0(10열) 포함 확정.
2. 파생변수 13개 정의(§2)와 열 순서(S0는 #11–#13 제외), #1의 분모 0 발견 시 봉인 전 설계 개정(임의 처리 금지).
3. 지역 평균 연령 정의(§3.2): 학습 행 자기 포함(leave-one-out 아님), 원본 `age` 사용, S1은 995 포함·미관측 지역은 학습 Fold 전체 평균, S2는 995 제외·미관측/전부-995 지역은 학습 Fold 비995 전체 평균, 지역별 단일 열 키.
4. LGBM-N 새 범주 4열은 native categorical(원핫 대안 미실행)(§3.3).
5. 파생 수치 열의 스케일: LR만 학습 Fold 표준화, LGBM은 원값.
6. 연령 정책은 각 기준선의 C 유지, 지역 평균은 대체 이전 원본 `age` 기반.
7. 기준선 B(§5): LGBM-N은 T8 N OOF, **LR-C는 같은 venv의 로컬 재적합 OOF `0601965653…`(0.688860)**, 원 환경 `de43f997…`(0.688687)는 인용 열. SHA·정렬·평균 재현 확인 방법.
8. 대조 재학습 2 fit(봉인 전 `control-check`), **LGBM·LR 모두 확률 1e-9·등급 동일의 엄격 기준(5e-4 허용 폐기)**, LR 실패 시 `LR_B_REFIT` 5 fit 자동 추가 규칙. 대조를 생략하면 30 fit(상한 34)이지만 새 실행기와 기준선의 동일성 증거가 없음.
9. fit 상한·시도 상한: 완료 **32(조건부 37)**, 시도 상한 **36(조건부 41)**, 재시도 규칙(인프라 중단만, 단위당 1회, 전체 4회, 대조 fit 포함).
10. 판정 다섯 조건과 임계: Δ ≥ +0.003, 승수 ≥ 4/5, ΔR3 ≥ 0, 3→1 오류율 Δ ≤ 0, 최악 Fold Δ > −0.003(seed 조건의 대체). 판정군 6개 비교, 다중 비교 규칙(§8.2), LR `CONVERGENCE_CAVEAT` 처리.
11. S1−S0·S2−S0·S2−S1은 임계 없는 기술 비교(§8.3).
12. 보고·진단 지표 목록(§9)과 Fold별 Δ·평균 ± SD 고정 항목.
13. 병렬도(Fold 직렬, 기준선과 같은 스레드)·실행 조건·다른 학습과 동시 실행 금지, 시작 시점은 컨트롤 타워 결정.
14. 코드 위치(`experiments/derived_bundle/`, `tests/test_derived_bundle.py`), 기존 코드 import 전용, `preprocess.py` 불변, `x_train.csv`·`final_holdout` 런타임 가드, 배타 `RUNNING.lock`·`attempts.jsonl`·실패 시도 보존, 실행 순서 "구현 → 전체 unittest → peter 커밋(40자 SHA) → preflight → control-check → prepare 봉인".
15. 실행 주체(한 번에 한 주체, 모델 지정은 AGENTS 규칙)와 예상 시간(약 25~65분, 미측정) 수용.
16. 공개 보고 범위(집계만)와 파일명, 독립 감사 후 커밋 순서.
17. 한계 수용(§12): 팀원 파이프라인 재현이 아님, seed 42 반복 노출, 묶음 효과(AGENTS "한 요소씩" 원칙의 묶음 평가 예외, S0로 2덩어리만 분리), 지역 지문 가능성, geo2 심화 미실행.
18. 범위 밖 확인: 변수별 분해, leave-one-out 평균, 원핫 대안 팔, 다른 모델, 튜닝, geo2/geo1 평가, 팀원 파이프라인 재현·성능 비교, 최종 모델 교체, 홀드아웃.
19. 결과를 본 뒤 기준·팔·정의를 바꾸지 않는다(변경은 새 실험 ID).
