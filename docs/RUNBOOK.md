# 팀 공통 실행 안내

이 문서는 **`main`에 포함된 공통 전처리 v1.0.1**만 대상으로 합니다. 필수 4개 모델과 개인 실험 실행기는 개인 브랜치에서 관리하고, 팀이 승인한 실행법은 이후 이 문서에 통합합니다.

## 평가·데이터 원칙

- 예측 대상: `damage_grade`(1/2/3), 주지표: **Macro F1**
- `building_id`와 정답은 입력 `X`에 넣지 않습니다.
- 전처리의 원핫 인코딩·선택적 수치 스케일링은 **학습 Fold에서만 fit**하고 검증에는 transform만 수행합니다.
- 기존 생성된 개발 208,480건 / 홀드아웃 52,121건 / **80:20·5-Fold·seed 42는 팀 합의 전의 잠정안**입니다. 합의 없이 분할을 다시 만들거나 개인 실험과 비교 결과를 혼용하지 마세요.
- 홀드아웃은 모델 선택·튜닝·조기 종료에 사용하지 않습니다.

## 1. 환경 구성

검증에 사용한 버전은 Python **3.13.5**와 `requirements.txt` 의존성입니다. 팀 PC에서도 같은 조건으로 확인하세요.

```bash
python -m pip install -r requirements.txt
```

## 2. 데이터 준비

이 저장소는 Public이므로 원본·개발·홀드아웃 데이터는 커밋하지 않습니다.

기존 v1.0.1 데이터 패키지가 있다면, 패키지의 `data/` 폴더를 프로젝트 루트에 별도 설치하세요. 팀 공통 배포 경로는 별도 합의가 필요합니다. 기존 개발·분할 파일의 SHA-256은 `configs/data_contract.json`에 기록돼 있습니다.

원본 CSV로 처음 생성할 때는 프로젝트 폴더 **외부**의 데이터로 다음 명령을 사용합니다. 이미 분할 데이터가 있다면 **재생성하지 않아도 됩니다**. 생성 디렉터리는 비어 있어야 합니다.

```bash
python preprocess.py --input ../nepal_building_damage.csv --output data
```

## 3. 공통 검사

```bash
python -m unittest discover -s tests -v
```

- 로컬에 `data/`가 있으면 실제 데이터 통합 검사를 포함해 수행합니다.
- GitHub Actions는 원시 데이터가 없으므로 합성 검사만 통과하고 데이터 의존 검사는 명시적으로 skip할 수 있습니다. **CI 성공은 실제 데이터 학습 성공이 아닙니다.**
- `cv_fold`가 `0.5` 같은 비정수일 때 읽기 단계에서 거절하는 v1.0.1 패치를 유지합니다.

## 4. 개인 연구/팀 결과 통합

실험은 `peter` 등 각 개인 브랜치에서 진행합니다. 공통 분할과 평가 지표가 확정된 후 PR로 코드·설정·검증 요약만 검토해 `main`에 통합하세요. 팀원의 개별 수행과 결과 확인 없이 개인 결과를 팀 전체가 수행한 것처럼 작성하지 마세요.

`data/`, `outputs/`, 원본 CSV, 홀드아웃 정답, 건물별 OOF, 모델 파일 및 자격증명은 공개 저장소에 넣지 않습니다. `.gitignore`는 실수 방지 장치이므로 실제 커밋 파일 목록도 확인해야 합니다.
