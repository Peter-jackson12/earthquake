# Earthquake — 모델 계열 비교 연구 (XGBoost·LightGBM vs LR)

> **새 ChatGPT 세션에 붙여넣을 인계문** · 작성 2026-10-14 KST · 진행 전 [연구 현황](RESEARCH_STATUS.md)과 GitHub의 실제 최신 HEAD부터 확인한다.

## 0. 목표

GitHub `Peter-jackson12/earthquake`의 개인 연구에서 **동일 데이터·동일 Stratified 5-Fold·동일 주지표 Macro F1** 조건으로 XGBoost/LightGBM을 기존 LR과 비교한다. **LR 전처리 변경 연구(T1)와 지역·기초구조·연령 조합 G1~G5 연구(T3)는 다른 세션에서 별도로 진행 중**이므로, 이 세션은 **모델 계열 효과(T4)를 먼저 분리**하는 데 집중한다.

새 모델의 개발 CV Macro F1이 0.7을 넘는지뿐 아니라 **3→1 심각한 과소예측, 3→2, 3등급 Recall, 원본995 집단의 오류**까지 확인한다. 결과를 미리 정하지 않고 학습·OOF·감사를 통해 판단한다.

**이 문서는 인계 및 실행 계획이다. XGBoost/LightGBM 학습을 이미 완료했다는 뜻이 아니다.** 다른 조원이 XGBoost로 Macro F1 >0.7을 냈다는 사용자 보고는 참고사항이지만, 같은 데이터·분할·평가·OOF 규약이 확인되기 전까지 직접 비교 결과가 아니다.

## 2. 고정 데이터·평가 계약

- 원본: 260,601행, 40열(입력38 + `building_id` + `damage_grade`). `building_id`는 모델 입력에서 제외.
- 개발: **208,480행**; 원래 고정 **Stratified 5-Fold, seed=42**. 학습166,784 / 검증41,696행 per Fold.
- 이전 홀드아웃: **52,121행**, 개인 최종 평가에 이미 사용. **재평가·재튜닝·최종 선택에 재사용 금지**.
- 데이터 SHA-256: 원본 `87abd2bc2b05d3e687bd176959967fd38334fff607e6afeb2d20d0d899c13e97`, 개발 `8ef0302a90fc66a49f20fdaefc8e7302ef4bbd3ca2b8b7b741a52f0503ce31b1`, 분할 `7673dbeb136e9a916c67a3b19928b3fbc621ae627a5667a677a1ca6eae838721`.
- 정답 라벨1/2/3. 주지표 **Macro F1 평균**, Fold 간 표준편차(ddof=1). **pooled OOF F1은 별도** 기록. 부지표 등급별 P/R/F1, 3등급 Recall, 원시·정규화 혼동행렬, 3→1·3→2(건수/실제 3등급 분모), `age=995`/비995, 지역·구조의 표본 수와 악화.
- 누수 방지: 분할과 검증 행을 그대로 유지하고, 인코더·대체 통계·기타 학습형 변환은 **각 훈련 Fold에서 fit**, 검증 Fold에는 transform만. 학습 행 삭제·리샘플링·클래스 가중치는 첫 비교에 도입하지 않는다.
- 원본 CSV·행별 OOF·라벨·모델 바이너리는 공개 GitHub에 업로드하지 않는다. 실험 설정·코드·검토된 집계와 SHA·재현 방법만 공개.

## 3. 기존 결과 — 비교 기준만 재사용

이전 LR A/B/C/D/E/F는 **로지스틱 회귀·기존 Fold로 수행된 전처리 비교**다. 아래 숫자는 새 모델 결과가 아니다.

| LR 기준 | 처리 | CV Macro F1 |
| --- | --- | ---: |
| A | `age=995` 원값 유지 | **0.683677** |
| C | 각 학습 Fold 비995 중앙값(각 Fold 15)으로 995만 대체 + 원본 표시 변수 | **0.688687** |
| E2 | 학습 Fold 비995 q99(각 Fold 90)으로 995만 절단 + 표시 | **0.688664** |

C는 **LR 연구에서 채택한 비교 기준**일 뿐, XGBoost/LightGBM의 최선 정책이라고 가정하지 않는다. 트리 모델은 큰 값을 구간 분할할 수 있으므로 A를 우선 직접 비교해야 한다. `age=995`가 공식 결측 코드인지 여부는 확인되지 않았다.

저장된 LR 원시 OOF와 메타데이터를 쓸 수 있다면 해시·ID·정답·Fold·모델 설정 일치 시 재사용하고, 없으면 숫자만 **이전 근거**로 인용하며 같은 실험의 완전한 쌍별 재검증을 했다고 주장하지 않는다.

## 4. 실행할 첫 실험 — 모델과 전처리 요인 분리

우선 **미튜닝 고정 하이퍼파라미터**(시드·모델 버전·예산을 결과 열람 전에 문서화), 동일 분할·동일 특성 출발점으로 아래 2×2를 수행한다.

| 실험 ID 제안 | 모델 | age 처리 | 직접 비교 |
| --- | --- | --- | --- |
| `XGB_A_v1` | XGBoost | A 원본995 유지 | 기존 LR-A, XGB-C |
| `XGB_C_v1` | XGBoost | C 중앙값+표시 | 기존 LR-C, XGB-A |
| `LGBM_A_v1` | LightGBM | A 원본995 유지 | 기존 LR-A, LGBM-C |
| `LGBM_C_v1` | LightGBM | C 중앙값+표시 | 기존 LR-C, LGBM-A |

- **4설정 × 5-Fold = 신규 20 fit**가 1차 계획이며, 실행 전 실제 자원·패키지 가용성 확인. 학습하지 않았으면 결과를 비워 둔다.
- XGBoost/LightGBM은 다중분류 3클래스, seed 고정, **첫 라운드는 무가중치·무샘플링·동일 인코딩 정책**으로 진행한다. 범주형 변수와 지역 코드를 연속 수치 순위로 취급하지 않는다.
- 첫 비교에서 가능하면 Fold별 fit된 기존 전처리·OneHot 표현을 공통 출발점으로 사용한다. 트리에 불필요한 표준화 제거, native categorical 채택, `num_leaves`/`max_depth`/`n_estimators` 등 변경이 동시에 들어가면 그 효과를 단일 **모델 계열 효과**로 주장할 수 없다. 불가피한 모델별 전처리 차이 및 라이브러리 버전을 모두 기록한다.
- 조기 종료(early stopping)를 사용한다면 **해당 Outer Fold의 검증 데이터를 stopping/튜닝에 사용하지 않는다**. 필요 시 학습 Fold 내부 분할만 쓰고, 외부 Fold는 평가 전용으로 보존한다.
- LightGBM/XGBoost 버전 및 CPU 스레드·학습 시간·메모리·수렴/경고/예측 확률 검증을 기록한다. 이 단계에서 Optuna/대규모 그리드/새 특성 조합을 함께 실행하지 않는다.
- E2는 **추가 후보**로 남긴다. A/C의 첫 비교 결과와 오류 패턴을 보고 필요할 때 **별도 실험 ID·사전에 확정한 비교 기준**으로 진행한다. G1~G5 조합은 별도 세션의 결과와 섞지 않는다.

## 5. 산출물과 독립 감사

- 새 실험마다 ID, 설정 JSON, 소스 커밋·패키지 버전, 데이터·분할 SHA, Fold별 fit 행/예측 행 수, 변환 통계·클래스별 빈도, 시간·수렴 경고 기록.
- **Fold별 Macro F1, 평균/표준편차, pooled OOF, Accuracy(=Micro F1), 등급별 P/R/F1, 혼동행렬, 3→1·3→2, 실제 3등급 Recall**, `age995`/비995 그룹과 지역별 성능·표본 수를 모두 보고한다. 모델 간 심각한 과소예측이 개선됐는지 명시.
- 공개하지 않는 행별 OOF를 이용해 **학습기와 독립된 감사 함수**로 ID/Fold/정답·확률 합·중복·분모·등급별 지표·예측 변경을 검증한다. 단순 파일 존재는 성능 검증이 아니다.
- 일관된 평가 계약으로 5 Fold 전체가 유효할 때만 기준 LR과 비교한다. Fold 평균 점수 차이를 통계적 유의성·다른 지진에 대한 일반화로 과장하지 않는다.
- 결과가 LR보다 좋더라도 **개인 최종 모델, 팀 최종 모델, `app.py`, `main`을 자동 교체하지 않는다**. 별도 공유·검토 결정이 필요하다.

## 6. 다른 세션과 충돌하지 않는 작업 범위

- **진행 중인 다른 세션(T3)**: C 고정 LR에 연령 구간과 지역/구조/연령 교차특성을 더하는 G1~G5 연구. 코드 소유 경로 `experiments/age995/interactions/`. 이 결과를 기정사실로 두거나 수정하지 않는다.
- **이 세션(T4)**: XGBoost/LightGBM 모델 계열 비교. 신규 `experiments/model_families/`, `reports/MODEL_FAMILY_*`, `tests/test_model_families*.py` 등 독립 경로 권장. 새 브랜치에서 진행하여 T3와 격리한다.
- 기존 `preprocess.py`, 원본 데이터, 기존 `experiments/age995/` 코드, A~F 산출물, T3 설정, `main`, `peter`의 최종 모델은 원칙적으로 변경하지 않는다.
- 다른 세션 커밋이 반영됐다면 **최신 HEAD와 비교 후 안전하게 갱신**한다. 강제 push, rebase 이력 재작성, 기존 결과 덮어쓰기는 금지. 커밋 한국어 권장.
- 모델 비교가 완료되면 [연구 현황](RESEARCH_STATUS.md)의 T4를 **코드만/합성테스트/실데이터 CV/독립 감사/완료** 중 확인된 정확한 상태로 업데이트하고 증거 링크를 붙인다.
