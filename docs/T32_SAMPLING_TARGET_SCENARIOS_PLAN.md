## 0. 배경 — 이 설계가 필요한 이유

기존 층화 결과에서 불균형 처리는 모두 **완전 균등화**(모든 등급을 같은 건수로 맞춤) 한 점만 평가됐다. 가중치·재표집은 Macro F1을 떨어뜨리거나(LR) 올리면서(RF) 거의 예외 없이 3→1을 크게 늘렸다([층화 종합](../reports/STRATIFIED_SUMMARY_20261016.md) 표1: LR balanced 3→1 467→2,445). "원분포(처리 없음)"와 "완전 균등" 사이의 **중간 지점**이 있는지, 3→1 증가가 1등급 증강과 3등급 증강 중 어디서 오는지, 같은 목표 비율을 **행 복제/삭제로 만들 때와 가중치로 만들 때** 같은지는 아직 답이 없다. 또 과제 필수 항목인 "처리 후 등급별 건수와 원본 대비 변화량"이 지금까지 일부 보고(RUS: 16080/94885/55819 → 각 16080, ROS: 각 94,885 또는 94,886)에만 있고 시나리오 표로 정리돼 있지 않다.

## 3. 시나리오 정의와 목표 건수 산식 (학습 전 고정)

### 3.1 기호와 규칙

- 한 학습 Fold의 원본 등급 건수 `n1, n2, n3`(`n2`가 최다, `n1`이 최소; **봉인 시 대소 순서를 검사하고 어긋나면 중단**). 합계 `N`. 목표 건수 `t1, t2, t3`는 Fold마다 **그 Fold의 학습 건수에서 계산**한다. 검증 Fold는 어떤 시나리오에서도 변경하지 않는다.
- **부분 완화 비율 φ = (격차를 채우는 비율).** φ = p/q(분수로 고정: 1/4, 1/2, 3/4, 1).
- **올리는 방향(UP, 복제 기반 ROS와 가중치)**: 2등급 불변, `t_c = n_c + add_c`, `add_c = floor((2·p·(n2−n_c) + q) / (2·q))`(정수 연산, 0.5는 올림), c ∈ {1, 3}. `t2 = n2`.
- **내리는 방향(DOWN, 삭제 기반 RUS)**: 1등급 불변, `t_c = n_c − rem_c`, `rem_c = floor((2·p·(n_c−n1) + q) / (2·q))`, c ∈ {2, 3}. `t1 = n1`.
- φ=0은 원분포, φ=1은 완전 균등(UP은 기존 ROS, DOWN은 기존 RUS와 같은 목표). 부동소수점 반올림(`round`)은 쓰지 않는다(경계 0.5 처리 차이 방지).
- 분해 시나리오(UP, 복제만): `ONE1` = 1등급만 `n2`까지(`t=(n2, n2, n3)`), `ONE3` = 3등급만 `n2`까지(`t=(n1, n2, n2)`).
- 대안(채택하지 않음): 지수 보간 `t_c = n_c·(n2/n_c)^α`(sklearn class-weight power 관례). 선형 격차 채움이 건수를 직접 읽기 쉬워 선택했다. 승인 항목이다.

**UP와 DOWN은 같은 φ에서 같은 목표 비율이 아니다.** 예: 1등급/2등급 비는 UP50 0.585, DN50 0.290이고 총 학습 건수(225,720 대 107,511)도 다르다. 따라서 φ가 같다고 UP과 DOWN을 "같은 처리 강도"로 비교하지 않는다(§10 방향 비교는 기술 비교로 한정). DOWN에는 짝이 되는 가중치 팔을 두지 않는다.

### 3.3 가중치 팔의 "유효 목표 건수" (행 수는 불변)

가중치 팔은 학습 행을 바꾸지 않으므로 **등급별 가중 합(유효 질량)**을 목표 건수로 기록한다.

- **LR의 W-OBJ(복제 등가)**: `w_c = t_c / n_c`, 정규화 없음. LR 목적함수 `C·Σ s_i ℓ_i + ½‖β‖²`에서 행 복제는 행별 정수 가중치(1+추가 복제 횟수)와 같은 식이다. ROS는 이 행별 가중치를 난수로 정하므로 **등급별 합(유효 질량)이 `t_c`로 같고 기댓값에서 W-OBJ(등급별 균일 가중치)와 같을 뿐, 한 표본에서 목적함수가 정확히 같지는 않다.** 차이는 복제 추출 난수와 최적화 허용오차에서 온다. W-OBJ의 유효 질량은 `t_c`와 정확히 같다.
- **트리(LGBM-N, RF)의 W-NORM**: `w_c = (t_c / n_c) · N / Σt`(합 = N, sklearn `balanced`·GBC `sample_weight` 관례). 트리는 가중치 척도에 거의 불변이므로 이 관례를 쓴다. EQ(φ=1)에서 `N/(3·n_c)`가 되어 기존 `class_weight='balanced'`와 일치한다(벡터 일치 검사, 학습 불필요).
- Fold 0 예시 가중치: W-OBJ — UP25 (2.2252, 1, 1.1750), UP50 (3.4504, 1, 1.3499), UP75 (4.6756, 1, 1.5249), EQ (5.9008, 1, 1.6999). W-NORM — UP25 (1.8911, 0.8498, 0.9985), UP50 (2.5495, 0.7389, 0.9975), UP75 (3.0559, 0.6536, 0.9966), EQ (3.4574, 0.5859, 0.9960). 
- 참고: 기존 `LR.BAL`(`balanced`, 합 = N)은 W-OBJ EQ와 **상대 비율은 같고 전체 척도만 1.707배(=284,655/166,784) 작다**. LR에서 이는 사실상 규제 강도(C)의 척도 차이이므로, LR.BAL vs W-OBJ.EQ 차이는 "규제 척도 효과"이고 ROS.EQ vs W-OBJ.EQ 차이는 "복제 난수 효과"다. 둘을 별도 비교로 보고한다.

### 3.4 기록 규칙 (필수 항목 충족)

모든 셀·Fold마다 `before`(학습 원본 등급 건수), `target`(산식 결과), `after`(실제 처리 후 건수), `delta = after − before`, `multiplier`, 처리 후 비중, 학습 행수, 가중치 벡터와 유효 질량, 샘플러 seed, 추출 인덱스(복제 다중집합 또는 유지 인덱스)의 SHA-256, 검증 Fold 등급 건수(불변 확인)를 원장 `sampling` 블록에 저장한다. **`after ≠ target`이면 즉시 중단**한다(샘플러 계약 위반). 공개 보고에는 Fold별 건수 표(집계)를 싣는다.

## 4. 팔(arms) 정의와 셀 목록

### 4.1 LR (기본 모델) — T0 개인 최종 LR C=1, v1.0.1 전처리

공통: `LogisticRegression(solver='lbfgs', C=1, max_iter=1500, tol=1e-4, random_state=42)`, 전처리 `make_preprocessor(scale_numeric=True)`를 **샘플링 전 학습 Fold 전체에서 fit**, 샘플링은 인코딩된 CSR 행 선택(원본 행 뒤에 추가 행을 쌓는 T0 `PersonalSamplingLR`과 같은 구성), `.toarray()` 없음, `threadpool_limits(1)`.

| 팔 | 설명 | 새 셀 | 재사용 | 샘플러 seed |
|---|---|---|---|---|
| R-UP | `RandomOverSampler(sampling_strategy={1:t1, 3:t3}, random_state=seed)` — **2등급(고정 등급) 키 제외, 키는 오름차순 삽입** | P25, P50, P75, ONE1, ONE3 | EQ(`personal_random_over`), ORI | 42 |
| R-DOWN | `RandomUnderSampler(sampling_strategy={2:t2, 3:t3}, random_state=seed)` — **1등급(고정 등급) 키 제외** | P25, P50, P75 | EQ(`lr_rus`) | 42 |
| W-OBJ | 위 3.3의 복제 등가 가중치, 행 불변 | P25, P50, P75, EQ | ORI | — |
| 소음 셀 | R-UP P50, R-DOWN P50을 샘플러 seed만 바꿔 반복 | 각 2 seed | — | 101, 202 |
| 참고 | LR.BAL, LR.SMOTE.EQ | 없음 | 있음 | — |

- **고정 등급 키를 dict에 넣지 않는다 (imblearn 0.14.1 소스를 동결 venv에서 읽어 확인).** `RandomUnderSampler._fit_resample`은 `np.unique(y)` 순서로 돌며 `sampling_strategy_`에 키가 있는 등급마다 `random_state.choice(range(n), size=…, replace=False)`를 호출한다. 키에 1등급을 넣으면 `size=n1`짜리 순열 추출이 일어나 난수 상태가 소모되고 이후 2·3등급 선택이 `'auto'`(1등급 키 없음)와 달라진다. 그러면 control c3가 실패하고 `lr_rus` 재사용이 무효가 된다. `RandomOverSampler._fit_resample`은 `sampling_strategy_` dict의 **삽입 순서**대로 등급별 `choice(…, replace=True)`를 호출하므로, 키는 오름차순으로 넣고 2등급(추가 0)은 제외한다. dict 검증(`_sampling_strategy_dict`)은 지정한 키만 검사한다.
- **봉인 전 필수 게이트 G-IDX (학습 없음, 라벨만 사용)**: 5개 Fold 모두에서, 학습 Fold 라벨에 대해 (a) R-DOWN dict(φ=1)의 `sample_indices_`가 `RandomUnderSampler(random_state=42)` `'auto'` 경로와 정확히 같은 정수 배열, (b) R-UP dict(φ=1)의 `sample_indices_`가 `RandomOverSampler(random_state=42)` `'auto'` 경로와 정확히 같은 정수 배열임을 확인한다. 하나라도 다르면 `prepare`를 거부한다. 합성 단위 테스트와 실제 개발 라벨 검사 둘 다로 구성한다.
- **부분 완화 추출의 포함 관계(소스 독해 기준, 합성 테스트로 확인 예정)**: 같은 seed에서 R-UP의 1등급 추가분과 R-DOWN의 선택 집합은 φ가 커질수록 앞선 집합을 포함(nested)하지만, R-UP의 3등급 추가분은 1등급 추출 뒤에 같은 난수열을 이어 쓰므로 φ마다 비포함(non-nested)이다.
- **샘플링 순서**: 스키마·인코더·스케일러 fit(샘플링 전 학습 Fold 전체) → 샘플링 → 학습. 인코더/스케일러를 복제 행에 fit하지 않는다. 독립 감사가 저장 전처리 상태가 샘플링 전 학습 Fold 통계와 일치하는지 재계산한다.

### 4.2 LGBM-N (층화 상위, 확장 모델)

T8 N과 동일: C 전처리 + 범주 11열 native categorical(학습 Fold 어휘, 미관측은 NaN), 파라미터 `experiments/lgbm_native_cat/config.json` 그대로(300 rounds, lr 0.05, num_leaves 31, `n_jobs=2`, `random_state=42`, 조기 종료 없음). T8 코드는 import만 하고 수정하지 않는다.

| 팔 | 설명 | 새 셀 | 재사용 |
|---|---|---|---|
| W-NORM | `sample_weight`(합 = N 관례), 행 불변 | P25, P50, P75, EQ | ORI(T8 N) |
| R-UP | ROS 행 복제(원본 행 뒤 추가) | P50, EQ | ORI |

R-UP을 P50·EQ 두 점만 하는 이유: 복제 팔은 학습 행이 최대 1.7배라 비용이 늘고, 가중치와 복제는 LightGBM에서 `min_child_samples`·`min_data_per_group`(행 수 기준)와의 상호작용이 달라 **서로 같은 결과를 보장하지 않는다**. 그 차이를 두 점에서 확인하면 충분하다고 본다(승인 항목).

### 4.3 RF (선택 확장 — 승인 시)

T0의 RF(`n_estimators=100, max_depth=20, min_samples_leaf=2, max_features=0.1, random_state=42`)에 `class_weight` dict(W-NORM)를 적용한다. 새 셀 P25, P50, P75(15 fit). ORI=`feature_budget/rf`, EQ=`class_weights/rf`(balanced)를 재사용한다. RF 예측은 T14 교훈에 따라 **단일 스레드**로 한다(다중 스레드 합산 순서에 따른 ~1e-16 변동 방지).

## 5. 모델 범위 판단 (비용·의미)

### 5.1 포함
- **LR(전부)**: 개인 최종 모델, 기존 완전 균등 셀이 이미 있고 비용이 가장 작다(Fold당 약 4~27초). 모든 시나리오·메커니즘을 채운다.
- **LGBM-N(가중치 4 + 복제 2셀)**: 층화 CV 2위(0.699342). 학습 약 12초/회(T8 원장 실측)라 저비용. 층화 상위 모델에서 불균형 처리가 어떻게 작용하는지 필수 질문(Q5)에 답한다.

### 5.2 선택 확장
- **RF(가중치 3셀)**: T0 필수 4모델 중 RF의 불균형 효과가 컸고(무가중치→balanced +0.0189, 3→1 187→1,862), 로컬 5 fold 학습이 약 4~5분(`class_weights/rf` 총 261.6초)이라 비용도 작다. 단 T0 RF(0.6479)는 층화 상위가 아니다. 포함 여부는 승인 항목이다. 기본 제안은 **포함**(필수 모델 트리 대표성).

### 5.3 제외와 이유
- **T14 RF 계열(0.700427)**: TE·지역 빈도·ROS·원시 geo ID·age 원값이 한 파이프라인에 묶여 있고 요인이 분리되지 않았다. 여기에 목표 비율을 얹으면 "ROS가 이미 포함된 모델의 ROS 비율 변경"이 되어 해석이 불가능하다. 25 fit이 2~5시간 추정이라 비용도 크다. 제외한다.
- **DT·sklearn GBC**: 필수 모델이지만 T0에서 완전 균등(가중치) 비교를 이미 했고, 부분 완화의 한계 정보가 작다. 비용(GBC 약 50초/fold)과 범위 때문에 이번 범위 밖이며 **미수행**이다. 보고서에 "DT·GBC 부분 완화: 미수행"을 표로 남기고 완료로 표시하지 않는다.
- **XGBoost·CatBoost 등**: 층화 결과가 없거나 가이드 필수 아님.

### 5.4 제약형 SMOTE
부분 완화 SMOTE는 새로 만들지 않는다. T0에서 SMOTE와 ROS의 차이는 CV 0.00003로 사실상 같았고(실제 보간으로 값이 바뀐 행은 추가 행의 약 32%, 나머지 복제 fallback) `make_plan`이 `'auto'` 균등 목표를 내부에서 고정해 쓰므로 부분 목표를 지원하려면 **동결 코드(`personal_sampling.py`)를 수정하거나 복제**해야 한다. 이는 위험·비용 대비 정보가 작다. **가이드의 SMOTE 계열 부분 완화 질문은 이 실험이 답하지 않는다(미수행).** SMOTE 계열은 기존 제약형 SMOTE 완전 균등 참고 셀과 SMOTENC 불채택 근거로만 다룬다. 포함 요청 시 별도 설계(승인 항목 3).

### 6.1 control(통제 재학습) — 연구 fit 횟수에 넣지 않되 상한 8회(RF 포함 10회)

T8이 O 팔에서 한 방식과 같다. 재사용 셀이 **T32 실행기가 만드는 셀과 같은 계산 경로**임을 확인하기 위해 재학습하고 저장 OOF의 해당 Fold와 비교한다. **Fold 0(2등급 94,885)과 Fold 2(2등급 94,886) 두 곳**에서 한다. 통과 기준(제안): 예측 등급 100% 일치, 확률 최대 절대차 ≤ 1e-9.

| control | 비교 대상 | 확인하는 것 | fit |
|---|---|---|---:|
| c1 | LR.ORI Fold 0·2 vs `personal_none` | T32 LR 실행 경로 = 기존 경로 | 2 |
| c2 | LR.ROS.EQ(dict `{1,3}`) Fold 0·2 vs `personal_random_over` | 추출·행 순서 동일 | 2 |
| c3 | LR.RUS.EQ(dict `{2,3}`) Fold 0·2 vs `lr_rus` | 전처리→RUS→LR 경로 동일 | 2 |
| c4 | LGBMN.ORI Fold 0·2 vs T8 N | LightGBM N 경로 | 2 |
| c5(RF 포함 시) | RF 균등(dict 가중치) Fold 0·2 vs `class_weights/rf` | RF 가중치 dict = `balanced` | 2 |

- G-IDX(§4.1)는 5개 Fold 모두의 추출 인덱스 동일성을 학습 없이 보증하므로, control은 학습 계산 경로의 동일성(BLAS 등)을 두 Fold에서 보는 용도다. Fold 1·3·4의 재사용 자격은 G-IDX + 지표 재계산으로 확인한다.
- control **실패 시** 해당 재사용 셀은 비교 기준으로 쓰지 않는다. 대신 그 셀을 새 학습으로 채워야 하며(최대 ORI 5 + ROS.EQ 5 + RUS.EQ 5 fit, 필요시 LGBMN.ORI 5·RF 10) **추가 승인 없이는 진행하지 않는다.**
- `LR.BAL`과 `LR.SMOTE.EQ`는 참고 셀이라 control 없이 쓰며 해석 시 "경로 미통제" 단서를 붙인다.
- 벡터 일치 검사(학습 없음): W-NORM EQ 가중치 = `compute_sample_weight('balanced', y_train)`와 상대오차 1e-12 이내.

## 7. 누수 방지

- 모든 변환·인코딩·스케일러·범주 어휘는 학습 Fold에서만 fit. 샘플러·가중치 계산도 학습 Fold 라벨만 입력. 검증 Fold의 행·라벨은 샘플러/가중치/전처리에 전달되지 않는다(함수 서명과 테스트로 강제).
- 검증은 원분포 41,696행 그대로. 샘플링 후 건수는 학습에만 해당한다.
- 홀드아웃 경로 가드: 실행기·테스트가 `final_holdout` 경로 접근 시 실패하도록 한다(T14 선례). 이 설계 작성에서도 접근하지 않았다.
- 모델 선택·early stopping·튜닝 없음. 하이퍼파라미터는 기존 값 그대로다.

| RF(선택) | W-NORM 3셀 | 15 |
| **총계 (RF 포함)** | 새 셀 25개 | **125** |

- 신규 fit 상한: **RF 제외 110, 포함 125** (재사용 셀은 이 숫자에 포함하지 않으며 신규 실행으로 표시하지 않는다). control은 별도 최대 8회(RF 포함 10회), 연구 fit이 아님을 원장에 표시. 시도 상한 = fit 상한.
- **사전 고정 3단계 실행(기본 순서, 검토자 제안 채택)**: 단계마다 사용자 승인으로 진행하며 **단계 결과를 보고 나머지 설계(시나리오·팔·임계)를 바꾸지 않는다**(진행 중단만 가능).

| 단계 | 셀 | 단계 fit | 누적 fit | control |
|---|---|---:|---:|---|
| 1 | LR R-UP P25·P50·P75 + LGBM-N W-NORM P25·P50·P75 | 30 | 30 | c1, c4 |
| 2 | LR W-OBJ P25·P50·P75·EQ + LGBM-N W-NORM EQ | 25 | 55 | c2 |
| 3 | LR R-UP ONE1·ONE3, R-DOWN P25·P50·P75, LGBM-N R-UP P50·EQ, 소음 4셀 | 55 | 110 | c3 |
| 3'(RF 선택) | RF W-NORM P25·P50·P75 | 15 | 125 | c5 |

  1단계는 §10 용량-반응의 핵심(샘플링·가중치 부분 완화가 두 모델에서 어떻게 움직이는가)을 답하고, 2단계에서 샘플링 대 가중치(Q4)와 균등점이 채워지며, 3단계가 분해(Q3)·방향·소음을 채운다. 단계 사이에 집계 점검(원장·SHA·수렴)은 하되 중간 결과로 후속 단계의 구성을 바꾸지 않는다.
- **재시도: 자동 재시도 0회.** 학습 실패·비수렴·확률 이상은 원본·실패 로그를 보존하고 중단한다. **수동 복구**(프로세스 소실·정전처럼 학습이 끝나지 않고 사라진 경우에 한해, 완료 단위는 해시만 검증하고 미완료 단위만 이어서 실행)의 허용 여부와 횟수(제안 1회)는 승인 항목이며 승인 전에는 0회다. 수동 복구 시 시도 상한은 중단 단위 재시작분만큼 늘 수 있다.
- LR 비수렴(`ConvergenceWarning`)은 Fold 실패로 간주하고 **실험 전체를 중단**한다(자동 재시도 0, 이후 셀로 우회 금지). 이미 완료된 셀은 보존되지만 중단 지점 이후는 `max_iter` 등 설정 변경 없이는 진행할 수 없고, 변경은 새 사전등록과 승인이 필요하므로 후속 단계 전체가 지연된다. 가중치 5.9배의 W-OBJ·ONE1에서 lbfgs 반복이 늘 수 있다(미측정). `max_iter`를 사후에 올리지 않는다.
- 병렬화는 한 단계만: 셀·Fold 순차, LR `threadpool_limits(1)`, LGBM `n_jobs=2`, RF 학습 `n_jobs=2`/예측 단일 스레드(최종값은 기존 로컬 재현의 `jobs=2` 기록과 `prepare`에서 대조 — 미확인). 학습 실행 담당은 한 번에 한 주체. 희소 행렬 `.toarray()` 금지(LGBM-N은 T8과 같은 밀집 float32 39열이며 CSR을 전체 변환하지 않는다).

### 8.2 예상 시간 (측정 근거와 추정 구분)

측정 근거(로컬 재현 `results.json`·T8 원장): LR 무처리 약 15.5초/fold, LR ROS 약 27초/fold(284,655행), LR balanced 약 13초/fold, LR RUS 약 3.8초/fold(48,240행), LGBM-N 약 12초/fit, RF balanced 총 261.6초/5 fold.

**아래는 미측정 추정이다.** 학습 행수에 대략 비례한다고 가정하면 LR R-UP 5셀 약 9분, R-DOWN 3셀 약 2분, W-OBJ 4셀 약 5분, 소음 4셀 약 5분, LGBM-N 6셀 약 7분, RF 3셀 약 13분. **순수 학습 합계 약 28분(RF 제외)~41분(RF 포함).** 모델 저장·재로딩 검증·CSV 왕복·백업 복사·전처리 비용과 control, 원장 기록을 포함하면 약 1.5~3시간으로 예상한다. 집계·독립 감사 시간은 별도다. 첫 셀 로그로 추정을 고쳐 보고하고, 추정이 틀려도 설계·판정은 바꾸지 않는다. 디스크: LR 모델은 작고(계수 행렬) RF joblib이 가장 크며 원본+`backup/` 2벌 모두 합쳐 수 GB 이내로 추정한다(비공개, 미측정). `prepare`는 여유 용량 하한을 확인한다.

## 9. 체크포인트·원장·재개·감사·보고 (AGENTS 운영 순서)

운영 순서는 **로컬 데이터 보존 → 실험별 체크포인트 → 독립 감사 → GitHub 보고**다.

1. **봉인 전**: 승인된 계획·설정·코드·합성 테스트를 `peter`에 커밋하고 `python -m unittest discover -s tests -v`를 실행해 pass/skip을 구분한다. **봉인 전 필수 게이트: G-IDX(§4.1, 5개 Fold 추출 인덱스 동일성).** 합성 테스트 필수 항목: 목표 건수 산식(경계 0.5 올림, 대소 순서 위반 시 중단), `after == target` 강제, ROS/RUS dict 추출 계약(고정 등급 키 제외·삽입 순서), 검증 Fold 불변, 가중치 벡터 일치, W-OBJ와 복제의 목적함수 등가(소형 합성 LR), 샘플링 전 전처리 fit, 홀드아웃 경로 가드. `prepare`가 소스·설정·이 계획·환경·개발 데이터 계약·manifest·재사용 OOF/T8 산출물 SHA·Fold별 건수·목표 표를 전체 커밋 SHA로 결속한다. 기존 봉인 파일·출력은 수정·덮어쓰지 않는다.
2. **Fold 체크포인트**: 셀·Fold마다 모델, 전처리 상태, 샘플링 기록(3.4), 검증 ID·정답·확률(17자리 왕복), 지표, 수렴 정보, 학습 시간을 저장하고 SHA-256과 상태를 원장에 기록한다. 저장 직후 모델 재로딩 확률 최대 절대차 ≤ 1e-12(RF는 단일 스레드), CSV 왕복 정확 일치, 별도 `backup/` 사본 SHA 확인 후에만 `complete`. 완료 단위는 해시만 검증하고 재학습하지 않으며 `RUNNING.lock`은 배타적으로 생성한다.
3. **집계(`finalize`)**: 비공개 `analysis.json` — Fold 평균/SD(ddof=1), 풀링 지표(등급별 P/R/F1·지지, 혼동행렬, 정확도), 3→1·3→2·2→3 건수와 분모(실제 3등급 69,774), 예측 등급 비중, 시나리오별 φ 곡선, Δ 표(§10), 소음 셀 퍼짐, 샘플링 기록 요약.
4. **독립 감사**: 실행기를 import하지 않는 별도 담당이 (a) 재사용 OOF·T8 산출물 SHA·정합 재확인, (b) 목표 표를 개발 CSV·manifest·산식에서 처음부터 재계산, (c) 샘플링 기록의 `after`가 목표와 같고 추출 인덱스가 학습 위치 부분집합인지·검증 불변인지, (d) 저장 전처리 상태가 샘플링 전 학습 Fold 통계와 일치하는지, (e) 가중치 벡터 재생성, (f) OOF가 개발 행과 1:1이고 `argmax==y_pred`, (g) 모든 지표·Δ·라벨을 sklearn으로 처음부터 재계산, (h) 저장 모델 native 재추론 확률차, (i) 홀드아웃 비접근을 확인한다. 감사 PASS 전에는 공개 성능 보고를 확정하지 않는다.
5. **공개 보고**: 감사 PASS 뒤에만 `reports/`에 집계 보고서(제안 `SAMPLING_TARGET_SCENARIOS_20261016.md`)와 집계 JSON을 커밋한다. 원시 데이터·행별 예측·OOF·모델·manifest·추출 인덱스는 공개 Git에 올리지 않는다. 공통 문서(RESEARCH_STATUS, PLAN, STRATIFIED_SUMMARY 갱신)와 push는 메인이 조율한다. 이 문서는 예약 실행이나 백그라운드 서비스를 설정하지 않는다.

**실행 명령은 구현 후 확정한다.** 현재는 어떤 명령도 확정하지 않았다.

## 10. 판정 (기술 판정 — 학습 전 고정, 사후 완화 없음)

가설 지지/기각 판정이 아니라 **사전 고정 기술 분류**다. 비교 기준은 같은 모델·같은 환경의 ORI 셀(같은 Fold)이다. 모든 임계는 **제안값이며 승인 항목**이다.

각 새 셀에 대해 항상 보고(임계 충족 여부와 무관):
ΔMacro F1(Fold 평균 차, ddof=1 SD 병기), ORI 대비 더 높은 Fold 수(엄격, /5), 등급별 P/R/F1·지지, **Recall1, Recall3, 3→1 건수와 3등급당 비율, 3→2 건수**, 풀링 Macro F1, 정확도, 예측 등급 비중. **ΔMacro F1을 보이는 모든 표의 같은 행에 Δ3→1 건수와 비율을 함께 표시한다. 이 열이 없는 표는 `finalize`가 생성을 거부한다.** 3→1 증가는 "이득 대비 비용"으로 항상 같이 해석한다.

분류 규칙(제안):

| 기호 | 정의 | 제안 임계 |
|---|---|---|
| T_F1 | Fold 평균 ΔMacro F1 최소 | **+0.003** (기존 실험 관례) |
| T_win | ORI보다 엄격히 높은 Fold 수 | **≥ 4/5** |
| T_31 | 풀링 3→1 비율 차 상한(분모 69,774) | **≤ +0.003**(약 +209건) |
| T_R3 | 풀링 3등급 Recall 차 | **≥ +0.02** |

- **A. 이득 유지형**: ΔF1 ≥ T_F1 AND 승 ≥ T_win AND Δ3→1율 ≤ T_31.
- **B. 이득-비용 교환형**: ΔF1 ≥ T_F1 AND 승 ≥ T_win AND Δ3→1율 > T_31.
- **C1. 탐지 교환·F1 유지형**: A·B가 아니고 ΔRecall3 ≥ T_R3 AND ΔF1 ≥ −0.003.
- **C2. 탐지 교환·F1 소폭 하락형**: ΔRecall3 ≥ T_R3 AND −0.01 ≤ ΔF1 < −0.003.
- **C3. 탐지 교환·F1 큰 하락형**: ΔRecall3 ≥ T_R3 AND ΔF1 < −0.01 (기존 완전 균등 LR 셀은 이 구간).
- **D. 이득 없음**: 그 외.
- 모든 분류에 Δ3→1 건수·비율을 병기한다. F1 구간 경계(−0.003, −0.01)도 제안값이며 승인 항목이다.

추가 기술 보고(게이트 없음):
- **용량-반응**: 각 팔·모델에서 φ별 ΔF1, ΔRecall3, Δ3→1, ΔRecall1 곡선과 단조 여부(인접 φ 사이 부호 변화 개수). "최적 φ"를 고르거나 채택하지 않는다(선택 통계).
- **분해(Q3)**: ONE1 vs ONE3 vs EQ-UP의 Δ3→1·ΔF1 비교(가법성 가정을 검정하지 않음, 단순 차이 표).
- **샘플링 vs 가중치(Q4)**: 같은 φ에서 (R-UP − W-OBJ)의 ΔF1·Δ3→1, 그리고 소음 셀 퍼짐과 비교. `LR.BAL − W-OBJ.EQ`(규제 척도 효과)와 `ROS.EQ − W-OBJ.EQ`(복제 난수 효과)를 분리 표시. 소음 셀 퍼짐(seed 3개의 ΔF1 범위)보다 작은 차이는 "소음 수준과 구분 불가"로 쓴다.
- **방향·모델 비교(Q1/Q5, 기술 비교)**: R-UP vs R-DOWN은 같은 φ에서도 클래스 비·총 학습 건수가 달라(§3.2) 통제된 요인 비교가 아니며 부호·크기만 나란히 보고한다. LR vs LGBM-N(vs RF)도 절대 수준이 아닌 방향만 비교한다.
- 참고 열: LR.ORI 대비가 아닌 **로컬 재현 LR-C(`age995/C`, 0.688860; 원래 환경 공표값 0.688687은 쓰지 않음)·LGBM-N ORI 대비** 값(전처리가 달라 한 요소 비교가 아님을 표기, 로컬끼리만 비교 원칙). LR-C 로컬 OOF의 경로·SHA는 `prepare`가 확인한다(미확인). 선택은 승인 항목.
- 모든 셀을 충족 여부와 무관하게 보고한다. 유의성 검정·인과 주장 없음. Fold 5개는 독립 표본이 아니다.

## 11. 보조 분석 (학습 0회, 게이트 없음, 승인 시)

**A3 확률 오프셋 에뮬레이션**: LR.ORI의 저장 확률에 로그 가중치 오프셋 `log(t_c/n_c)`를 더해 argmax를 다시 정하고, 같은 φ의 W-OBJ·R-UP 셀 예측과의 일치율과 ΔMacro F1·Δ3→1을 비교한다. "부분 완화가 사실상 결정 경계 이동과 같은가"를 묻는 사후 분석이며 T15·T28의 결정 규칙 연구와 결합하지 않는다. 같은 OOF를 재사용하는 사후 기술 통계다.

## 12. 홀드아웃·경계

`earthquake/data/final_holdout/`는 열거를 포함해 접근하지 않는다. 과거 개인 평가에 이미 쓴 홀드아웃은 선택·튜닝·재평가에 재사용하지 않으며 새 독립 성능으로 주장하지 않는다. `preprocess.py` v1.0.1, 원본 38개 입력, 특수값(age=995 등), 기존 `reports/`·봉인 계획·소스·기존 출력은 변경하지 않는다. 팀원 브랜치(EY·jjjjin·sy)와 `earthquake/` 원본 checkout을 건드리지 않는다. **기존 개인 최종 모델(T0 LR C=1)을 바꾸지 않으며**, 어떤 시나리오가 좋아 보여도 채택은 T29류 별도 최종 평가 설계와 사용자 결정 사항이다. T15/T17/T28의 결정 규칙, T24/T27 피처, T18 튜닝과 결합하지 않는다.

## 13. 한계

- **같은 개발 자료의 반복 평가**: 층화 5-Fold를 T0~T14에서 이미 반복 사용했다. 이 실험은 그 결과(균등화 시 F1 하락·3→1 증가)를 본 뒤 만든 **적응적 후속 설계**이며, 사전등록은 이번 절차만 묶는다. 시나리오 22~25개를 같은 Fold에서 비교하므로 선택 편향이 있고 독립 성능이 아니다.
- **샘플러 난수와 최적화 소음**: 주 셀은 샘플러 seed 42 한 번이다. 소음 셀(LR 2 seed)은 **샘플러 추출 난수**만 가늠하며 LGBM-N·RF의 샘플러 소음은 측정하지 않는다. 또 **LR 최적화·BLAS 소음은 담지 못한다**: 독립 검토에 따르면 같은 LR.ORI라도 원래 환경과 로컬 재현의 예측이 949행 다르고 최대 확률차가 0.08에 달했다(이번 작성에서 재확인하지 않음). 이 크기의 소음이 ΔF1 해석에 섞일 수 있다. 추출은 §4.1 포함 관계 서술처럼 일부만 nested라 시나리오 간 차이에 추출 난수가 섞인다.
- **환경 이중성**: 로컬 재현값과 2026-10-13 원래 환경 공표값이 LR에서 약 1e-4 단위로 다르다. T32 내부 비교는 로컬 값만 쓰므로 STRATIFIED_SUMMARY 표1 숫자와 직접 비교하지 않는다.
- **K-Fold 5개**: Fold 표준편차·승수는 유의성이 아니다. 3→1은 실제 3등급 69,774건 중 0.7% 미만(ORI 기준)인 희소 사건이라 작은 건수 차이에 비율이 민감하다.
- **랜덤 분할**: 같은 지역이 학습·검증에 모두 나온다. 층화 개선이 지역 암기를 반영할 수 있어 미관측 지역 일반화(geo2/geo1)는 이 실험이 답하지 못한다. 일부 모델(LGBM-N, T14)은 층화에서 높고 geo2에서 낮았던 선례가 있다.
- **선형 격차 채움은 한 가지 정의**다. 지수 보간·특정 비율 목표(예: 1:2:3 = 1:3:2)는 다르게 움직일 수 있다. 3등급 비중이 약 33.4%로 고정되는 성질은 이 정의의 결과다.
- **복제 ≠ 가중치(트리)**: LightGBM·RF에서 복제와 가중치는 최소 리프 행 수 조건과 부트스트랩이 달라 같지 않다. LR에서만 목적함수가 동일하다.
- **RUS 부분 완화**는 정보 손실을 포함하고, 같은 φ에서도 UP과 목표 비율·총 건수가 다르다(§3.2). 짝이 되는 DOWN 가중치 팔이 없어 방향 비교는 기술 비교에 한정한다.
- 분포 가정: 처리 후 분포가 실제 지진 피해 분포와 다르다는 점, 보정되지 않은 확률(`predict_proba`) 해석 한계가 있다. Macro F1은 3→1 비용을 반영하지 않는다. 팀의 오류 비용·허용 기준은 별도 결정이다. 건물 안전 판정이나 점검 우선순위 자동 결정으로 해석하지 않는다.

## 14. 미확인 사항

1. 요약 가이드에 없는 심화 항목 문구의 원문 대조(사용자 원문 필요).
2. (해소) Fold 1~4 학습 건수는 T8 fold json으로 확인함. 남은 일은 `prepare`의 재계산 대조.
3. 재사용 OOF 5+2개와 T8 산출물의 현재 바이트 SHA(기록값 옮김만 했고 이번에 재계산하지 않음).
4. 고정 등급 키를 뺀 dict 경로가 `'auto'`와 같은 추출 인덱스인지는 소스 독해로 예상하지만 G-IDX(5개 Fold)로 확인하기 전까지 미확인.
5. W-OBJ(가중치 최대 5.9) LR의 `max_iter=1500` 수렴 여부, 각 셀의 실제 fit 시간.
6. RF `n_jobs` 설정과 로컬 재현의 실제 스레드 설정, LGBM-N R-UP의 `min_data_per_group` 상호작용 크기.
7. 재사용 control이 1e-9 기준을 통과할지(`lr_balanced`·`lr_rus`는 `baseline.py` 경로, ROS·SMOTE·none은 `run_personal_sampling.py` 경로이므로 BLAS 스레드 설정 차이가 있을 수 있음).
8. 현재 `peter` HEAD와 동시 세션의 변경(조회하지 않음).

## 15. 승인 필요 항목 (사용자 결정)

1. 모델 범위: 기본 LR + LGBM-N(제안), RF 선택 확장 포함 여부(제안: 포함), DT·GBC·T14 RF 계열 제외 확인.
2. 시나리오 정의: 선형 격차 채움 φ ∈ {0, 1/4, 1/2, 3/4, 1}, 정수 반올림(0.5 올림), 방향 UP·DOWN, 분해 시나리오 ONE1·ONE3 포함 여부, 지수 보간 대안 제외 확인.
3. 팔 구성: R-UP(2등급 키 제외 dict)·R-DOWN(1등급 키 제외 dict)·W-OBJ(LR)/W-NORM(트리), DOWN 짝 가중치 팔 없음·방향 비교는 기술 비교로 한정, LGBM-N 복제를 P50·EQ만 하는 것, 제약형 SMOTE 부분 완화 미포함(포함 요청 시 별도 설계), SMOTENC 불채택 유지.
4. 재사용 허용: 로컬 `20261014_01/runs` OOF 5개·RF 2개, T8 N OOF 재사용과 control 기준(Fold 0·2, 예측 100% 일치·확률차 ≤ 1e-9)과 G-IDX 봉인 전 게이트, control 실패 시 재학습(최대 ORI 5+ROS.EQ 5+RUS.EQ 5 fit 등)의 별도 승인 절차, 로컬 값과 원래 환경 공표값을 섞지 않는 원칙.
5. 소음 셀(LR R-UP·R-DOWN P50, seed 101·202, 20 fit) 포함 여부.
6. 판정 임계(T_F1 +0.003, T_win 4/5, T_31 +0.003, T_R3 +0.02, 분류 C 세분 −0.003/−0.01)와 A·B·C1~C3·D 분류, 3→1 병기 의무.
7. fit 상한(RF 제외 110 / 포함 125), control 최대 8회(RF 포함 10회), 자동 재시도 0, 수동 복구 1회 허용 여부, 동결 venv 사용.
8. 참고 비교 열(LR-C, LGBM-N ORI 대비)과 보조 분석 A3의 포함 여부.
9. 실험 ID·비공개 출력 경로·공개 파일명, 담당 구분(구현 worker, 장시간 실행 관리자, 독립 감사 담당).
10. **3단계 실행(§8.1)과 단계별 진행 승인**: 1단계(30 fit) 시작 승인, 2·3·3' 단계 진행 여부는 각각 별도 승인. 단계 결과로 설계를 바꾸지 않는 원칙 확인.
11. 코드·설정·테스트 구현과 `prepare` 봉인 시작 승인(현재 모두 미착수), 원문 가이드 심화 항목 문구 대조.

이 승인이 나오기 전까지 T32는 미실행이며 완료로 표시하지 않는다. 층화 주 평가 결과를 내는 설계이지만, 실행 전에는 어떤 수치도 이 실험의 결과가 아니다.
