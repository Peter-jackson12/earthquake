## 목적과 선행 방법

기존 세 등급 다중분류 대신 피해 순서를 반영한 두 누적 이진 문제로 학습하면 동일 geo2 평가에서 Macro F1 및 심한 피해 오류가 개선되는지 확인한다. 기존 C 전처리와 입력 38개를 유지하며 T21/T22 파생변수, T20 학습 가중치, T18 튜닝, T17 결정 규칙은 결합하지 않는다.

공식 데이터의 피해 1/2/3은 낮음/중간/거의 완전 파괴의 순서다. [DrivenData 설명](https://www.drivendata.org/competitions/57/nepal-earthquake/page/136/)의 순서형 목표 정의와 [Frank·Hall 2001](https://researchcommons.waikato.ac.nz/entities/publication/ce0009f5-92fa-4113-b8b2-7ac929cfd32c)의 k−1개 누적 이진분해 아이디어를 참고한다. 아래 평균 투영은 우리 실험의 사전 고정 후처리다. 원 논문의 정확한 재현이나 공동 순서형 손실함수 학습이라고 표현하지 않는다.

## 고정 학습과 확률 복원

단일 팔 `CUMULATIVE_BINARY`에서 outer-train 전체 행으로 두 모델을 각각 학습한다. 행을 등급별로 걸러 학습하지 않는다.

- `GE2`: 정답 `(y >= 2)` → `q2 = P(y >= 2)`.
- `GE3`: 정답 `(y >= 3)` → `q3 = P(y >= 3)`.
- 전처리는 동일 outer-train의 C를 공유하며 두 모델에 같은 CSR을 제공한다. 995 대치는 학습 non995 중앙값과 원래 표시 변수를 유지한다.
- 두 모델 각각 LightGBM binary objective, 300 rounds, 31 leaves, learning_rate=0.05, seed42, 내부 2스레드. multiclass 전용 num_class는 제거한다. 나머지는 기존 LGBM-O 설정 그대로다.
- 가중치·재표집·early stopping·확률 보정 학습·임계값 탐색은 없다. 각 모델의 내부 클래스는 [0,1]이고 양성 확률만 사용한다.

두 예측에서 `q3 > q2`이면 두 값을 `(q2+q3)/2`로 같게 바꾼다. 그 외에는 원래 값을 유지한다. 이 고정식은 두 값에 동일 가중치를 주는 제곱거리 최소 단조투영이다. 검증 정답이나 전체 자료 통계를 쓰지 않는다. 입력 확률은 유한한 [0,1]이어야 하며 잘못된 확률을 임의 clipping으로 숨기지 않는다.

투영 후 `p1=1-q2`, `p2=q2-q3`, `p3=q3`으로 복원한다. 합이 1인 세 확률의 argmax로 예측하며 완전 동률은 낮은 등급이다. 위반 행에서는 p2=0이 된다는 구조적 영향을 보고에 명시한다. 순서 위반 수·비율·초과량 평균과 최댓값, 2등급 Precision/Recall/F1을 함께 공개한다. 순서 보정만으로 실제 3→1 오류가 줄어든다고 가정하지 않는다.

## 평가와 예산

- 실험 ID `T23_ordinal_damage_v1`, 코드 `experiments/ordinal_damage/`.
- geo2 manifest seed42/101/202/303 × 5 Fold = **20개 외부 평가 단위**, 단위당 GE2·GE3 두 binary fit = **실제 40회 시도 상한**이다. 단위 수와 실제 학습 수를 별도로 원장에 기록한다.
- 실패 재시도 금지. 첫 임계모델이 저장된 뒤 두 번째가 실패하면 첫 모델·로그를 보존하고 연구를 중단한다. 새 attempt나 완료 모델 재학습으로 복구하지 않는다.
- 첫 공식 `geo2_s42/f0`의 두 binary fit을 비용 확인에 사용한다. 별도 실자료 smoke fit이나 baseline 재학습은 없다.
- T8/T13의 LGBM-O OOF를 SHA·ID·정답·Fold 대조 후 기준으로 재사용한다.
- 새 출력 `local_reproduction/T23_20261015_ordinal_damage/run`, 기존 출력 덮어쓰기 금지.

학습 방식 전체의 비교다. 기존 multiclass는 round마다 세 클래스의 트리를 만들고 이 방식은 두 binary 모델을 만들므로 총 트리 수·용량·연산량이 완전히 같은 비교가 아니다. 같은 rounds를 사용했다는 이유로 순서 정보 하나의 순수 인과 효과라고 주장하지 않는다. 각 모델 트리 수·학습시간을 기록한다.

## 판정과 집계

기존 무가중치 LGBM-O 대비 다음 조건을 모두 요구한다. T21/T22 결과를 보고 기준을 바꾸지 않는다.

1. 20 Fold 평균 Macro F1 차이 ≥ +0.003.
2. 양의 차이 Fold ≥ 14/20, 동률 제외.
3. 양의 seed별 Fold 평균 차이 ≥ 3/4.
4. 네 seed 혼동행렬을 합한 3등급 Recall 차이 ≥ 0.
5. 같은 반복 pooled 3→1 오류율 차이 ≤ 0.

개발 건물 208,480개의 네 번 반복 예측 833,920개를 독립 관측으로 취급하지 않는다. 3→1·3→2 분모는 69,774×4=279,096, 2→3은 118,607×4=474,428이다. Fold 평균·SD(ddof=1), 각 seed pooled, 등급별 P/R/F1·혼동행렬, 오류 전환 및 age995/non995를 남긴다. 순서형 진단으로 평균 절대 등급 오차와 두 등급 차이 오류율도 기술 보고하되 사후 판정 조건으로 추가하지 않는다. 같은 개발 자료의 반복 연구·선택 편향이 남고 최종 채택·외부 성능·안전성 보장은 아니다.

## 체크포인트와 독립 감사

- 두 임계모델 각각 fit 직후 native 모델·원시 양성 확률·전처리 증거·지표를 저장하고 SHA·백업·재로딩 검증을 마친다. 각 fit의 시도 시작·종료·실패를 원장에 기록한다.
- 두 모델이 모두 완료된 뒤 복원 확률·최종 등급·투영 진단을 별도 단위 체크포인트로 저장한다. 원시 누적 확률과 결과의 연결을 검증한다.
- 모델 입력 CSR train/valid SHA, 전처리 상태, binary 정답별 학습 지지 수, 설정·트리 수·경고를 기록한다.
- 합성 검사는 경계 확률·위반/비위반·완전 동률·비유한값·잘못된 모양/범위, 실제 작은 두 binary native 저장·복원, 첫/둘째 fit 실패와 예산·완료 건너뛰기·잠금·집계를 포함한다.
- 실제 독립 감사는 저장 joblib 역직렬화나 연구 실행기 import 없이 C를 재구성하고 40 native binary 모델을 재추론한다. 원시 누적 확률·투영·클래스 확률·등급·지표·오류 전환·진단·다섯 판정·원장 40시도·20단위·입력/설계/백업 SHA를 모두 대조한다. 감사 중 재학습은 없다.
- 기존 T21/T22 봉인 파일과 공통 의존 코드를 수정하지 않는다. 감사 PASS 후 집계 보고와 JSON만 Git에 넣는다.
