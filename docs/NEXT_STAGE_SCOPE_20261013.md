## 실행 전 고정 범위

2. 제한 CV 탐색은 무가중치 LR C={0.1,10} 두 후보와 balanced RF (max_features,min_samples_leaf)={(0.1,1),(0.2,1),(0.2,2)} 세 후보, 총 신규 25 Fold다. LR C=1과 balanced RF (0.1,2)는 기존 결과를 재사용한다. RF는 class_weight=balanced를 고정하고 나머지 공통 파라미터를 유지한다. 여러 요인이 다른 조합은 하나의 인과효과로 주장하지 않는다.

4. SMOTENC는 기존 Fold 0의 학습 구간에서만 제한 표본으로 안전성 파일럿을 수행한다. 지역·이진 범주, 특수값 및 합성값 계약을 점검한다. 위반이 확인되면 전체 학습으로 확대하지 않고 설계 판단이 필요한 항목으로 남긴다. 파일럿은 전체 모델 비교 완료가 아니다.
5. Streamlit 대시보드는 공개 가능한 집계만 읽고 EDA·모델 비교·불균형 처리·오류·검증 범위를 표시한다. 최종 홀드아웃 결과는 미실행으로 남긴다.
