## 0. 요약 (권고안)

1. 현재 데이터에는 **완전히 독립된 Test가 없다.** 개발 208,480행은 모두 seed 42 5-Fold에서 수십 개 설정의 검증 행으로 반복 노출됐다. 과거 홀드아웃 52,121행은 T0 평가에 1회 사용됐고 그 결과도 공개됐다(§1).
2. 권고안은 **(B) 새 seed 반복 층화 확인 CV**다.
   - 후보 3개(T0·T14·T8-N)의 파이프라인과 결정 규칙을 실행 전에 동결한다.
   - seed 101/202/303/404/505 × 5-Fold, 총 25 Fold에서 현 최종 T0 대비 교체 여부를 판정한다.
3. 과제 주제 가이드의 절차는 "검증으로 선택한 뒤 분리해 둔 Test에서 최종 평가"다(`docs/PROJECT_GUIDE_KO.md` §3 요약). **이 절차를 끝까지 따르는 것은 T0 유지(F)뿐이다.**
   - T0은 동결 후 홀드아웃 1회 평가를 거쳤다.
   - B로 교체되는 모델은 분리 Test 단계를 거치지 않는다.
   - 그래서 교체 결과에는 항상 **"개발 자료 반복 층화 확인 CV, 독립 Test 성능 아님"**을 표기한다(§5.8).
4. 신규 fit 상한은 기본 완료 78회(후보 3 × seed 5 × Fold 5 = 75, 대조 확인 3), 시도 상한 81회다. 학습 시간은 기존 보고 기준 합계 약 16~25분으로 추정하며 LGBM-N은 미측정이다(§7).
5. 3→1 상한을 엄격하게 두면, seed 42 기록만 봐도 두 도전 후보가 교체 조건을 충족하지 못할 가능성이 높다. 이것은 결과가 아니라 예상이다. 3→1 상한값은 결과가 아니라 **오류 비용 판단**으로 사용자가 정해야 한다(§5.4, 승인 항목 9).

## 3. 권고안 B의 고정 질문

> 실행 전에 동결한 도전 후보(T14 RF, T8 LGBM-N)가 개발 자료의 **새 seed 5개 × Stratified 5-Fold**에서, 같은 Fold의 현 최종 모델 T0(v1.0.1 + 무가중치 LR C=1)보다 Macro F1이 일관되게 높고, 3등급 과소예측(3→1)과 3등급 재현율이 사전 상한 안에 있는가?

- 판정은 "개인 최종 모델을 T0에서 바꿀지"에 대한 사전 등록 규칙이다. 인과, 요인 효과, 독립 성능, 지역 일반화, 안전성은 판정하지 않는다.
- seed 42 결과는 이미 선택에 쓰였으므로 **판정에 넣지 않고** 나란히 보고만 한다.
- **AGENTS "개선은 기존 기준선과 한 요소씩 비교"와의 긴장:** T14는 TE·ROS·RF·원시 age를 함께 바꾼 묶음이고, T8-N도 T0 대비로 보면 모델·995 처리·범주 표현이 모두 다르다. 이 평가는 개선 원인을 밝히는 것이 아니라 **완성된 파이프라인 사이의 최종 선택**이다. 이득을 어느 요소에도 귀속하지 않으며, 요인 분리는 기존 T8 등 단일 요소 비교 보고를 따른다고 명시한다(T16 RF 요인 분리는 geo2 전용이며 층화 기준의 T14 요인 분리는 아직 없다).

### 4.2 후보 수를 최소화한 근거

- 후보가 늘면 같은 행에서 "최댓값 고르기"의 편향과 다중 비교 문제가 커진다. 그래서 **"T14·T8을 새 최종 후보로 올릴지"에 필요한 최소 집합**만 둔다. 현 최종(C0)과 seed 42 상위 두 설정(C1·C2)이다.
- 제외한 설정과 이유:
  - T3 G2(0.690993)·G5·G4·G1: LR-C 대비 +0.0014~+0.0023으로 표준 기준 +0.003에 못 미친다. G2는 3→1이 452→478로 늘었다.
  - LR-C(0.688687): 연구 기준선일 뿐 최종 후보로 제안된 적이 없다. T0 대비 +0.005010이라 "가장 단순한 개선"의 참고값은 된다. **선택 팔(C3, 판정 게이트 없음)**로 넣을지는 승인 항목 5다.
  - T15 오프셋·T10 LGBM_TE·T12: 사후 규칙 파생이거나 LR-C 근처라 도전 의미가 작다.

### 4.3 동결 후보의 알려진 쟁점(실행 전 기록, 고치지 않음)

1. **T14 범주 어휘:** 문자 범주의 `category` 어휘를 개발 자료 전체에서 관측된 값으로 만든다. T14 계획은 이를 "라벨과 무관한 스키마, 통계 fit 아님"으로 기록했다. 그러나 AGENTS의 "전체 데이터에 인코더를 fit하지 않는다"와 해석이 충돌할 수 있다. 확인 평가에서 바꾸면 동결이 깨지므로 **그대로 두고 한계로 명시**한다. 교체가 결정되면 최종 재학습에서 어떻게 처리할지는 사용자가 정한다(승인 항목 13).
2. **T14 원시 geo ID 수치 사용:** RF가 지역 코드를 숫자로 분할한다. 가이드는 지역 코드 크기를 거리·순위로 해석하지 말라고 한다. 모델 내부 표현일 뿐이며, 해석에서 수치 크기의 의미를 주장하지 않는다.
3. **T0 교차환경 재현:** T4 로컬 교차환경 재현에서 LR 계열 22개 실행이 엄격 기준 `1e-6`을 넘어 `DIFFERENCE_UNDER_REVIEW` 상태다(BLAS 차이 의심). §5.2의 T0 대조 확인은 이를 고려해 허용 오차를 둔다(승인 항목 7).

### 5.3 지표

- **1차:** 25개 새 Fold 각각의 Macro F1(`labels=[1,2,3]`, sklearn `f1_score(average='macro')`). 요약은 Fold 평균 ±SD(ddof=1)와 seed별 평균이다.
- **짝 차이:** 같은 Fold에서 Δ_f = F1(도전) − F1(C0). 평균 Δ, 양의 Fold 수, seed별 평균 Δ를 계산한다.
- **보조:**
  - 등급별 Precision/Recall/F1/지지 수, Accuracy
  - Fold별·seed별·풀링 혼동행렬(행=실제)
  - **3→1·3→2 건수와 비율**: 분모는 실제 3등급이다. 풀링은 5 seed 반복 예측이라 분모가 348,870이고, 고유 3등급 건물은 69,774개다.
  - Recall3, 2→3, 예측 등급 비율, age=995 집단(1,125행), geo1 26/20/13 프로파일, 같은 행 예측 전환(turnover)
- 풀링 값은 고유 건물 208,480개를 5번 반복 예측한 합계다. 1,042,400개의 독립 관측으로 세지 않는다. Fold 평균과 풀링 F1은 다른 요약이다.
- **SD/√25로 신뢰구간이나 표준오차를 만들지 않는다.** Fold 점수가 독립이 아니어서 과소 추정된다.

### 5.5 다중 비교와 해석 규칙

- 도전 후보는 2개다. 판정은 각 후보의 **게이트 동시 충족(conjunctive)**으로 하며 p값으로 게이트하지 않는다. Fold 간 학습 행의 약 75%가 겹치고 seed 간에도 같은 행을 쓰므로 Fold 점수는 독립 표본이 아니다.
- 보조 기술 통계(승인 항목 11): Nadeau–Bengio 보정 반복 CV t 통계를 **보고만** 한다. 게이트로 쓰지 않고 "유의"라는 표현도 쓰지 않는다.
  - 차이 표본 J = r×k = 25.
  - 분산 보정 (1/J + n_test/n_train), n_test/n_train = 41,696/166,784 = 0.25.
  - 두 비교에 대한 Holm 보정값을 함께 낸다.
  - 이 보정도 근사이며, 같은 행을 반복 쓴 선택 편향은 반영하지 못한다.
- **둘 다 충족할 때 선택 규칙(사전 고정, 승인 항목 12):**
  1. 25 Fold 평균 Macro F1이 높은 후보를 고른다.
  2. 두 후보 평균 차가 0.002 미만이면 풀링 3→1 비율이 낮은 후보를 고른다.
  3. 그래도 같으면 C2(T8-N)를 고른다.
  - 이 선택도 같은 25 Fold에서 하는 선택이므로, 선택된 모델의 평균은 약하게 낙관적이라고 보고서에 적는다.
  - **사전 정보 공개:** 0.002 임계는 seed 42에서 두 후보 차(0.700427 − 0.699342 = 0.001085)를 알고 정한 제안값이다. seed 42와 비슷한 결과가 나오면 2번 단계로 넘어가 3→1이 낮은 쪽(seed 42 기록상 T8-N)이 선택된다. 이 결과를 의도해 임계를 고르지 않도록, 승인 시 임계값과 그 근거(Fold SD 0.001~0.003 수준의 차이는 구분하지 않는다)를 함께 확정한다.
- seed 42 결과(기존)와 새 25 Fold 결과의 방향이 다르면 사실대로 함께 보고한다. 판정은 새 결과로 한다.
- C3 LR-C를 넣는 경우 기술 비교만 하며 교체 대상이 아니다.

### 5.6 지역 의존성(geo2) 결과의 처리

- 기존 감사 결과로 보면 지역 일반화에서 두 후보는 약하다.
  - **T14 RF:** geo2 Group 20 Fold 평균 **0.557068**(A1 종합 `reports/EXPERIMENT_SYNTHESIS_20261016.md` 값. seed 평균 0.5632/0.5543/0.5555/0.5554와 일치). LR-C 대비 −0.0088(8/20 승), LGBM-O 대비 −0.0250(`reports/TE_ROS_RF_REPRO_20261015.md`).
    - 주석: T14 보고 본문의 "0.556"은 seed 평균·A1 종합값과 맞지 않아 표기 오류로 보인다. 보고서 원문은 고치지 않는다.
  - **T8-N:** geo2 seed 42 5 Fold 0.5457로 LR-C 0.5651보다 낮다(`reports/LGBM_NATIVE_CAT_20261014.md`).
  - **T0**(LR C=1, 연령 원값)의 geo2 결과는 기존 보고에서 찾지 못했다. 가장 가까운 대용은 LR-C다.
- **기본 권고:** geo2는 **게이트로 쓰지 않는다.** 층화 확인 결과와 **같은 비중으로 심화 결과 절에 병기**한다(과제 가이드 심화 항목의 지역 분리 평가·무작위 층화와 지역 단위 비교). 신규 geo2 fit은 하지 않고 기존 감사 수치만 인용한다.
- 교체가 결정되어도 보고서·대시보드에서 "처음 보는 2차 지역에서는 기존 LR 계열보다 낮았다"는 사실을 빼지 않는다. 지역 일반화나 배포 적합성은 주장하지 않는다.
- 대안(승인 항목 14): geo2를 게이트로 쓰면 "기존 geo2 Fold 평균이 LR-C 이상"을 조건으로 둔다. 기존 수치상 두 후보 모두 미충족이므로 이 대안은 사실상 "교체 안 함"을 고르는 것과 같다. 정확한 T0 geo2 비교가 필요하면 T0 geo2 신규 fit(seed 42 5회, 4 seed면 20회)이 추가로 든다.

### 5.7 최종 모델 교체 조건과 결과 해석

| 결과 | 판정 | 해석과 후속 |
|---|---|---|
| 도전 후보 1개 이상이 G0~G5 모두 충족 | **교체 조건 충족** → §5.5 규칙으로 하나 선택 | 교체 실행은 사용자가 따로 확인한다(승인 항목 13). 승인되면 동결 파이프라인으로 **개발 208,480행 전체에 1회 재학습**해 개인 최종 모델 산출물을 만든다(가이드 심화 "전체 데이터 학습"). 이 재학습 모델의 성능은 어디서도 측정되지 않으며, 보고 수치는 확인 CV 평균이다. 홀드아웃 행은 학습에 넣지 않는다. **교체 모델은 가이드의 "분리해 둔 Test에서 최종 평가" 단계를 거치지 않았음을 명시한다.** |
| G1~G3 충족, G4 또는 G5 미충족 | **교체 안 함** | "Macro F1 이득은 새 분할에서도 재현됐지만 3등급 과소예측 상한을 넘었다"로 기록한다. 오류 비용 판단의 결과이며, T0이 일반적으로 더 낫다는 증거가 아니다. |
| G1~G3 중 하나라도 미충족 | **교체 안 함** | seed 42의 이득이 새 분할에서 재현되지 않았다(분할 우연이나 선택 편향과 일치하는 결과). 원인은 판정하지 않는다. |
| G0 실패(대조·분할·감사) | **판정 불가** | 결과를 판정에 쓰지 않는다. 원인 보고 후 재설계는 별도 승인을 받는다. |

- "교체 안 함"이면 개인 최종 모델은 T0이다. 가이드의 선택 → 분리 Test 절차를 거친 상태가 그대로 유지된다. T0의 유일한 Test형 수치는 2026-10-13 홀드아웃 0.686771(1회)로 남는다. T14·T8-N의 seed 42 결과는 "선택 통계"로, 새 25 Fold 결과는 "확인 CV"로 보고한다.
- 교체하더라도 팀 `main`의 팀 최종 선정·제출과는 별개다. 팀 결정은 이 문서 범위 밖이다.

### 5.8 결과 표기 문구(보고서·대시보드에 그대로 사용)

- 성능 수치 옆: **"개발 자료 208,480행의 새 seed 반복 층화 확인 CV(seed 101/202/303/404/505 × 5-Fold, 전체 개발 CV). 이 행들은 기존 seed 42 CV에서 후보 선정에 이미 사용됐다. 독립 Test 성능이 아니다."**
- 교체 시: **"개인 최종 후보 교체는 사전 등록 확인 규칙 충족에 따른 것이며, 교체 모델은 분리 Test 최종 평가를 거치지 않았고 독립 Test 성능은 측정되지 않았다. 과거 홀드아웃 0.686771은 T0 한 모델의 값이다."**
- 금지 표현: "최종 Test 성능", "일반화 성능 입증", "유의하게 우수", "안전성 개선", "지역 일반화".
- 비교 순서: 층화 확인 결과 → 3→1·Recall3 → geo2 심화 결과를 항상 함께 싣는다.

## 7. 실행 운영

### 7.1 신규 fit 상한

| 항목 | 횟수 |
|---|---:|
| 연구 fit: 후보 3 × seed 5 × Fold 5 | 75 |
| 대조 확인: 팔당 seed 42 Fold 0 | 3 |
| **기본 완료 fit 상한** | **78** |
| 수동 재개 시도(중단된 Fold만, Fold당 최대 1회, 전체 최대 3회, 컨트롤 타워 승인) | ≤ 3 |

| (선택, 교체 승인 시) 전체 개발 자료 재학습 | +1(별도 기록) |
| 자동 재시도 | 0 |

- 완료 Fold는 재학습하지 않는다. 시도 상한에 이르면 추가 시도 없이 중단·보고한다.
- T14의 내부 TE 5-Fold 계산은 분류기 fit이 아니라 인코딩 통계 계산이므로 위 횟수에 들어가지 않는다(T14 규약과 동일).
- 원장이 상한, 미등록 단위, 대조 확인 선행 조건을 코드로 강제한다. `RUNNING.lock`으로 중복 실행을 막고, 학습 실행 주체는 한 번에 하나다.

### 7.2 체크포인트·원장·재개

- Fold가 끝나면 바로 모델·확률·지표·로그를 저장한다. SHA-256과 실행 상태를 `ledger.json`에 기록하고 `backup/`에 복사한다(AGENTS 운영 순서).
- 저장 직후 재로딩해 검증한다.
  - 모델과 인코더 상태를 다시 읽어 검증 행을 원시 특성에서 재인코딩·예측하고 저장 확률과 비교한다(atol 1e-12, 라벨 100% 일치).
  - CSV round-trip은 정확히 같아야 한다.
  - RF 예측은 단일 스레드로 한다(T14 수정 1).
- 완료 Fold는 SHA 검증만 하고 재학습하지 않는다. 중단되면 `running` 항목의 미완 산출물을 `.incomplete_attempt<n>`으로 보존한 뒤 수동으로 재개한다(§7.1 상한 안에서). 원본 실행 결과는 덮어쓰지 않는다.
- 병렬은 한 단계만 쓴다. RF `n_jobs=4`(fit), LGBM `n_jobs=2`, LR 단일 스레드, Fold는 순차, 외부 병렬은 없다. 희소 행렬을 통째로 `.toarray()`로 바꾸지 않는다(T8-N·T14는 원래 밀집 float32 설계).

## 8. 승인 필요 항목

1. **기본 평가안 선택:** B(권고) / F(추가 평가 없이 T0 유지) / E(선택 절차 중첩 평가).
2. **과거 홀드아웃 예외(A):** 허용 여부, 허용한다면 §2 다섯 조건의 수용 여부. 기본은 불허.
3. **새 seed:** 101/202/303/404/505 사용 여부(다른 숫자 가능), seed 수 5.
4. **"저장된 fold만" 규칙 해석:** 학습 전에 생성·봉인한 새 층화 manifest를 "저장된 fold"로 인정할지(§5.1).
5. **후보 집합:** C0·C1·C2 고정. C3 LR-C를 기술 비교 팔로 추가할지(+26 fit).
6. **모델 내부 난수:** 봉인값으로 고정할지(권고), seed마다 바꿀지(동결 범위가 바뀌므로 비권고).
7. **대조 확인 허용 오차:** 특히 T0 LR의 라벨 일치율 ≥ 99.9%·Fold F1 차 ≤ 1e-4. 실행 전 비교 기준 파일 존재 확인.
8. **G1~G4 수치:** δ=+0.005, ≥ 20/25, ≥ 4/5, Recall3 Δ ≥ 0.
9. **G5 3→1 상한:** S/R/N안 중 선택과 그 오류 비용 근거.
10. G5에서 S안을 고르면 B를 실행할지, F로 갈지.
11. 보조 기술 통계(Nadeau–Bengio 보정 t, J=25, Holm) 보고 여부. 게이트로는 쓰지 않는다.
12. 둘 다 충족할 때의 선택 규칙과 평균 차 임계 0.002(seed 42 차 0.001085를 안 상태에서 정한 제안값).
