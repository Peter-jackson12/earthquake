# 미실행 실험의 우선순위와 수용 기준 — 개인 peter 연구 계획 (2026-10-13)

**목적:** 새 모델을 즉시 학습하지 않고, [EDA](../reports/EDA_FINDINGS_20261013.md)와 [기존 오류 분석](../reports/OOF_ERROR_REVIEW_20261013.md)을 바탕으로 **아직 실행하지 않은 실험만** 순서와 완료 기준까지 사전 정의한다.

## 이미 수행하여 중복하지 않을 항목

- 전처리 v1.0.1 실제 재실행과 검증
- 기본 Dummy + LR·DT·RF·GradientBoostingClassifier 전체 개발 5-Fold
- RF의 `max_features=sqrt→0.1` 단일 변경
- GBC의 `max_features=sqrt→None` 단일 변경
- LR의 `class_weight=None→balanced` 단일 변경
- 위 결과의 전체 OOF 혼동행렬과 오류 비교

개발 데이터 **208,480건**, 최종 홀드아웃 **52,121건**이며, 기존 80/20·seed 42·5-Fold는 **팀 공식 합의 전 잠정 기준**이다. 각 팀원이 직접 공통 과정을 수행해야 한다는 과제 요구를 개인의 기존 실행으로 대체하지 않는다.

## 실험 1 — 다른 모델의 가중치 (첫 추가 실험)

**질문:** LR에서 관찰된 Recall/Precision의 손익이 다른 모델에서도 발생하는가?

| 모델 | 현재 비교 기준 | 변경할 요인 하나 |
|---|---|---|
| DT | `baseline_v1` 설정 | `class_weight=None→balanced` |
| RF | `feature_budget_v1`의 `max_features=0.1` | `class_weight=None→balanced` |
| GBC | `feature_budget_v1`의 `max_features=None` | 학습 Fold의 라벨만 사용해 계산한 `sample_weight` 전달 |

GBC에는 `class_weight` 파라미터가 없으므로 학습용 `sample_weight`를 사용한다. 학습 Fold 이외에서 가중치를 계산하거나 검증 분포를 재가중하지 않는다.

**완료 기준:** 각 모델에서 무가중치와 가중치 5-Fold 점수, 클래스별 P/R/F1, 3→1·3→2 건수/비율, 실행 파라미터·Fold 배정·수렴/오류 로그 저장. 결과 채택은 Macro F1 평균뿐 아니라 심각한 과소예측의 악화도 검토한 뒤 결정한다.

## 실험 2 — Random Under Sampling (RUS)

**질문:** 샘플 수 손실을 감수한 균형화가 주지표와 클래스별 Recall을 개선하는가?

- 우선 기준 모델: **무가중치 LR 기본 설정**, 같은 개발 Fold와 전체 38개 원본 변수를 사용.
- 통제 조건: 동일 전처리 옵션·하이퍼파라미터·검증 ID·주지표·시드; **변경하는 것은 Fold 내부 훈련 표본 선택만**.
- 첫 실험은 `RandomUnderSampler(random_state=42)`로 훈련 Fold에서만 다수 클래스를 소수 클래스 수에 맞추는 방법을 비교. 검증·홀드아웃의 분포는 변경하지 않는다.
- 후속 비율 조절은 첫 결과를 본 후 **새 실험 ID**로 별도 기록한다.

**완료 기준:** Fold별 샘플링 전/후 1·2·3등급 표본 수, Macro F1 평균·표준편차, OOF 혼동행렬·3→1 악화 여부, 샘플 제거로 인한 정보 손실과 비용을 함께 보고한다.

## 실험 3 — 제한적인 CV 튜닝

**질문:** LR과 후보 변수 수를 완화한 RF에 개선 여지가 있는가?

- 현재 비교 기준: LR 기본 CV Macro F1 **0.683677**, RF `max_features=0.1` CV Macro F1 **0.628992**.
- 가벼운 탐색 제안: LR의 `C={0.1,1,10}`; RF의 `max_features={0.1,0.2}`과 `min_samples_leaf={1,2}` 등 작은 후보 집합.
- 앞선 불균형 실험 결과에 따라 먼저 탐색할 모델/공간을 결정하고, 모델마다 다른 예산과 탐색량을 기록한다.
- 모델 내부/외부 병렬화를 중복 최대치로 설정하지 않고, 원핫 후 희소 행렬을 `.toarray()`로 밀집 변환하지 않는다.

**완료 기준:** 고정 5-Fold Macro F1, Fold별 분산, 등급별 오류, 변경 파라미터와 탐색 범위, 기준선 대비 개선·악화, 총 학습 비용을 기록한다. CV 선택 이후 **남겨둔 Test는 한 번의 최종 평가까지 접근하지 않는다**.

## 실험 4 — SMOTENC는 설계만, 대량 실행은 보류

과제 가이드의 SMOTE 계열 비교 요구를 무시하지 않는다. 다만 지역 11,595개 코드와 다수의 범주·이진 변수가 있는 자료에서 일반 SMOTE를 원핫 행렬에 곧바로 적용하면 해석 불가능한 중간값·조합이 생길 수 있다.

- SMOTENC의 명목형 변수 지정(지역 3개, 문자형 8개, 필요시 이진 플래그 22개), 수치 5개 처리, 새로운 범주/조합의 타당성을 먼저 검토
- 모든 샘플링은 **학습 Fold 내부에만** 적용하고 검증에는 원래 분포 유지
- 제한된 소규모 파일럿에서 메모리·시간·생성 사례의 유효성을 점검한 후 전체 Fold 실행 여부 결정
- 과제 필수 요구라면 **미실행을 완료로 표시하지 않고**, 안전한 구성 또는 제한 이유를 팀과 기록

## 공통 실험 계약·결과 수용

1. `data_contract.json` 원본 및 `split_manifest.csv` SHA를 일치시키고 동일 Fold를 사용한다. 팀 기준 확정 전 변경 사항이 생기면 기존 결과와 섞지 않는다.
2. 피처 생성·인코딩·스케일링·샘플링·가중치 통계는 모두 **학습 Fold 기준**으로만 학습한다.
3. 보고 항목은 5-Fold **Macro F1 평균과 표준편차**, OOF 등급별 Precision·Recall·F1, Accuracy, 원시·정규화 혼동행렬, 실제 3등급 대비 3→1·3→2 비율이다.
4. 모든 건물이 해당 설정의 OOF에서 정확히 1번 예측됐는지, 확률 열 순서가 1/2/3인지, 설정·데이터 해시·코드 커밋이 기록됐는지 확인한다.
5. 단순히 평균 F1이 소폭 상승했다고 즉시 채택하지 않는다. Fold별 방향성과 3→1 과소예측의 손익을 확인하고, 악화가 있다면 그대로 보고한다. 임의의 사후 기준으로 Test 점수까지 조정하지 않는다.
6. 개인 실험은 `peter`에 유지하고 팀이 검토·재현해 채택한 내용만 PR로 `main`에 반영한다. 팀원의 독립 수행 기록은 별도다.

**이 문서는 실험 설계만 완료한 것**이며 RUS·추가 가중치·튜닝·SMOTENC를 이번 작업에서 새로 실행한 것으로 해석하면 안 된다.
