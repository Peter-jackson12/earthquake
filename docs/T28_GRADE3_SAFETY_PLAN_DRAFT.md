표준 다섯 조건(평균 Δ≥+0.003, 양의 Fold≥14/20, 양의 seed 평균≥3/4, 풀링 3등급 Recall Δ≥0, 풀링 3→1 오류율 Δ≤0)이 적용된 T20~T27의 11개 팔 중 이 다섯 조건을 모두 충족한 팔은 없다. T15·T16·T18·T19는 각자의 사전 기준을 썼으므로 이 진술에 포함하지 않는다. T20 가중치는 F1·Recall3 개선을 이미 확보했으므로(3→1에서만 +1건 차이), 가장 근접한 출발점이다.

T17의 b 고정값(LGBM-O b=0.5, LGBM_TE_G b=0.3)은 같은 OOF에서 고른 선택 통계이며 독립 성능이 아니다. T28은 이 값을 쓰지 않는다.

## 1. 고정 질문 (하나)

> **T20의 3등급 가중치 LGBM-O(W)의 확률에, 바깥 학습 행 내부 Group OOF만으로 고른 단일 파라미터 비용 결정 규칙 R을 적용하면, 무가중치 LGBM-O(O) 대비 T20의 F1·Recall3 개선을 유지하면서 풀링 3→1 오류율이 증가하지 않는가?**

핵심 가설은 "W의 F1·Recall3 이득과 O 수준 이하의 3→1을 동시에 얻을 수 있는가"이며, 사전 다섯 조건 + 추가 두 조건(§8)으로 판정한다. 채택·최종 모델 선정·안전성 보장이 아니라 개발 CV상의 고정 가설 지지 규칙이다.

## 2. 주 설계 권고: W + 비용 결정 규칙 R_λ (단일 요인은 "결정 규칙", 요인 분리 팔 포함)

### 2.1 규칙 정의

확률 p=(p1,p2,p3)에 대해 예측 등급 j를 기대 오분류 비용 최소로 정한다.

`pred = argmin_j Σ_i p_i · C[i,j]`, C의 대각은 0, 오분류 비용은 모두 1이며 **실제 3→예측 1 비용만 λ**다. 풀어 쓰면 다음과 같다.

- 예측 1의 손실 = p2 + λ·p3
- 예측 2의 손실 = p1 + p3
- 예측 3의 손실 = p1 + p2

λ=1이면 손실이 1−p_j이므로 원래 argmax와 정확히 같다(수치 동치 검사로 확인). 손실 동률은 낮은 등급 우선(기존 argmax 동률 규칙과 동일하게 [1,2,3] 순서)으로 정한다. λ는 "1등급 예측을 하려면 3등급 확률이 작아야 한다"는 방향으로만 작동하므로, T15의 3등급 오프셋(2·3 경계)과 달리 1 대 2·3 경계를 겨냥한다.

그리드: λ ∈ {1, 1.25, 1.5, 2, 3, 4, 6, 8, 12, 16} (10개, 사전 고정). 그리드 상한에 닿아도 확장·재탐색하지 않고 보고한다.

### 2.2 λ 선택 절차 (바깥 Fold f마다, 내부 Group OOF만 사용)

1. 바깥 학습 행 `A_f`(평가 Fold f 제외)만 취한다. 평가 행 `B_f`와 라벨은 입력되지 않는다.
2. `A_f` 안에서 T15와 같은 방식으로 내부 5-Fold를 만든다(`StratifiedGroupKFold(5, shuffle=True, random_state=42)`, 그룹 = `(geo_level_1_id, geo_level_2_id)`). 내부 Fold 라벨의 SHA는 설계에 봉인하며, T15의 같은 단위 내부 Fold와 일치하는지 확인한다(확인 필요, §5).
3. 내부 Fold마다 W(T20과 동일한 C 전처리, 300 rounds, 31 leaves, lr 0.05, sample_weight 1/1/1.5, n_jobs 2)를 내부 학습 행에서만 학습해 내부 검증 확률을 얻는다. 가중치는 내부 학습 행의 실제 등급에서 만든다. 전처리는 내부 학습 행에서만 fit한다. 이렇게 `A_f` 전체의 **내부 OOF 확률**을 얻는다.
4. 각 λ에 대해 내부 OOF의 풀링 Macro F1(labels=[1,2,3]), 3→1 오류율(분모 = 내부 OOF의 실제 3등급 수), 1등급 Recall을 계산한다.
5. **최소 건수 요건**: 내부 OOF에서 λ=1의 3→1 건수가 N_min(제안 50) 미만이면 줄일 대상이 부족하므로 λ=1로 두고 "무변경(희소)" 단위로 기록한다.
   **실현 가능 집합** F = {λ : 3→1율(λ) ≤ ρ · 3→1율(λ=1), Recall1(λ) ≥ Recall1(λ=1) − 0.03, 그리고 내부 풀링 Macro F1(λ) ≥ 내부 Macro F1(λ=1) − δ_F1}. ρ=0.90, δ_F1=0.003(둘 다 제안, 승인 항목). 여기서 λ=1 기준은 W의 내부 OOF 자기 자신이다(O 기준 아님, §4 참조). F가 비어 있지 않으면 F에서 내부 OOF Macro F1 최대 λ(동률이면 작은 λ)를 고른다. **F가 비어 있으면 λ=1(변경 없음)을 고르고 "무변경 단위"로 기록**한다. 상한까지 가도 제약을 못 맞추는 경우를 숨기지 않고 보고한다.
6. 이미 저장된 **T20의 바깥 모델 평가 Fold 확률**(`A_f` 전체로 학습)에 선택된 λ 규칙만 적용해 보정 예측을 만든다. 바깥 라벨은 λ가 확정된 뒤 지표 계산에만 사용한다. 함수 서명은 `decide(y_inner, p_inner, p_outer, grid, rho, r1_tol)`처럼 바깥 라벨을 인자로 받지 않는다.
7. 실행 중 검사: 내부 OOF 행 집합이 `A_f`와 정확히 일치하고 `B_f`와 교집합 0, 내부 Fold 그룹 서로소, 내부 클래스 지지 ≥ 30, 내부 Fold SHA가 봉인값과 일치. **λ=1 동치 검사(부동소수 동률 규칙)**: λ=1은 구현상 리터럴 `argmax(p)+1`을 쓴다. λ>1 손실 비교는 `|Δ손실| ≤ 1e-12`이면 동률로 보고 낮은 등급을 고른다. 별도로 손실식(λ=1)과 저장 `y_pred`를 비교해, 불일치 행이 있으면 그 행의 상위 두 확률 차가 모두 ≤ 1e-9일 때만 허용하고(행합 오차 기인) 그 건수를 기록한다. 그 밖의 불일치는 중단 조건이다. 100% 정확 일치를 요구하지 않는다. 하나라도 실패하면 seed 교체·설계 수정 없이 중단한다.

선택 제약 ρ, δ_F1, N_min, Recall1 허용값은 학습 전에 고정하며 결과를 본 뒤 바꾸지 않는다.

### 2.3 요인 분리 팔 (2×2: 모델 가중치 × 결정 규칙)

W와 R은 동시에 바꾸면 효과를 한쪽에 귀속할 수 없다. 이미 측정된 두 팔을 기준으로 두고 규칙만 새로 적용한다.

| 팔 | 학습 가중치 | 결정 규칙 | 출처 | 판정 역할 |
|---|---|---|---|---|
| A0 O | 1/1/1 | argmax | T8·T13 OOF 재사용 (기준선) | 기준 |
| A1 W | 1/1/1.5 | argmax | T20 산출물 재사용 | 비교 기준(규칙 효과 분리) |
| **A3 W+R_λ** | 1/1/1.5 | R_λ | **신규 내부 fit 100회** | **주 판정 팔** |
| A2 O+R_λ | 1/1/1 | R_λ | T15의 LGBM-O 내부 OOF 재사용 가능 시 추가 fit 0회 | 보조(상호작용 분리, 게이트 없음) |
| A4 W+b | 1/1/1.5 | T15 오프셋 b∈{0..2} | A3과 같은 내부 OOF 재사용, 추가 fit 0회 | 보조(게이트 없음) |

상호작용 = (A3−A1) − (A2−A0)로 기술 보고한다. A2·A4는 사전 판정 게이트가 아니며 결과를 보고 주 팔을 바꾸지 않는다. A2의 T15 내부 OOF를 SHA·내부 Fold 일치로 재사용할 수 없으면 A2를 생략하고 "상호작용 분리 불가"로 보고한다(재학습은 별도 승인 없이는 하지 않음). T15의 보정된 LGBM-O 결과(3→1 902 → 892)는 b 오프셋 팔의 참고 수치이며 R_λ 팔로 합산하지 않는다.

## 3. 대안 설계 (주 설계로 채택하지 않은 이유)

- **(a) W + 3등급 오프셋 b 결합**: 사용자 가설 예시와 가장 가까우나 T15 오프셋은 3→1을 거의 바꾸지 않았다(902 → 892). W가 이미 3등급을 올린 상태에서 b는 대체로 0 근처일 가능성이 크며(미측정), 3→1 직접 겨냥이 아니다. A4로 같은 내부 OOF에서 무료로 기술 보고하므로 별도 주 설계는 아니다.
- **(b) 2-파라미터 로짓 오프셋(1등급과 3등급 동시)**: 탐색 공간이 커지고 선택 낙관성이 늘어난다. 1등급 전체를 억제해 Recall1·Precision1이 떨어질 위험이 크다(1등급 Recall 0.349가 이미 낮다). 비용 규칙은 p3가 클 때만 1등급 예측을 막으므로 더 표적적이다.
- **(c) W의 가중치 sweep(예 1.25/2.0)**: 새 학습 요인이며 T20이 가중치 1.5 한 개를 사전 고정 가설로 평가했다. 반복 개발 탐색을 더 키우므로 이번에는 제외한다.
- **(d) 3→1 비용을 학습 단계(커스텀 목적함수)에 넣기**: 구현 위험이 크고 확률 의미가 바뀐다. 이번 범위 밖.

## 4. 한계가 되는 설계 가정

- W의 확률은 학습 가중치로 인해 보정된 사후확률이 아니다(T20 보고에 명시). 비용 규칙은 p를 사후확률로 간주하므로 p3가 과대 평가된 상태에서 λ가 선택된다. 이 효과는 λ 선택(내부 OOF)이 일부 흡수하지만 이론적으로 분리되지 않는다. 확률 보정은 T28의 요인이 아니다.
- 내부 모델은 `A_f`의 약 80%(개발 데이터의 약 64%)로 학습돼 바깥 모델과 확률 분포가 조금 다를 수 있다(T15와 동일 한계).
- **선택·판정 기준선 불일치**: λ 선택의 ρ 제약은 W의 내부 OOF(λ=1) 대비이고, 판정 C5는 바깥 평가의 O(902건) 대비다. 기준선이 다르고 내부 OOF에서의 감소가 바깥 Fold 감소로 이어진다는 보장이 없다(내부 모델은 데이터의 64%, 확률 분포가 다름). 또 W는 이미 903건이라 O 기준 C5를 통과하려면 바깥에서 최소 2건 이상 순감소가 필요한데, ρ=0.90이면 내부 기준으로 약 10% 감소를 목표로 한다. 대안: (i) C5 기준선을 W로 바꾸고(A3 ≤ A1, 규칙 단독 효과) O 대비는 보조로 보고 — 이 경우 질문이 "O 대비 안전"에서 "W 대비 악화 없음"으로 약해진다; (ii) 선택 제약의 기준을 내부 O OOF로 맞춤(T15 내부 OOF 재사용이 확인될 때만 가능). 주 설계는 O 기준 C5를 유지하되 이 선택은 승인 항목이다.
- 3→1은 실제 3등급 279,096개 중 0.32%인 희소 사건(902건)이다. 1건 차이는 통계적 의미가 없고 판정은 엄격 부등식이라 임계에 민감하다. 이 점을 해석에 명시한다.

## 6. 누수 방지와 학습 규모

- **모든 선택은 outer-train 내부 Group OOF**다. 바깥 평가 Fold의 행, 라벨, 지역, 확률은 λ 선택에 입력되지 않는다. 다른 바깥 Fold의 OOF로 정하지 않는다(그 모델이 평가 Fold 행을 학습했으므로 누수).
- 전처리·인코더·스케일러는 해당 학습 행에서만 fit한다. 전체 데이터 fit 없음. `load_development()`와 저장 Fold만 사용한다.
- **신규 fit 상한: 내부 fit 100회 = 4 seed × 5 바깥 Fold × 5 내부 Fold (W 팔 한정).** 바깥 W 학습 0회(T20 재사용), 최종 전체 개발 fit 0회. 시도 상한 100.
- **재시도 규칙: 자동 재시도 0회.** 학습 실패·비수렴·확률 이상(모델 문제)은 원본·실패 로그를 보존하고 중단하며 같은 단위를 다시 학습하지 않는다. 이는 "수동 복구"와 별개다. 수동 복구는 프로세스 소실·정전 등 **학습이 끝나지 않고 사라진 경우**에 한해, 사람이 소실을 확인한 뒤 완료 단위는 해시만 검증하고 **미완료 단위**를 이어 실행하는 절차다(전체 실험 1회, 설정·데이터 변경 없음, 실패 단위 재학습 아님). 허용 여부와 횟수는 승인 항목이며 승인 전에는 0회다(T16 선례). 시도 상한 100은 수동 복구 시 중단 단위 재시작분을 더해 최대 101이 될 수 있어 승인 시 명시한다.
- 병렬화는 한 단계만: Fold 순차, LGBM 내부 스레드 2, 외부 병렬·중복 학습 없음. 희소 행렬 `.toarray()` 없음. 학습 실행은 한 번에 한 주체만 담당한다.
- 예상 시간(미측정 추정): T20의 20회 학습합이 204.1초(약 10초/회)이므로 내부 fit(약 64% 데이터) 100회는 학습 자체 20~30분 내외로 추정한다. 전처리·저장·백업 포함 실제 시간은 첫 단위 로그로 확인한다. 디스크는 모델 100개 + 백업 사본으로 1~2GB 이내(추정, 비공개).

## 7. 체크포인트·원장·감사·보고 절차 (AGENTS.md 운영 순서)

운영 순서는 **로컬 데이터 보존 → 실험별 체크포인트 → 독립 감사 → GitHub 보고**다.

1. **봉인 전**: 승인된 계획·설정·코드·합성 테스트를 `peter`에 커밋하고 `python -m unittest discover -s tests -v`를 실행해 pass/skip을 구분한다. `prepare`가 소스 전이 import, 설정, 이 계획, 동결 환경, 개발 데이터 계약, 기존 manifest·OOF·T20 산출물 SHA를 전체 커밋 SHA로 결속한다. 기존 봉인 파일·출력 경로는 수정·덮어쓰지 않는다.
2. **Fold(내부 fit) 체크포인트**: 내부 fit마다 모델, 내부 검증 ID·정답·확률, 지표, 학습 시간, 학습/검증 CSR의 shape·dtype·배열 SHA를 저장하고 SHA-256과 상태를 원장에 기록한다. 저장 직후 모델 재로딩 확률 최대 절대차 ≤ 1e-12, CSV 왕복 정확 일치, 원본·별도 백업 SHA를 확인한 뒤 원장을 complete로 바꾼다. 완료 단위는 해시만 확인하고 재학습하지 않으며 `RUNNING.lock`은 배타적으로 생성한다.
3. **결정 단위 체크포인트**: 바깥 Fold마다 내부 OOF 곡선, 선택된 λ, 실현 가능 집합 여부(무변경 단위 포함), 보정 예측을 같은 방식으로 저장·재로딩·백업한다.
4. **집계**: `finalize`가 Fold 평균/SD, seed별 평균, 풀링 지표(클래스별 P/R/F1·지지 수·혼동행렬·정확도), 3→1·3→2·2→3과 분모, 선택 λ 분포, 무변경 단위 비율, age995/비995를 비공개 `analysis.json`으로 만든다.
5. **독립 감사**: 실행기를 import하지 않는 별도 담당이 입력·분할·기준선·T20 산출물 SHA, 내부 OOF가 `A_f`와 일치하고 `B_f`와 서로소인지, 그룹 서로소, 모든 λ 곡선과 선택 규칙(동률·제약·무변경 처리)의 처음부터 재계산, 보정·판정 입력 재생성, native 모델 재추론 확률차를 확인한다. 감사 PASS 전에는 공개 성능 보고를 확정하지 않는다.
6. **공개 보고**: 감사 PASS 뒤에만 `reports/`에 집계 보고서와 JSON을 커밋한다. 원시 데이터·행별 예측·OOF·모델·manifest는 공개 Git에 올리지 않는다. 공통 문서(RESEARCH_STATUS, PLAN) 갱신과 push는 메인이 조율한다. 이 문서는 예약 실행이나 백그라운드 서비스를 설정하지 않는다.

**실행 명령은 구현 후 확정한다.** 현재는 어떤 명령도 확정하지 않았다.

## 8. 판정 기준 (학습 전 고정, 사후 완화 없음)

주 판정 팔은 A3(W+R_λ)이고 비교 대상은 A0(무가중치 O)이다. 20 Fold 전체로 평가한다.

기존 다섯 조건은 **의미와 임계를 그대로 유지**한다(T20과 같은 규칙).

1. C1: Fold 평균 Macro F1 차이(A3−A0) ≥ **+0.003**.
2. C2: A3가 A0보다 엄격히 높은 Fold ≥ **14/20**(동률은 승리 아님).
3. C3: seed별 5Fold 평균 차이가 엄격히 양수인 seed ≥ **3/4**.
4. C4: 반복 OOF 풀링 실제 3등급 Recall 차이 ≥ **0**.
5. C5: 반복 OOF 풀링 **3→1 오류율 차이 ≤ 0**(분모 = 실제 3등급 지지 수, 엄격). 즉 A3의 풀링 3→1 건수가 기준 902건 이하여야 한다. T20의 903건은 이 기준에서 실패였다.

3→1 관련 추가 조건(초안에서 제안하며 승인 필요):

6. C6: seed별 풀링 3→1 오류율 차이(A3−A0) ≤ 0인 seed ≥ **3/4**(전체 합계가 한 seed에 의해서만 좌우되는 경우를 막음).
7. C7: 풀링 1등급 Recall 차이(A3−A0) ≥ **−0.03**(3→1을 1등급 예측 억제로 얻을 때 1등급 탐지를 희생하는지 확인. T15의 G3와 같은 허용치).

`supports_fixed_hypothesis = C1 ∧ … ∧ C7`. 승인되지 않은 C6·C7은 판정 조건에서 제외하되, 그 경우에도 수치는 보고한다. 다섯 조건만 쓰는 선택과 일곱 조건을 쓰는 선택은 학습 전에 하나로 확정한다.

보조(게이트 없음, 항상 보고): A3−A1(규칙 단독 효과: ΔF1, Δ3→1, Δ3→2, Δ2→3, ΔRecall1, ΔRecall3), 상호작용 (A3−A1)−(A2−A0), A4 결과, 선택 λ의 Fold·seed별 분포, 무변경 단위 비율, 그리드 상한 도달 수, age995/비995 하위 집단. 무변경 단위가 20 Fold 중 과반이면 "규칙이 W를 거의 바꾸지 못했다"고 보고한다. 모든 seed/Fold를 충족 여부와 무관하게 보고한다.

**퇴화 해석 규칙(사전 고정)**: "무변경" 단위(F 공집합 또는 N_min 미만)가 20개 중 **10개 초과**(제안)이면 결과가 W와 사실상 같아지므로 "구조적 실패: 이 규칙 가족은 W의 3→1을 선택 제약 하에서 줄이지 못했다"로 해석하고, C1~C7 수치가 우연히 충족돼도 가설 지지로 기록하지 않는다. 무변경 단위는 지표 계산에 λ=1로 포함하되 그 수를 항상 함께 보고한다.
