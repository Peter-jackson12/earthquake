# 논문 메모의 검증 보완 — 2026-10-13

이 문서는 [기존 논문 메모](PAPER_BENCHMARK_NOTES_KO.md)의 제한사항을 보완한다. 프로젝트 실험 결과를 논문 점수로 대체하지 않는다.

## Ghimire 등: 5등급과 3등급을 모두 평가

기존 메모의 5등급 중심 설명은 불완전하다. 원문의 damage-prediction 절과 Table 3에는 5등급 평가 외에도
DG1+DG2 / DG3 / DG4+DG5를 묶는 3등급 traffic-light 평가가 있다.
전체 입력/기본 입력에서 보고한 0.68/0.64는 **Accuracy**다. 우리 CV Macro F1과 수치가 비슷하다고 동등한 성능으로 비교하지 않는다.
동일한 3개 클래스 수만으로 데이터, 클래스 정의, 분할, 입력 또는 지표가 같아지는 것도 아니다.

원문: https://journals.sagepub.com/doi/10.1177/87552930221106495

## 아직 독립 확인하지 못한 원문 수치

ACK PDF의 세부 수치와 FAITH 표·혼동행렬 불일치 주장은 이번 후속 개발에서 재검증하지 않았다.
특히 FAITH의 수치 불일치를 이번 세션에서 독립 입증한 사실처럼 발표하지 않는다. 해당 그림을 직접 확인하고 계산하기 전까지 재확인 필요 상태를 유지한다.
논문을 점수 목표로 삼지 않고 오류의 심각도 구분, 불균형 처리의 손익, 계산량·표준편차를 함께 기록하는 방법만 참고한다.
