# T24 상위 지역 기준값과 상대 차이 실험 계획

2026-10-15 사용자 승인. 개인 `peter`에서 구현·검토·커밋 후 첫 실자료 실행 전에 봉인한다. 봉인 뒤 이 파일을 수정하지 않고 현재 진행 상황은 [RESEARCH_STATUS](RESEARCH_STATUS.md)에 기록한다.

## 목적과 비교 범위

기존 무가중치 LGBM-O의 C 전처리 입력에 상위 지역의 건물 크기·층수 기준값과 각 건물의 상대 차이를 추가한다. 처음 보는 세부 지역에서도 상위 지역의 건물 특성이 예측에 도움이 되는지 검증한다. 기존 T10/T11의 피해 등급을 사용한 지역 Target Encoding과 달리 정답을 사용하지 않는다. T12의 행별 크기 비율, T21/T22의 행별 상호작용과도 구분한다.

이번 비교는 추가 6열 묶음 전체의 효과다. 지역 중앙값과 차이 각각의 효과를 분리하지 않으며 지역 특성의 인과 효과나 새로운 지진에서의 성능을 주장하지 않는다. T22/T23 결과와 무관하게 정의·판정을 고정하고 다른 피처·순서형 학습·튜닝·가중치·결정 규칙과 결합하지 않는다.

## 고정 피처 정의

팔은 `GEO1_CONTEXT` 하나다. 그룹은 `geo_level_1_id`, 수치 열의 순서는 `count_floors_pre_eq`, `height_percentage`, `area_percentage`다.

1. 각 outer-train의 geo1별 수치 3열 중앙값을 계산한다. 짝수 개의 중앙값은 가운데 두 값의 산술평균이다. 모든 outer-train 행을 포함하며 학습 행 자신의 값도 포함한다. 정답과 검증 행은 사용하지 않는다.
2. 같은 outer-train 전체의 수치 3열 중앙값도 계산한다. transform에서 학습 때 없었던 geo1은 이 전체 중앙값을 사용한다. 검증 자료의 지역별 통계를 새로 계산하지 않는다.
3. 출력 열은 지역 중앙값 3개, 그다음 각 행의 원값에서 사용한 중앙값을 뺀 차이 3개다. 두 블록 내부 수치 순서는 위와 같다. 합계 6열을 기존 C 행렬 뒤에 추가한다.
4. 추가 블록은 스케일링·클리핑 없이 float32 CSR로 저장한다. 중앙값과 차이는 float64로 계산한 뒤 변환하며 변환 후에도 유한값인지 확인한다. 차이는 음수일 수 있다. 전체 희소 행렬 밀집화는 금지한다.

입력은 중복 없는 문자열 열 이름을 가진 DataFrame이다. geo1과 수치 3열은 결측 없는 유한한 비음수 정수여야 하며 0은 합성 경계값으로 허용한다. 열 누락·순서 변경·학습 뒤 arm 변경·비유한값·float32 범위 초과는 실패한다. 빈 학습 입력은 거부하고 빈 transform은 0×6 CSR를 반환한다. 기존 원본 입력과 C의 age995 처리·표시는 유지한다.

피처 상태에는 입력/출력 열 순서, 전체 학습 행수, 정렬된 geo1별 행수와 중앙값, 전체 중앙값과 정의를 저장한다. 각 train/valid의 미관측 geo1 건수·비율·전체 행수도 기록한다. 피처 상태·어휘·지역별 통계는 비공개 산출물이며 공개 보고에는 집계만 쓴다.

공식 자료는 지역 3열을 큰 지역에서 세부 지역으로 이어지는 코드로, 높이와 면적을 정규화된 값으로 설명한다. 높이·면적을 실제 미터·제곱미터로 해석하지 않는다. [DrivenData 데이터 설명](https://www.drivendata.org/competitions/57/nepal-earthquake/page/136/). 이 자료는 변수 의미의 근거이며 이번 파생변수의 개선 효과를 입증하지 않는다.

## 모델·분할·예산

- 실험 ID `T24_geo_context_features_v1`, 코드 `experiments/geo_context_features/`.
- C 및 LGBM-O는 T8/T13과 동일: 300 rounds, 31 leaves, learning_rate 0.05, random_state 42, 내부 2스레드. 나머지 파라미터·동결 환경도 유지한다.
- 무가중치, 재표집·early stopping·튜닝·임계값 조정 없음. labels=[1,2,3] 순서 확률 argmax이며 완전 동률은 낮은 등급이다.
- geo2 Group manifest seed 42/101/202/303 × 5 Fold × 단일 팔 = 신규 **20회 시도 상한**. 실패 자동·수동 재시도는 0회다.
- T8/T13의 동일 Fold LGBM-O OOF를 SHA·ID·정답·분할 대조 후 재사용한다. 기준선 신규 학습 0회, 별도 실자료 smoke fit 0회다.
- 출력 `local_reproduction/T24_20261015_geo_context/run`은 최초 봉인 시 미존재여야 한다. 기존 출력·태그를 덮어쓰지 않는다.
- 첫 `GEO1_CONTEXT/geo2_s42/f0`은 공식 예산에 포함한 자원·체크포인트 점검 단위다. 정상 종료와 재측정 후 나머지 19개를 진행한다.

## 사전 판정과 보고

기존 T21/T22와 같은 다섯 조건을 모두 요구한다.

1. 20 Fold 평균 Macro F1 차이 ≥ +0.003.
2. 양의 차이 Fold ≥ 14/20, 동률 제외.
3. 양의 seed별 Fold 평균 차이 ≥ 3/4.
4. 네 seed 혼동행렬을 합한 3등급 Recall 차이 ≥ 0.
5. 같은 반복 pooled의 3→1 오류율 차이 ≤ 0.

3→1·3→2의 분모는 실제 3등급 수, 2→3은 실제 2등급 수다. 개발 건물 208,480개의 4회 반복 예측을 독립 관측으로 세지 않는다. Fold 평균·SD(ddof=1), seed별 pooled, 모든 등급 P/R/F1·혼동행렬, 기준 대비 오류 전환, age995/non995, 미관측 geo1 발생률을 남긴다. 중앙값 기반 피처는 상위 지역에 의존하므로 geo2 평가를 미관측 geo1 일반화의 검증으로 확대하지 않는다.

같은 개발 자료·분할을 반복 사용하는 후속 탐색이다. 다섯 조건 충족도 새로운 독립 평가·통계적 유의성·최종 모델 선정·안전성 보장을 의미하지 않는다. 기존 연구 기준과 최종 모델을 자동 변경하지 않는다.

## 검토·체크포인트·독립 감사

- 합성 검사: 홀수/짝수 중앙값, 단일 행 지역, 미관측 지역의 전체 중앙값 대체, 음수 차이, 0값, 입력 순서, 빈 입력, y 무사용, 검증 값 변경 시 학습 상태 불변, 저장·복원 일치를 확인한다.
- base/extra/full의 train/valid 여섯 CSR 증거로 원래 C 블록 불변 및 추가 블록을 검증한다. 학습 통계와 원본 입력은 감사자가 독립적으로 재구성한다.
- 각 Fold는 학습 전에 시도·running 상태를 기록한다. 모델·전처리·피처·예측·지표를 즉시 저장하고 SHA-256, 재로딩 확률(허용 절대차 1e-12), 원본/백업 일치를 확인한 뒤 complete로 기록한다.
- 어느 Fold든 failed 또는 running 상태이면 다른 Fold 필터로 신규 학습을 우회할 수 없다. 실패 원장·로그·부분 산출물을 보존한다. 완료 Fold는 검증 후 재사용하며 재학습하지 않는다.
- 전용 검사 → 독립 검토 → 전체 회귀 → 코드·계획 커밋 → 봉인 → 첫 공식 Fold → 자원 재확인 → 나머지 → finalize → 독립 감사 → 집계 보고·검토 순서다.
- 독립 감사는 실행기 import·저장 joblib 역직렬화·새 분류기 학습 없이 C/6열/상태/CSR를 재구성하고 native 모델 20개의 재추론, SHA·백업·입력·분할·원장·시도 수와 모든 집계·판정을 대조한다.

실자료 실행은 기존 Astra 실행 관리자만 맡는다. T22/T23의 기존 프로세스·잠금·자원과 조율하며 실험별 중복 실행은 금지한다. 새 Fold 전 가용 RAM≥8GiB·디스크≥15GiB, 지속 CPU≥90% 또는 디스크 포화가 없는지 확인한다. 병행 여부와 순서는 관리자가 자원 여유에 따라 결정하되 같은 실험의 관리자를 중복으로 띄우지 않는다. 구현 준비만으로 학습 시작을 주장하지 않는다.

기존 봉인 소스·계획·설정·감사 파일은 변경하지 않는다. 홀드아웃 접근, 새 브랜치·worktree, 팀원 브랜치 변경, 원시 자료·모델·OOF·manifest 공개 업로드는 금지한다. 공통 문서·커밋·공개 전달은 컨트롤 타워가 맡으며 이번 요청에서 공개 push는 하지 않는다.

## 실행 관리자 인계

`P`는 `local_reproduction/20261014_01/venv/Scripts/python.exe`, 작업 위치는 `worktrees/peter_rules`다. 설치·업그레이드 없이 workspace TEMP/TMP와 UTF-8을 사용한다.

```text
P -m experiments.geo_context_features.run prepare --data ../../earthquake/data --output ../../local_reproduction/T24_20261015_geo_context/run --code-commit <최종 검토된 전체 SHA>
P -m experiments.geo_context_features.run fit-all --data ../../earthquake/data --output ../../local_reproduction/T24_20261015_geo_context/run --arms GEO1_CONTEXT --schemes geo2_s42 --folds 0
```

첫 Fold 저장·재로딩·백업·정상 종료와 자원 재확인 후 같은 모듈 fit-all로 나머지를 이어간다. prepare는 반복하지 않는다. 20개 complete·종료·잠금 해제 후 finalize하고 별도 준비 영수증으로 인계된 감사 CLI를 실행한다. 감사 PASS 뒤 `reports/GEO_CONTEXT_20261015.md`와 `geo_context_20261015.json`에 집계만 작성하고 독립 보고 검토를 거친다.
